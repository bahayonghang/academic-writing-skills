## Findings

### A. 官方《写作指南》可量化条目（原文逐字摘录）

| 条目 | 原文摘录（逐字） | 出处 |
|---|---|---|
| **题名 ≤20 字（"一般不宜"）** | "题目应准确概括整个论文的核心内容，简明扼要，一目了然。一般不宜超过20 个汉字（符）"，"如有副标题，在主标题和副标题之间用破折号间隔。" | §1.1 |
| **摘要：博士 800–1000、硕士 600 左右** | "博士中文摘要一般 800-1000 汉字（符） ，硕士论文摘要一般 600 汉字左右。" | §1.3 |
| **关键词 3~5 个、逗号间隔** | "论文的关键词……应有 3~5 个，每个关键词之间用逗号间隔。关键词放摘要页最下方，从新的一行撰写。" | §1.3 |
| **致谢 ≤1000 字** | "致谢言语应谦虚诚恳，实事求是。字数不超过 1000 个汉字。" | §1.10 |
| 目录列到三级标题 | "目录一般列到三级标题，即二级节标题（如 2.2.5）即可。" | §1.5 |
| 三级及以上节标题不建议 | "一般情况下，不建议使用三级及以上节标题。" | §1.7.1 |

**注意（防编造）**：该指南全文**没有**以下规定——正文总字数、绪论/引言字数、结论字数、
参考文献最低条数、近五年文献占比。这些字段对 pkuthss 模板不得写入 TEMPLATE_THRESHOLDS，
更不得沿用燕山或清华数值。

### B. 官方《写作指南》结构性要求（摘录）

- **十个组成部分**（§第一章开篇）：
  > 学位论文一般应由 10 个主要部分组成，依次为：1. 封面，2. 版权声明，3. 中文摘要，4. 英文摘要（ABSTRACT），5. 目录，6. 正文（含引言和结论），7. 参考文献 8. 附录，9. 致谢、后记或说明，10. 学位论文原创性声明和授权使用说明。
  >
  > 学位论文如果有缩略词或者符号表，可以放到目录之后、正文之前（5-6 之间）。以上各部分独立为一部分，每部分从新的一页开始。
- **主要符号对照表是条件项**（§1.6）："如果论文中使用了大量的符号、标志、缩略词……应编写
  '主要符号对照表'。如果上述符号和缩略词数量不多，可以不设专门的'主要符号对照表'，在论文中
  出现时随即加以说明即可。"（仓库现有 pkuthss.md 写"必须包含符号说明章节"，与官方指南
  不符——官方是条件式；pkuthss 模板与示例也无此章。落地时应改为条件项。）
- **章序号用中文数字**（§1.7.1）："各章标题，例如：'第一章 引言'。章序号采用中文数字，
  章序号与标题之间空一个汉字符，采用黑体三号字，居中书写"。
  节编号"用阿拉伯数字表示……数字间用半角小数点'.'连接"（如 2.1、2.1.1、2.1.2.1）。
- **图表/公式编号：章.序，点号（唯一制式）**（§1.7.4）：
  > 图、表和表达式按章编号，用两个阿拉伯数字表示，前一数字为章的序号，后一数字为本章内图、表或表达式的顺序号。两数字间用半角小数点"."连接。例如"图 2.1"，"表 5.6"，"式（1.2）"等等。
  - 图序图题在下（"图序与图名置于图的下方，采用宋体 11pt 字居中书写"）；表序表名在上；
    分图"分别以(a)、(b)、(c)……作为图序，并须有分图名"；续表"在每页表序前加'续'字"。
  - （与清华不同：**北大只给点号制式**，未给连字符选项；**未见**三线表强制条款。）
- **摘要页**（§1.3）：标题"摘要"黑体三号居中；"论文摘要不能出现图片、表格或其他插图材料。"
  基金资助"应在摘要第一页的页脚处标注"。（未明文禁止摘要中标注引用文献编号。）
- **英文摘要**（§1.4）："英文摘要由上到下应包含英文题目、作者姓名、专业名称（用括号括起放
  姓名之后）、指导教师姓名、'ABSTRACT'、英文摘要内容和关键词（KEY WORDS）。"
  "'KEY WORDS'大写，其后的关键词第一个字母大写，关键词之间用半角逗号间隔。"
  "英文摘要的内容应与中文摘要一致。"
- **脚注**（§1.7.3）：①②③ 样式上标，"脚注的序号按页编排，不同页的脚注序号不需要连续"，
  内容宋体小五。
- **参考文献**（§1.8）："论文中引用过的文献必须著录，未引用的文献不得出现。"
  "参考文献集中著录于正文之后，不得分章节著录。属于外文文献的，直接使用外文著录，不必译成
  中文。"标注法"可采用'顺序编码制'和'著者-出版年制'"；顺序编码制"文献序号放'[ ]'内，
  以上标方式标注在索引位置"。表内文字五号、行距固定 16 磅。
- **附录**（§1.9）："依顺序用大写字母 A，B，C，……编序号……只有一个附录时也要编序号，
  即附录 A。"附录内"例如'图 A.1'，'表 B.2'，'式（C-3）'等"。附录"并不是必须的"。
- **成果列表**（§1.10）："如果论文还有其它内容，如个人简历、在学期间发表的学术论文和成果等，
  可以放附录之后、致谢之前。发表论文列表要求同参考文献列表格式。"
- **页面设置**（§1.11）："纸张大小：标准 A4"；"页边距：上、下、左、右、装订线的页边距分别为：
  3.0cm, 2.5cm, 2.6cm, 2.6cm, 0cm，装订线位置：左。左右对称页边距。"
  "页眉距边界 2.0cm，页脚距边界 1.75cm"；页眉五号宋体居中、**奇偶页不同**（奇=各章名称，
  偶="北京大学博士学位论文"或"北京大学硕士学位论文"），文字下"划一条横线，线粗 0.75 磅"；
  页码"从'摘要'开始至'目录'……结束，页码用罗马数字"，"从'第一章 引言'开始……用阿拉伯数字"。
- **语言**（§第一章开篇）："学位论文均应采用国家正式公布实施的简化汉字撰写"（古文字、外文
  引用、外国语言文学论文除外，经学位办批准的英文论文"须用中文封面"）。
- **写法**（第二章，llm 判读类）：摘要"切忌写成全文的提纲，尤其要避免'第一章……；第二章……'"；
  引言五部分"1、问题的提出；2、选题背景及意义；3、文献综述；4、研究方法；5、论文结构安排"；
  结论 over-claim 红线（原文）：
  > 在评价自己的研究工作成果时，要实事求是，除非有足够的证据表明自己的研究是"首次"的、"领先"的、"填补空白"的，否则应避免使用这些或类似词语。
- **打印装订**（第三章）：双面打印（封面和原创性声明除外）；左侧装订；电子版"应是 1 个独立
  的 pdf 文件"、内容与纸质版完全一致（除签字）。

### D. pkuthss 模板文档事实（v1.9.4，2024-03-07）

- **维护状态**：cls 头部 `[2024/03/07 v1.9.4 Peking University dissertation document class]`；
  说明文档 `\docversion{v1.9.4}`、日期 `\zhdigits{2024}年\zhnumber{3}月`。
- **文档类选项及默认值**（pkuthss.cls 行 45–63，逐项）：`uppermark=false`、`pkufont=true`
  （"根据学校对论文格式的要求将西文字体改为类似于 Times New Roman / Arial 的字体"）、
  `pkufoot=true`（脚注带圈编号等）、`pkuspace=true`（行距/目录缩进/图表标题字号）、
  `spacing=true`、`pdftoc=true`、`spechap=true`、`pdfprop=true`、`ugly=false`；编码默认 GBK，
  UTF8 需显式声明。基础字号 `zihao=-4`（小四），基于 ctexbook。
- **ugly 选项（重要）**：cls 注释 "Whether to disable some infractions intended to make the
  style less ugly"（默认 false，即模板**默认在少数字号细节上有意偏离学校书面规定**）；
  示例 thesis.tex 注释原文：
  > 如果格式审查提示字号不严格符合标准，可以在 [] 中加入"ugly"选项。
  - 默认（非 ugly）：chapter 小二、section 小三、subsection 四号；`ugly`（严格校规）：
    chapter 三号、section 四号、subsection 13bp（cls 行 305–318）。
- **图表编号**：cls 未改 `\thefigure`/`\thetable`/`\theequation`，继承 book/ctexbook 默认
  `章.序`（点号），与校规"图 2.1"一致；`labelsep = quad`（编号与题文空一汉字位）。
  secnumdepth=3、tocdepth=2（同校规"目录列到三级标题"）。
- **页面**：`\geometry{a4paper, hmargin = 2.6cm, headheight = 0.5cm, headsep = 0.6cm}`；
  非 ugly `top = 3.0cm, bottom = 3.1cm, footskip = 1.1cm`，ugly `top = 3.1cm, bottom = 3.0cm,
  footskip = 0.8cm`（cls 行 279–284；与校规 上3.0/下2.5 数值不同属模板实现取舍）。
- **文档信息命令**（说明文档 §2.2 逐项）：`ctitle/etitle/cauthor/eauthor/date/studentid/school/
  cmajor/emajor/direction/cmentor/ementor/ckeywords/ekeywords/degreetype(1 学术/2 专业/0 不显示)/
  blindid/discipline`；集中设置用 `\pkuthssinfo{key = value, ...}`。
- **摘要**：`cabstract`/`eabstract` 环境（标题、作者、导师、专业自动生成）；关键词自动排在
  **摘要页最下方**（`\vfill\noindent\textbf{关键词：}`，cls 行 462–487），与校规"关键词放摘要页
  最下方"一致；中文关键词标签"关键词："（pkuthss-utf8.def）。示例 `ckeywords = {其一，其二}`
  用全角逗号，`ekeywords = {First, Second}` 半角逗号——与校规逗号间隔一致。
- **双盲评审支持**（说明文档 §2.2 + 示例）：封面用 `\makeblind`（替代 `\maketitle`）；
  西文摘要用 `beabstract` 环境（无作者导师行）；`\ifblind` 条件排除致谢；标题强制换行必须用
  `\thssnl` 而非 `\\`；盲审封面字段（pkuthss-utf8.def）："（匿名评阅论文封面）/中文题目：/
  英文题目：/一级学科：/二级学科：/论文编号："。原文（说明文档 §2.2）：
  > 排版双盲版论文时除了要去掉致谢等章节、隐去论文中其它可能泄露个人信息的部分外，还应注意在排版封面时须使用 \makeblind 而非 \maketitle 命令。
  （研究生院博士材料页同步提供"北京大学博士学位论文匿名评阅论文封面(2024)"官方 doc。）
- **参考文献**：默认样式为作者自制 biblatex 样式 **caspervector**
  （`\usepackage[backend = biber, style = caspervector, utf8, sorting = ecnyt]{biblatex}`）；
  说明文档"问题及其解决"章原文：
  > biblatex-caspervector 所实现的格式和 [北京大学研究生学位论文写作指南] 的规定并不一致……国标 GB/T 7714-2015 现在已经有了 biblatex-gb7714-2015 这一 biblatex 实现，用户也可以考虑使用。
  示例注释："biblatex-caspervector 也有一个'ugly'选项，使其更像国标格式；此外也可考虑改用
  style = gb7714-2015"。引用命令 `\cite`（未格式化）/`\parencite`（方括号）/`\supercite`
  （上标方括号）。参考文献列表标题被 biblatex 覆盖，须用 `\printbibliography[title=...]` 设置。
- **示例结构**（doc/example/thesis.tex 顺序）：封面（maketitle/makeblind）→ 版权声明 copy →
  中西文摘要（罗马页码）→ 目录 → 正文各章 → `\appendix` + `\printbibliography[heading=bibintoc,
  title={参考文献}]` → 附录 encl1 → `\backmatter` 致谢（盲审版去除）→ 原创性声明和使用授权
  说明 origin。**无"主要符号对照表"章**。
- **编译**：三种方式均可——latex+dvipdfmx / pdflatex / xelatex，配 biber；推荐 latexmk；
  "XeLaTeX 对非 UTF-8 编码的支持不好，因此 XeLaTeX 方式的编译不支持 GBK 编码"（说明文档 §1.3）。
- **表格字号**：说明文档"问题及其解决"章："模版并未尝试设定表格的默认字号，用户须自行按学校
  规定进行设置。"（校规表内文字 11pt 宋体。）
- **默认双面**：示例注释"若要避免章末空白页，请在调用 pkuthss 文档类时加入 openany 选项"；
  说明文档"文档默认情况下是双面模式，每章都从右页（奇数页）开始"。
- 模板自我定位（说明文档"问题及其解决"）："学校对学位论文格式的规定显然没有考虑到非 MS Word
  类排版工具的工作方式，因此 pkuthss 文档模版只是对其要求的格式进行模仿，而在一些小的细节上
  可能有所出入。"

### E. 与检查器映射建议（供落地参考，非事实）

- `script:title_len`：max 20（"一般不宜"→ 宜配缓冲带）；副题名规则只有"破折号间隔"，无合计字数。
- `script:abstract_len`：博士 (800, 1000)；硕士 600"左右"（区间需实现侧决定缓冲，如 ±10%，
  不得虚构上下限原文）。
- `script:kw_count`：(3, 5)。
- `script:conclusion_len`：无依据，禁写。`script:wordcount`/`intro_len`/`bib_count`/`bib_recency`：无依据，禁写。
- 致谢 ≤1000 字：现有 CHECKERS 无致谢字数检查器（不可新增脚本）→ 写 `llm` 或 `manual`。
- 章序号中文数字、图表点号编号、奇偶页眉 → `module:format`/`llm`/`manual`。
- 摘要禁插图材料有原文；"摘要不标引用编号"无原文 → abstract_no_cite 若用需换依据或降 llm。
- 未引用文献不得出现在参考文献表 → `module:bibliography`（verify_bib/check_references 联动）。

  研究生院公开原文，仅有 Overleaf/GitHub 二手描述——记入 missing-evidence.md，不得作为依据。
- 2024 官方 Word 模板为 .doc 二进制，仅做字符串粗扫交叉验证，未逐页核对版式数值。
