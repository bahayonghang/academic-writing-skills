# 预提交清单

跨场所纸质审核的综合清单。

## 通用清单（所有期刊或会议）

### 编译和格式化

- [ ] 论文编译没有错误
- [ ] 没有过满/未满的 hbox 警告 (LaTeX)
- [ ] 遵守页数限制（不包括参考文献）
- [ ] 使用正确的样式文件/模板
- [ ] 一致的字体大小和边距

### 内容完整性

- [ ] 无占位符文本（TODO、FIXME、XXX）
- [ ] 文本中引用的所有数字
- [ ] 文本中引用的所有表格
- [ ] 没有孤立引用（每个`\cite`有号码布条目）
- [ ] 没有未使用的参考书目条目
- [ ] 引用的所有方程（如果编号）
- [ ] 始终保持一致的符号

### 写作质量

- [ ] 所有首字母缩略词均在首次使用时定义
- [ ] 句子不要太长（> 60 个单词）
- [ ] 摘要是独立的
- [ ] 摘要包含所有 5 个结构要素（背景/目的/方法/结果/结论）
- [ ] 摘要结果部分包括至少一项定量发现
- [ ] 摘要在期刊或会议字数限制内
- [ ] 简介中明确说明了贡献
- [ ] 引言/相关工作中没有引用堆积（每句话最多 2 个集群引用，无需单独讨论）
- [ ] 包括限制部分
- [ ] 图/表标题简洁，没有类似人工智能的冗余，并使用一致的大小写
- [ ] 表格使用三行格式（书签/无垂直线）
- [ ] 表格标题位于表格上方，注释位于表格下方
- [ ] 每个表列内的数字精度一致
- [ ] 使用时表注中定义的统计显着性标记
- [ ] 文献综述使用主题组织，而不是作者/年份枚举（A1）
- [ ] 每个文学主题簇都以批判性分析结束（A2）
- [ ] 相关工作以明确的研究差距推导结束（A3）
- [ ] 讨论包含因果/归因分析，而不仅仅是数据重复（B3）
- [ ] 相关工作引用再次出现在结果情境化讨论 (B4) 中
- [ ] 结论包含所有三个要素：调查结果摘要 + 影响 + 局限性/未来工作 (B5)
- [ ] 简介贡献声明在结论 (C3) 中得到解答
- [ ] 声明措辞与证据强度相匹配——相关结果上没有因果语言，没有支持的“第一/新颖/普遍”，没有没有数字的模糊幅度词（参见`OVER_CLAIM_GUARD.md`)

### 理论与概念框架

- [ ] 核心理论概念定义清晰明确 (A5)
- [ ] 理论框架涉及现有理论，而不仅仅是引用它们（A6）
- [ ] 论文的理论贡献是可识别的并明确陈述的 (A7)
- [ ] 研究差距是真实存在的，有文献证据支持，而不是通过选择性引用捏造的

### 定性方法（当论文使用定性或混合方法时适用）

- [ ] 用理论/方法论原理描述的抽样策略 (B6)
- [ ] 讨论数据饱和或样本量合理（B7）
- [ ] 足够详细地描述编码/分析过程：阶段、编码器、示例 (B8)
- [ ] 报告的可信度策略（三角测量、成员检查、审计跟踪等）(B9)
- [ ] 涉及人类参与者或敏感主题的研究人员的反思性 (B10)

### 实验分析

- [ ] 实验部分使用连贯的段落叙述，而不是逐项列表
- [ ] 包含适当的、最新的 SOTA 基线方法并证明其合理性
- [ ] 消融研究有效验证了核心部件的贡献
- [ ] 在适用的情况下报告统计显着性/置信区间

### 提交合规性

- [ ] 匿名投稿（盲审无作者姓名）
- [ ] 尺寸限制内的补充材料
- [ ] 准备提交代码（如果适用）
- [ ] 道德审查标记（如果适用）

## NeurIPS 特定

- [ ] 已完成的纸质清单（附录）
- [ ] 包括更广泛的影响声明
- [ ] 准备好总结（针对已接受的论文）
- [ ] 主论文 <= 9 页（+ 无限参考文献/附录）
- [ ] 使用官方 NeurIPS 样式文件
- [ ] 再现性细节：随机种子、计算、数据集
- [ ] 指定方法中包含误差线
- [ ] 适当时进行统计显着性检验
- [ ] 记录数据集许可和同意
- [ ] 讨论潜在的负面社会影响
- [ ] 与适当基线的比较
- [ ] 关键设计选择的消融研究

## ICLR 特定

- [ ] 使用官方 ICLR 样式文件
- [ ] 双盲审查合规性
- [ ] 主论文 <= 10 页（+ 无限附录）
- [ ] 包括再现性声明
- [ ] 提供代码提交 URL（如果适用）

## ICML 特定

- [ ] 使用官方ICML样式文件
- [ ] 主论文 <= 8 页（+ 无限附录）
- [ ] 包括影响声明
- [ ] 补充 <= 50MB

## IEEE 特定

- [ ] 使用的 IEEE 样式文件（会议或期刊）
- [ ] 摘要 <= 250 字
- [ ] 提供关键字（3-5 个术语）
- [ ] 参考文献遵循 IEEE 格式
- [ ] 图标题位于图下方，表格标题位于表格上方
- [ ] 所有数字均为高分辨率 (>= 300 DPI)
- [ ] 无浮动`algorithm` / `algorithm2e`IEEE 伪代码中的环境
- [ ] 伪代码块使用标题和标签
- [ ] 伪代码块在出现之前在文本中被引用
- [ ] 当有助于审查时启用伪代码行号（推荐，非强制）
- [ ] 伪代码注释很短；段落级解释保留在正文中

## ACM 特定

- [ ] 包含 ACM 计算分类系统 (CCS) 概念
- [ ] 页脚中的 ACM 参考格式引用
- [ ] 用途`acmart`文档类
- [ ] 包含权限管理信息
