# 合并规则

将通道输出合并到`final_issues.json`.

## 合并时间

- 两项发现表明了相同的潜在缺陷
- 它们指向相同的引用或相同的本地文本范围
- 解决一个根本原因就能解决这两项发现

## 保持分开时

- 相同的根本原因会产生不同的纸面后果
- 研究结果需要作者采取不同的行动
- 一项调查结果与方法论有关，另一项调查结果与声明准确性有关
- 使用来自不同部分或附录的证据

## 优先规则

- 保留更好的解释
- 如果重复项不同意，则保持较高的严重性
- 如果解释在其他方面相同，则保持较高的置信度
- 保留所有相关部分

## 误报

仅当通过上下文、约定或解析噪音明确解决了某个发现时，才删除该发现。不要仅仅因为单个结果只出现一次而放弃它们。
