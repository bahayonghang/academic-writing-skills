## 第一类：句子结构

### 1.1 主题突出结构
❌“这个方法，它的优势是显而易见的。”
✅“这种方法的优点是显而易见的。”

### 1.2 连贯句
❌“我们提出了一种可以解决问题的方法。”
✅“我们提出了一种可以解决问题的方法。”

### 1.3 缺失的文章
❌“深度学习是流行技术。”
✅“深度学习是一项流行的技术。”

## 第二类：选词

### 2.1 弱动词
|中式英语|学术的|
|-----------|----------|
|制作|构造、生成、生产、创造|
|做|执行、进行、执行、实行|
|得到|获得、获得、获得、获得|
|使用|雇用、利用、利用、采用|
|展示|演示、说明、揭示、指示|
|寻找|发现、识别、观察、确定|

### 2.2 非正式表达
|避免|使用替代|
|-------|-------------|
|很多|大量的，大量的，大量的|
|大的|重要的，重要的，主要的|
|非常|高度、显着、显着|
|事物|因素、要素、方面、组成部分|
|好的|有效的、高效的、最佳的、卓越的|

### 2.3 冗余表达式
|多余的|简洁的|
|-----------|---------|
|彻底消除|排除|
|前景|前景|
|过去的历史|历史|
|基本原理|基础知识|
|提前计划|规划|

## 第三类：对冲（避免绝对化）

### 禁止的绝对词
- ❌ “显然”、“显然”、“当然”、“无疑”
- ❌ “总是”、“从不”、“全部”、“没有”
- ❌“证明”，“证明”（除非数学证明）

### 学术对冲
- ✅“看来……”、“看来……”
- ✅ “结果表明......”，“数据表明......”
- ✅“这可能归因于……”
- ✅“一种可能的解释是……”

## 第 4 类：时态用法

### 摘要
- 一般陈述的现在时
- 具体发现的过去时

### 介绍
- 既定事实的现在时
- 最近发展的现在完成时

### 方法
- 过去时（你做了什么）

### 结果
- 你的发现的过去时态
- 表格/数字的现在时（“表 1 显示...”）

### 讨论
- 用于解释的现在时
- 引用结果的过去时

## 类别 5：常见短语错误

### 介词错误
|错误的|正确的|
|-------|---------|
|根据|根据|
|设于|基于|
|与（相似）比较|与（相似）比较|
|不同与|不同于|
|聚焦于|专注于|

### 搭配错误
|错误的|正确的|
|-------|---------|
|做一个实验|进行/进行实验|
|做出结论|得出/得出结论|
|努力|努力|
|提出问题|提出问题|
|解决问题|解决/处理问题|

## 第六类：汉英翻译模式

### 6.1 直接翻译错误
|中文|❌ 中式英语|✅ 英语|
|------|-------------|-----------|
|越来越多|越来越多|日益|
|最近|最近几年|最近/自 2020 年以来|
|发挥重要作用|发挥重要作用|对于/使能至关重要|
|取得了很大进展|取得了很大的进步|已显着进步|
|随着...的发展|随着发展|随着X的进步/给定的进步|

### 6.2 学术表达模式
|中文|英语|
|------|---------|
|下面提出...|我们建议.../本文提出...|
|实验结果展示...|实验结果表明...|
|与...相比|与...相比/与...相比|
|综上说|总而言之/结论|
|表示的是|值得注意的是/值得注意的是|

## 打字机特定注释

### 注释语法
```typst
// This is a single-line comment

   multi-line comment */
```

### 常见打字错误
❌ 使用 LaTeX 语法：`\cite{}`
✅ 使用 Typst 语法：`@cite`

❌ 使用 LaTeX 数学：`\frac{a}{b}`
✅ 使用 Typst 数学：`$a/b$`或者`$(a)/(b)$`

❌使用LaTeX环境：`\begin{figure}`
✅ 使用 Typst 函数：`#figure(...)`
