# latex-thesis-zh 绪论写作能力优化：引用密度、文献分布、研究现状可视化、科学问题规范与整体性

## Goal

升级 `academic-writing-skills/latex-thesis-zh`（v5.3.0）对博士学位论文**绪论（第 1 章）**的写作指导与自动诊断能力，使其产出/审查的绪论满足：引用数量与密度达标、文献年份与来源分布合理、国内外研究现状有结构化可视呈现、科学问题表述含"对象-问题-方法"三要素、全章形成单一可答辩主线。

## 错误示范（file-backed fixture）

`D:\Documents\LYH\200-Learning\00博士毕业\毕业论文\thesis\chapters\chapter1.tex`——用当前版本 skill 写出的绪论，实测证据：

审读发现的**额外问题**（用户"还有其他问题"）：

- 缺"研究目的与意义"独立小节（背景与意义混写），缺"研究方法/技术路线"小节，多数高校规范（北工大等）要求绪论含课题来源与主要研究内容的明确分节。
- 1.2 节五个 subsection 内部无二级分层，单段密度过高（500+ 字/段），缩写定义（APC/MV/CV/FiLM…）密集堆在正文首现处。
- 综述每小节末尾的"收束段"存在但都收到同一句式（"第 N 章将……"），缺少"共识→分歧→局限→空白"的显式对比句。

## 外部最佳实践依据（调研结论，写入 references 时须注明可配置）

1. **引用数量**：博士学位论文参考文献总数一般 ≥100 篇，外文 ≥1/2，近五年 ≥1/3 且须有近两年文献（北京工业大学、哈尔滨工业大学撰写规范）；更严口径为近三年 ≥30%、近五年 ≥50%。绪论约 1 万字、承担全文大部分引用；用户基准：绪论 120~160 篇或更多。
2. **研究现状组织**：多维组织（时间分期/主题/方法/机构-地域）、"总-分-总"结构、从远到近排列；进阶做法为时间轴/研究演进图 + 文献对比矩阵表（维度：方法、假设、适用范围、局限）+ 量化统计；每主题簇末尾必须有比较/让步/局限句。三忌：讲义式罗列、主观设靶、来源含糊。注：甘特图属开题报告进度安排，不入绪论——以"研究演进时间线/技术路线图"承接该需求。
3. **科学问题凝练**：须同时含研究对象、研究问题、方法/技术路径三要素，可检验、可收集数据验证；一句话旗帜鲜明（国自然预评审共识）；主题唯一，用假设树自顶向下分解。
4. **引用多样性**：不只引一组学者；经典开创文献 + 近三年热点兼顾；一手文献优先；同一作者/团队文献不整簇堆引，应拆开分述并比较差异。
5. **整体性**：主题先行；先写正文后写绪论；与研究问题无关内容删除；创新点↔科学问题↔研究内容↔章节安排四方闭合。

来源：北工大撰写规范 PDF、鲲鹏智写《国内外研究现状写作指南》、博客园《博士毕业论文——绪论篇》、知乎《怎么合理引用论文参考文献》、澳城大《博士论文开题报告指南》、国自然预评审经验（guozr.com）等，全文见 research/ 或任务 journal。

## Requirements

- **R1 引用数量与密度诊断**：对绪论统计唯一引用键数、每 subsection 引用密度、单点堆引（一个 `\cite` ≥3 键）位置；阈值默认 120~160（博士绪论）、可配置；输出 `% LITERATURE (L##) [Severity] [Priority]` 格式报告。
- **R2 文献年份分布与来源多样性诊断**：给定 .bib 路径时解析 year 字段，报告近三年/近五年占比（默认目标 ≥30% / ≥50%）并列出可补位的年份空档；检测同一作者前缀/机构键在相邻引用中的扎堆模式并给出拆分建议。写作指导侧给出"选文配比"策略（每主题簇：经典 1~2 + 近三年 2~3 + 中外均衡），供与 bib-search-citation 协作时执行。
- **R3 研究现状结构化呈现**：references 新增绪论专章指导——研究演进时间线图（年代轴+阶段分期）、逐主题文献对比矩阵表模板、"总-分-总"小节骨架、每簇末尾对比/局限句；脚本侧新增检查：综述小节是否引用了总结性表格/图、是否存在分期或对比结构。
- **R4 科学问题三要素规范**：提供"针对〈对象〉的〈现象/瓶颈〉，研究〈科学问题〉，拟采用〈方法路径〉"模板与科学问题/技术问题/工程任务判别表；脚本检查绪论中"科学问题"表格行或枚举项是否为纯名词短语（缺对象或方法要素）。
- **R5 绪论整体性主线检查**：背景→现状→问题→内容→创新→结构六节共享同一主线的闭合检查——创新点、科学问题、研究内容、章节安排四方映射是否一一对应；首段是否漏斗式（领域→瓶颈→本文）；"国内外研究现状"是否区分国内/国外或显式声明按主题混排的理由。
- **R6 文档与路由落位**：绪论专项指导落在 `references/writing/`（新文件或扩展 thesis-writing-guide 绪论节）；SKILL.md 只加最小指针，细节全部下沉 references（延续 07-09 瘦身原则）。

## Constraints

- 不新增/伪造文献；引用数量不足时只诊断并提示从用户 .bib 检索候选，绝不编造条目（红线 #2）。
- 不破坏 `\cite{}`/`\ref{}`/`\label{}`/数学环境（红线 #1）；诊断输出遵循 skill 的 Output Contract。
- SKILL.md 改动须过 tests/contracts 的 ROUTER_ROW_RE 与字符串锁；version 不 bump（全仓同步规则），只改 last_updated。
- 阈值全部可配置且在 references 中注明出处与适用边界（各校规范有差异）。
- 优先扩展现有模块（literature/logic），避免新增 Module Router 行；确需新增须同步 contract 测试。
- fixture 不得直接提交用户真实论文：以脱敏/合成等价样本进入 `tests/` 或 `evals/`（保留问题模式，替换领域内容）。
