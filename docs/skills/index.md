# Skills

This repository currently documents six top-level skills. Start here when you know the kind of artifact you have but not the exact module or mode.

| Skill | Scope | First useful action | Entry |
| --- | --- | --- | --- |
| `cover-letter` | Submission cover letters for LaTeX manuscripts | Generate or align-check a letter against `main.tex` | [/skills/cover-letter/](/skills/cover-letter/) |
| `paper-audit` | Multi-format paper auditing and gate decisions | Run `quick-audit`, `gate`, or prepare a deep-review workspace | [/skills/paper-audit/](/skills/paper-audit/) |
| `latex-paper-en` | Existing English LaTeX papers | Compile, then run targeted review modules | [/skills/latex-paper-en/](/skills/latex-paper-en/) |
| `latex-thesis-zh` | Existing Chinese LaTeX theses | Map structure, detect template, then compile/check | [/skills/latex-thesis-zh/](/skills/latex-thesis-zh/) |
| `typst-paper` | Existing Typst papers | Compile/export, then run targeted review modules | [/skills/typst-paper/](/skills/typst-paper/) |
| `bib-search-citation` | Local `.bib` libraries | Search with compact filters and emit citations | [/skills/bib-search-citation/](/skills/bib-search-citation/) |

## How to Read These Pages

Each skill page follows the same user-facing shape:

- 适用场景 / when to use it
- 不适用场景 / when not to use it
- module or mode router
- minimum inputs
- script entry points
- output artifacts
- common requests

## Routing Shortcuts

- Letter for editors? Use `cover-letter`.
- Reviewer report or pass/fail readiness? Use `paper-audit`.
- Source-level compile, grammar, table, pseudocode, or bibliography diagnostics? Use the matching writing skill.
- Local bibliography search? Use `bib-search-citation`.
