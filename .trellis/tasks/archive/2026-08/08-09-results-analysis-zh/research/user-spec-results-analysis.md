# 实验结果分析规范

> 适用于中文工科学位论文中的模型对比、组件对比、敏感性分析和工业案例结果讨论。

## 1. 目标与事实边界

结果分析应当回答三个递进问题：实验观察到了什么差异，差异集中在哪些样本或指标上，哪些方法设计与该差异一致。分析必须从图表事实开始，再进入理论解释。不得先给机制结论，再从表中挑选数字印证。

写作前锁定以下对象：

- 数据块、样本数、评价顺序和输入权限；
- 评价对象所处的管线阶段，例如原始候选、个体准入后、集合筛选后或下游模型输出；
- 指标方向、最优值、次优值和风险子集定义；
- 图中曲线、箱线统计和表中数值的来源批次；
- 模型的已定义输入、结构、损失和训练协议；
- 能够区分完整设置与单个组件的实验类型。

本地参考学位论文只用于观察结果段的组织方式，不作为本论文数值、机制或学术主张的直接来源。

## 2. 强制论证顺序

模型对比小节应按以下顺序展开：

```text
比较协议与模型分组
  -> 总体指标排序与最接近基线
  -> 子集、工况或风险尾的排序变化
  -> 轨迹/散点定位误差发生位置
  -> 箱线或分布统计判断误差主体与离群尾部
  -> 输入信息和表征机制解释
  -> 组件记录或区分性证据复核
  -> 当前结论及下一实验接口
```

数值段和理论段不能交错成"报一个数、猜一个原因"的流水账。应先用一至三个自然段建立完整的经验事实，再用后续自然段解释其与问题特性及方法设计的关系。

## 3. 数值比较规则

### 3.1 比较对象

- 每个指标优先比较全表次优模型，而不是任意选择差距最大的基线。
- 当 RMSE、MAE 或子集指标的次优模型不同，应分别点名，不得用一个基线代表所有指标。
- $R^2$ 默认报告绝对差值，例如"提高 0.0499"；只有确有解释价值时才报告相对百分比。
- 误差指标的相对降低率统一为

```text
(基线误差 - 本文方法误差) / 基线误差 x 100%
```

- 分组比较必须先说明分组依据，例如输入权限、模型类型或训练协议。不能把分组均值当作受控实验结论。

### 3.2 参照与评价界限

同一张表混合点参照和评价界限时，必须逐行锁定比较对象与判据：

- R2R 点参照用于报告效应量接近程度；没有等价包络或等价检验时，只能写"接近参照"，不得写"统计等价"。
- R2R P95 界限表示对应 R2R 指标分布的第 95 百分位。区间型估计应比较与判据同方向的置信端点，例如误差指标使用置信上界与上界阈值比较。
- 预先给定的支持域或目标上界应与 R2R P95 分开命名，不能统称为"R2R 参考"。
- 一个单元格包含多个指标时，每个判据只作用于明确绑定的指标。KS 有界限而 W1 无界限时，应分别写"KS 上界低于界限"和"W1 作描述性记录"，不能将整行概括为"界限内"。

写作顺序为"估计值与区间 -> 对应参照或界限 -> 绝对差或端点比较 -> 受支持的结论"。例如：

```text
选定集的平均 KS 为 0.033，R2R 点参照为 0.030，绝对差为 0.003，结果接近点参照。指定条件 KS 的 95% 置信上界 0.055 低于 0.060 的评价界限；同一行的 W1 没有界限，仅报告估计值和置信区间。
```

评价对象名称必须包含其管线阶段。若表中统计量来自"个体准入 + 集合筛选"后的候选，应统一称为"选定集"；不得把该结果外推为原始候选池保真度，也不得直接推出下游模型效用。

### 3.3 排序反转

若总体、低风险尾、高风险尾或不同工况的排序不一致，必须报告反转。推荐写法为：

```text
方法 A 的总体和高风险尾误差最低；低风险尾由方法 B 取得最低值。因此，A 的相对优势主要分布在总体样本和高风险尾，并未在所有子集保持同一排序。
```

禁止删除不利指标，或用"总体最优"替代子集上的真实交叉结果。
风险子集样本较少时，应在首次解释该排序处给出样本数，并将结论写成当前测试块的点估计，
不据此形成稳定排序或跨数据集结论。

## 4. 图、表与分布统计的分工

| 证据 | 主要回答 | 合格分析 |
| --- | --- | --- |
| 指标表 | 谁更优、差多少 | 最优/次优、相对差、绝对差、排序反转 |
| 预测轨迹 | 差异发生在哪里 | 峰值、低谷、过渡段、连续偏移或局部欠估 |
| 散点图 | 误差随目标如何变化 | 对角线偏离、异方差、边界压缩 |
| 箱线图 | 典型误差与尾部误差如何组成 | 中位数、四分位距、上须和离群值 |
| 组件表 | 哪些结构变化伴随指标变化 | 同指标逐项对照及交叉结果 |

轨迹分析必须回到指标。例如，高值窗口集中欠估应与高风险尾 RMSE 或最大绝对误差对应。箱线图分析必须区分误差主体和上侧尾部：中位数及四分位距描述典型窗口，上须、离群值和最大值描述少量大误差窗口。不得只写"曲线更贴合"或"箱体更小"。

## 5. 生成候选与统计保真度结果

本节适用于生成模型输出经准入、重排或集合筛选后，与真实样本比较边际分布、联合分布和动态结构的结果讨论。统计保真度只回答选定评价对象在规定统计量上是否接近参照或满足界限；下游预测、分类或优化效用应另设小节评价。

### 5.1 标题、对象与来源

标题必须同时交代生成来源、管线阶段和评价问题。推荐形式为：

```text
方法 A 候选经阶段 B 筛选后的统计保真度
```

例如"PFG-CDM 候选经 MC3-C5 筛选后的统计保真度"能够锁定生成方法、筛选阶段和统计评价目标；"生成结果与保真度"不能说明被评价的是原始候选、准入候选还是最终选定集，应避免使用。

正文首段必须继续锁定：

- 评价对象的来源批次和最终管线阶段；
- 真实样本、R2R 参照和评价界限各自由哪个数据块确定；
- 指标在哪个原始空间、标准化空间或变换空间内计算；
- 表、图和正文数值是否来自同一批选定集。

标题、表题、列名、图题和正文应使用同一对象名称。若统计量来自"个体准入 + 集合筛选"后的选定集，不得简称为"生成样本"并外推到原始候选池。

### 5.2 强制论证顺序

生成保真度小节按以下顺序展开：

```text
评价对象及来源批次
  -> 参照和界限定义
  -> 边际与指定条件指标
  -> 联合分布指标
  -> 动态结构指标
  -> 图中的支持区间和局部差异
  -> 与完整生成—筛选管线的一致性解释
  -> 下游效用实验接口
```

先完成逐类指标判读，再综合回答"在哪些统计层面接近参照或满足界限"。不能在第一项 KS 通过后提前概括整组指标，也不能把下游模型性能混入统计保真度结论。

### 5.3 指标含义与判读

| 指标族 | 回答的问题 | 必须报告 | 可支持的结论 |
| --- | --- | --- | --- |
| KS、W1 | 单变量边际分布及指定条件偏移 | 估计值、区间、逐指标参照或界限 | 对应边际接近点参照，或对应端点处于界限内 |
| MMD、SWD | 多变量联合分布差异 | 核或投影设置、估计值、区间和对应界限 | 在当前核或投影定义下满足联合分布评价界限 |
| C2ST | 分类器能否区分真实集与选定集 | 实际分类器、分组方式、折数、AUC 区间和判据 | 在该分类器和分组折协议下区分度接近随机水平 |
| ACF、PSD | 时间相关性与频谱结构差异 | 滞后或频域设置、误差值、区间和对应界限 | 在所评价的时域或频域统计量上满足动态界限 |

置信区间端点必须按判据方向比较：

- 对"数值越小越好"的上界判据，比较置信上界与阈值；
- 对 C2ST 的双侧容许带，检查 AUC 区间或预先定义的统计量是否落入以 0.5 为中心的容许范围；
- 对下界判据，比较置信下界；对双侧区间判据，同时检查两个端点；
- 区间重叠不等于统计等价。只有预先定义且完成的等价检验才能使用"等价"。

### 5.4 混合参照表与结果术语

同表出现多类参照时，应在列名、表注或逐行单元格中明确区分：

1. **R2R 点参照**：用于说明估计值与真实样本重采样基线的绝对差，结果术语为"接近参照"；
2. **R2R P95 界限**：用于比较同一指标的相应置信上界，结果术语为"上界内"或"区间内"；
3. **指定目标界限**：由支持域、任务目标或预注册规则给出，必须写明不是 R2R 点参照；
4. **无判据统计量**：仅报告估计值与区间，结果术语为"描述性记录"。

复合行中的判据必须逐指标绑定。若"条件 KS/W1"一行只有 KS 上界，结果列应分别写"KS 上界内；W1 描述性记录"，不得将整行写为"界限内"。同理，不能把 ACF 的阈值用于 PSD，也不能把 R2R 点参照改写为通过/未通过判据。

结果列宜使用"接近参照""上界内""区间内""描述性记录"等短语。对中文窄列采用左对齐定宽 `p` 列并合理分配列宽；不要用 `\makecell` 把长句强行塞入狭窄单元格。编译后必须目检整表，因为没有 overfull 警告仍可能出现逐字断行、异常字距或不可读的多行堆叠。

### 5.5 图形解释与变量语义

密度图或边际分布图必须说明生成侧曲线代表什么变量。条件生成任务中，生成侧可能是给定生成器的指定条件 $y^*$，并不等同于可直接观测的"合成样本真实值"。正文和图题不得把二者混称。

图形分析至少包含两层：

- **支持区间**：主要质量区间是否重叠，边界或尾部是否存在缺口；
- **局部形态**：哪些分箱、峰肩、峰顶或尾部的密度高度存在差异，以及这些差异是否与 KS/W1 数值一致。

"两条密度曲线相似"不是完整分析。图只作为对应边际指标的定位证据，不能替代联合分布和动态结构指标。

### 5.6 完整设置解释与证据边界

机制解释应建立"方法中已定义的约束 -> 对应统计量 -> 当前观察"的映射：

- 动态表示、时序编码或动态一致性约束，可与 ACF、PSD 的时域和频域结果建立一致性解释；
- 候选准入、可行性约束、分布距离预算或集合筛选，可与最终选定集的 KS、W1、MMD、SWD 和 C2ST 结果建立一致性解释；
- 只有原始候选池、阶段中间输出或受控组件移除结果存在时，才能区分生成器、单项准入规则或集合筛选各自的贡献。

没有上述区分性证据时，归因保持在完整"生成方法—筛选设置"层级，使用"与……一致"或"表明完整设置得到的选定集……"，不得写"某一组件保证了保真度"或"某个阈值带来了全部改善"。

结尾应正面回答本节覆盖的问题，例如"选定集在所评价的边际、联合和动态统计量上接近相应参照或满足相应界限"，然后说明下一小节将评价下游效用。不要用连续免责声明稀释主结论，也不要由统计保真度直接推出预测性能提升。

### 5.7 可复用句式与正反例

基础句式：

```text
指标 X 的估计值为 a [l,u]，对应 R2R 点参照/评价界限为 b；二者绝对差为 d，或其置信上界 u 低于 b。因此，该指标接近参照/处于上界内。指标 Y 未设判据，仅作描述性记录。
```

推荐整段：

```text
方法 A 候选经阶段 B 筛选后的选定集，其控制变量平均 KS 为 0.034，R2R 点参照为 0.031，绝对差为 0.003；指定条件 KS 的 95% 置信上界 0.057 低于 0.060 的目标界限，而同一行的 W1 未设界限，仅作描述性记录。联合分布方面，MMD、SWD 及采用分类器 C 和五个分组折计算的 C2ST 均满足各自判据；ACF 与 PSD 的置信上界也分别低于对应动态界限。密度图显示两侧主要支持区间重叠，但选定集在主峰右肩的密度略低，这与非零的边际距离一致。动态指标结果与完整设置中的动态表征和一致性约束相符，联合指标则描述了阶段 B 输出的最终选定集；各组件的独立贡献仍需中间输出或组件移除实验区分。下一小节据此单独评价该选定集的下游效用。
```

不合格：混淆管线阶段。

```text
生成模型得到的原始样本与真实数据一致。
```

问题：若指标来自筛选后的选定集，该表述同时混淆评价阶段，并把"满足有限统计量"扩大为整体一致。

不合格：把单项判据外推到整行。

```text
条件 KS/W1 的置信区间均在 0.060 界限内。
```

问题：只有 KS 定义界限时，W1 不能共享该阈值，应作为描述性统计单独报告。

不合格：由完整设置结果归因到单一组件。

```text
ACF 和 PSD 通过证明动态编码器保证了时间保真度。
```

问题：完整生成—筛选设置不能排除其他训练约束与筛选步骤的作用，且"保证"超出点估计和区间能够支持的证据层级。

## 6. 理论解释的证据阶梯

每项解释先判断证据等级：

| 等级 | 可写内容 | 推荐谓词 |
| --- | --- | --- |
| 图表事实 | 当前测试块直接观察到的数值与形态 | "为""低于""集中在" |
| 结构事实 | 公式或算法直接定义的输入与计算 | "使用""保留""调节""回退" |
| 一致性解释 | 结果形态与结构机制相互对应 | "与……一致""与……相符""支持……的关联" |
| 组件贡献 | 同一框架的受控组件变化 | "去除后……变化""该记录支持……" |
| 因果归因 | 严格受控、预算一致且能排除替代解释 | "由……带来""主要归因于" |

完整模型之间的差异通常只支持一致性解释。即使某个模型独有可靠性门控，也不能仅凭总体排名写"性能提升来自可靠性门控"。应先写该门控如何处理缺失或陈旧条件，再引用组件记录；若训练预算、随机性或其他组件同时变化，结论保持在"当前记录支持"的层级。

## 7. 基线解释的四个轴

解释异构基线差异时，按以下四个轴检查，不按模型逐个编故事：

1. **输入信息**：是否接收低频条件、掩码、年龄或其他状态变量。
2. **时序与变量表征**：是否显式保持时间顺序、完整历史、局部卷积或变量间耦合。
3. **训练目标**：是否对状态重叠、风险尾、缺失路径或不确定性施加约束。
4. **数据支撑**：拟合样本量、尾部稀疏性和目标分布是否与模型容量匹配。

同一段最多解释一至两个轴。机制必须是正文方法定义、可靠引用或模型公开结构中的事实。不要因单次测试排名断言某类模型"天然不适用"，也不要把模型发表时间、参数量或复杂度直接等同于性能。

## 8. 正反例

### 不合格：数值复述

```text
方法 A 的 RMSE 为 0.17，方法 B 为 0.19，方法 C 为 0.20，因此方法 A 最好。
```

问题：没有最接近基线的差值、误差位置和方法设计解释。

### 不合格：无证据归因

```text
方法 A 的性能提升主要来自门控、注意力、尾部损失和不确定性建模。
```

问题：完整设置比较不能区分四个组件，列出更多机制不会提高解释可信度。

### 推荐：事实到解释

```text
方法 A 的总体 RMSE 较次优方法 B 低 10.2%，高风险尾 RMSE 低 24.5%，但低风险尾由 B 取得最低值。轨迹显示两者差异主要集中在高值峰附近，箱线分布进一步表明 A 的误差主体和上侧尾部均较小。A 显式接收条件可用性与年龄，并在条件不可用时保留单源路径；该结构事实与高值及过渡窗口的误差变化一致。后续去除条件输入的记录使总体 RMSE 增大，因此当前证据支持条件信息与性能差异的关联，但不能把全部增益归于单一门控组件。
```

## 9. 本地结构对照与取舍

四篇本地参考论文反复采用"曲线现象 -> 指标统计 -> 方法机理"的顺序，可作为段落组织参照：

- 《水泥粉磨过程关键指标预测模型与运行优化算法研究》3.4.5：先比较单源与融合轨迹，再用误差表量化多源信息的差异。
- 《水泥烧成系统多指标预测模型与决策算法研究》3.5：按高/低频输入、PCA 处理和联合预测形成分层对照，再用 RMSE 与 MAE 收束。
- 《水泥熟料煅烧过程数据增强及质量预测模型研究》6.5.2：先定位平稳区、波动区和极值区的误差，再分指标比较增强设置。
- 《复杂非平稳工业过程异常监测与诊断》3.4：将统计量超限位置、误识别率和组件移除记录对应到不同监测能力。

采用其"由图到数、由数到机制"的组织方式，但不沿用由单次排名直接推出组件因果、普适性或工程收益的写法。所有机制结论仍按第 6 节的证据阶梯降级或关闭。
