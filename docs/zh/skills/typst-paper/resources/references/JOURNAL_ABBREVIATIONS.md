# 期刊名称缩写

本参考提供了参考书目中期刊名称标准化的 ISO 4 缩写规则和常见示例。

## ISO 4 规则

1. 单字标题绝不会缩写（例如“Nature”、“Science”、“Lancet”）
2. 每个重要单词均使用 ISSN LTWA（标题词缩写列表）独立缩写
3. 介词、冠词和连词除非是第一个词，否则被省略
4. 缩写词以句点结尾
