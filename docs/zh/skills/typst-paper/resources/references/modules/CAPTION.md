# 图形和表格标题生成指南 (Typst)

当用户请求在 Typst 文档中生成或优化图形或表格标题时，请严格遵循这些指南，以确保符合顶级出版标准（例如 NeurIPS、ICLR、ICML）。

## 1. 标题/句子大小写规则

- 如果输出是**名词性短语**：使用**标题大小写**（所有主要单词的第一个字母大写，末尾没有句号）。
- 如果输出是一个**完整的句子（完整句子）**：使用**句子大小写**（仅第一个单词的第一个字母和专有名词大写，必须以句点结尾）。

## 2. 写作风格和极简主义

- **直接方法**：消除冗余前缀，例如“该图显示”或“该图说明”。开始直接描述内容（例如，“...的架构”、“...的性能比较”、“...的可视化”）。
- **表格**：使用标准表达方式，例如“比较”、“消融研究”或“结果”。避免使用“展示”或“描述”等华丽词，而使用“展示”、“比较”或“呈现”。
- **去除“AI风味”**：保持词汇精确、简单。避免使用过于复杂或晦涩的词语。

## 3. 格式和输出限制

- **输出纯文本**：不要在前面添加“图 1：”或“表 1：”。仅输出标题文本本身。
- **打字员兼容性**：
  - Typst 不使用反斜杠`\`对于常见的字符，例如`%`或者`&`和 LaTeX 一样。在适当的地方输出标准纯文本。
  - 完全保留数学公式（保留 `$` 符号）。
- 仅输出英文文本。除非用户要求，否则不要输出任何额外的对话框或解释。

## 4. 执行示例

**用户输入：**
“帮我写一段表达：本表了我们在ImageNet数据集上的消融实验结果，主要对比了不同深度下的精度展示。”

**代理回复：**
```typst
// Caption [Severity: Minor] [Priority: P2]: Translated and optimized caption
// Original: 本表展示了我们在ImageNet数据集上的消融实验结果，主要对比了不同深度下的精度。
// Revised: Ablation study on the ImageNet dataset comparing accuracies at different depths.
```
