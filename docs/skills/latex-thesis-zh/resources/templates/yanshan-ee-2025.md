# Yanshan University School of Electrical Engineering graduate thesis format checklist (2025)

> This file transcribes the normative clauses of the 2025 college format checklist. It is not the 2024 graduate-school specification (see `yanshan.md`).
> 111 statuses are not 111 compliant items. `manual` and `llm` need human review. `module:` only prints a follow-up command. It does not run that command, and it does not mark a compound item passed.
> `script:third_person` reports only word-level candidates. The result stays NEEDS-LLM. It does not prove that the whole thesis is third person.
> This checklist does not add `TEMPLATE_THRESHOLDS`. Abstract-length and reference-count thresholds from the graduate-school template must not decide these items.

## Specification

- **Name**: 2025 format checklist for graduate theses, School of Electrical Engineering, Yanshan University
- **Relation to the graduate-school template**: `yanshan.md` is the 2024 graduate-school snapshot. This file is the college checklist. The two coexist.
- **Degree**: Items 74 and 90 apply only to `博士` (a master's run keeps the row and sets SKIP). Items 10, 47, 66, and 92 are `通用`. Doctor-only sentences stay in the requirement text. A master's run does not SKIP those items.
- **Acceptance boundary**: Except `script:third_person` on item 88, this checklist has no automatic PASS that covers a whole item. MODULE, MANUAL, and NEEDS-LLM are not acceptance.

## How to obtain it

- Use the checklist published by the college. This file invents no numeric exemption, buffer, or school tolerance.
- Final-check command: `uv run python $SKILL_DIR/scripts/check_spec.py main.tex --template yanshan-ee-2025 --degree doctor --year 2026`
- The MODULE hint for item 42 may include `--author-cite`. That switch is an author-writing convention. It is not the text of college item 42.
