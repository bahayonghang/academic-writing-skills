# 三线表指南（GB/T 中文学位论文）

本指南说明中文学位论文中常见的三线表（`booktabs`）惯例。题注语言、编号、字体和特殊
表格形式以当前学校规范与实际 class 为准。

## 三线表标准

三线表恰好包含三条水平线，且**不含竖线**：

1. **顶线**（`\toprule`）：位于列标题上方
2. **中线**（`\midrule`）：位于列标题下方、数据行上方
3. **底线**（`\bottomrule`）：位于最后一行数据下方

### 反例（必须标记）

- 使用竖线（列格式中的 `|`、`\vline`）
- 使用内部水平线（数据行之间的 `\hline` 或 `\cline`）
- 使用 `\hline` 代替 booktabs 命令
- 导言区缺少 `\usepackage{booktabs}`

### 最小正确示例

```latex
\begin{table}[htbp]
  \caption{不同模型的准确率比较（\%）}
  \label{tab:accuracy}
  \centering
  \begin{tabular}{lSSS}
    \toprule
    模型 & {精确率} & {召回率} & {F1值} \\
    \midrule
    基线模型   & 85.3 & 82.1 & 83.7 \\
    本文方法   & \textbf{91.2} & \textbf{89.5} & \textbf{90.3} \\
    \bottomrule
  \end{tabular}
\end{table}
```

## 表题与编号（GB/T）

- **表题位置**：表格上方
- **编号格式**：“表 3-1”或“表3.1”（按章编号），宋体五号
- **标签**：紧跟表题之后（`\label{tab:...}`）
- **表注**：位于表格下方，以“注：”（中文）或“Note.”（英文）开头

检查脚本接受真实的 `\caption` 或 `\bicaption`，包括命令后的空白、换行和可选短标题。
注释中的题注、`\captionsetup` 或名称相似的自定义命令不能满足题注存在性检查。这一语法
检查不证明题注措辞或模板渲染正确。应使用实际 class 要求的题注形式，不统一替换各校宏。

## 小数点对齐

使用 `siunitx` 宏包的 `S` 列类型按小数点对齐数字：

```latex
\usepackage{siunitx}
\sisetup{detect-weight, mode=text}
```

无法使用 `siunitx` 时，用 `r` 右对齐数值列。

## 统计显著性标记

| 符号 | 含义 |
|--------|---------|
| `*`    | p < 0.05 |
| `**`   | p < 0.01 |
| `***`  | p < 0.001 |

显著性标记紧跟数值，例如 `91.2***`。

## 数值精度规则

| 数据类型 | 精度 | 示例 |
|-----------|-----------|---------|
| 百分比 | 1 位小数 | 85.3% |
| 均值 +/- 标准差 | 2 位小数 | 3.14 +/- 0.05 |
| p 值 | 3 位有效数字 | 0.003 |
| 大数计数 | 无小数 | 1,024 |

同一列内的精度必须一致。

## 长表间距

只有编译页显示 `\LTpost` 或相关 longtable 间距确实造成局部留白时，才修改长表间距。
在受影响的 `longtable` 外局部设置最小改动，例如：

```latex
{
  \setlength{\LTpost}{0pt}
  \begin{longtable}{...}
    ...
  \end{longtable}
}
```

不能从一个页面症状推导出要修改全局 class 或所有长表。重新编译并检查表格末尾、后续段落、
分页、重复表头和相邻页。如果留白由其他机制产生，则保持 `\LTpost` 不变。

## 避免表格二次缩放

表格已有固定列宽时，先检查 `\resizebox`、额外的小字号命令或其他外层缩放是否又缩小一次。
只移除造成文字不可读的冗余层，再在编译页检查宽度溢出、列换行、表线对齐和可读性。宽表本身
不授权把所有表格缩放到 `\textwidth` 或修改 class。

## 加粗最优值

在对比表中，加粗每列的最优值。方向不明确时添加指标：
- `↑` 越高越好
- `↓` 越低越好

## Word 兼容说明

以 .docx 提交学位论文时：
1. 在 Word 中创建标准表格
2. 全选 -> 边框 -> 无框线
3. 添加顶边框、标题行下边框和表格底边框
4. 得到与 booktabs 风格一致的三线表

## 编译页验收

使用现有 `compile.py` wrapper，并传入论文实际入口文件和 recipe。脚本检查通过或生成 PDF
都不等于视觉验收完成。编译后实际查看受影响表格及相邻页。如果没有查看渲染页面，将视觉
结果标为 `missing evidence`。
