PRACTICAL APPLICATIONS AND RESOURCES` → `IX. FUTURE DIRECTIONS` → `X. CONCLUSION`。前置 `(Survey Paper)`、`Abstract—` 与 `Index Terms—`。无独立 Related Work 节。`related_work=inlined`（Introduction 中段 `Related Surveys.` 评 Wang / Ye / Jin / Rahmani，并用 Table I 对比）。Introduction 末有节序路标，指向 Section II–IX。综述结构：定义 → 分类法 → 四任务 → 应用 → 未来方向 → 结论。
