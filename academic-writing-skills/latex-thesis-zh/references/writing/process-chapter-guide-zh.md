# 第二章（过程分析章）写作专章指南

面向工业/过程背景中文博士学位论文的**第二章**写作与诊断。此处特指"工艺流程分析 +
全文方法架构"章式（下称**过程分析章**）：第二章先给工艺/过程分析，推出建模/控制难点，
再落到统摄后续各章的总体方法框架。诊断入口：

```bash
uv run python $SKILL_DIR/scripts/analyze_logic.py main.tex --process-chapter
uv run python $SKILL_DIR/scripts/check_format.py main.tex
```

> 本文所有阈值（篇幅、节数、引言字数、工艺特性词表）为 5 篇流程工业博士论文与公开目录
> 调研的**学科惯例**口径（出处见各节），**以导师与本校研究生院最新规范为准**；命令行
> 阈值均可覆盖。参考论文以过程域指代（固废焚烧、水泥烧成、水泥熟料煅烧、水泥粉磨、
> 锌冶炼浸出），页码为解密 PDF 物理页。

## 一、章式判别（先判别，再套规则）

第二章有三种主流写法，判据不同、规则不同，**不可混用**。判别之后各走各的规则：

| 特征 | 过程分析章式（本指南） | 方法章式 | 拆两章变体 |
| --- | --- | --- | --- |
| 决定性判据 | 工业/过程对象**贯穿全文** | 方法学为主，对象仅后期出现 | 工艺与方案分列两章 |
| 第二章内容 | 工艺分析 + 难点 + 全文方法框架 | 直接写方法/模型/实验 | 第二章纯工艺，第三章总体方案 |
| 综述落位 | 综述在绪论承担，不再设综述章 | 同左 | 同左 |
| 走哪套规则 | 本指南 + `--process-chapter` | [method-chapter-guide-zh.md](method-chapter-guide-zh.md) + experiment `--per-chapter` | 工艺章走本指南，方案章走框架规范 |

**判据说明**：工业对象是否"贯穿全文"是决定性判据——第二章之后每章都围绕同一工业过程
（建模/预测/控制/优化多章展开）即过程分析章式；应用对象仅在最后一两章作验证出现，则是
方法章式，按方法章专章指南处理，本指南不适用。脚本 `--process-chapter` 会先做**章式
预判（双信号）**：章/节标题须同时命中过程信号（工艺/流程/过程分析/变量分析）与框架信号
（总体框架/技术框架/研究方案）才套用 P-\* 检查，否则只输出一条 Info 提示"若为方法+实验
章式请走方法章规则"（方法章常见的"问题描述/总体框架"节名不会单独触发）。

## 二、推荐骨架与顺序不变式

5 篇参考论文章式 5/5 一致，推荐骨架：

```text
2.1 引言（或章标题后导语）
2.2 工艺/过程分析（常并入变量选取）
2.3 变量/数据〔可选，3/5 论文在此建立统一数据契约〕
2.4 难点/关键问题
2.5 总体框架/方案
2.6 本章小结
```

**顺序不变式**（P-ORDER 基础）：`工艺分析 →（变量/数据）→ 难点/问题 → 总体框架 → 小结`。
**难点节必须在框架节之前**——框架是对难点的结构化回应，顺序颠倒（框架先于难点）触发
P-ORDER（Minor）。

参考论文骨架对照（节标题已按过程域归并）：

| 论文 | 直属节 | 骨架要点 | 篇幅 |
| --- | --- | --- | --- |
| 固废焚烧 | 5 | 引言 / 过程分析 / 智能预测与优化控制架构 / 重要性与难点 / 小结 | PDF p30–41 |
| 水泥烧成 | 6 | 引言 / 系统简介 / 变量选择及特征 / 问题描述 / 框架设计 / 小结 | PDF p27–44 |
| 水泥熟料煅烧 | 5 | 引言 / 过程描述 / 关键问题 / 预测方案 / 小结 | PDF p28–37 |
| 水泥粉磨 | 7 | 引言 / 工艺分析及变量选取 / 数据预处理 / 优化问题 / 优化框架 / 优化模型 / 小结 | PDF p35–52 |
| 锌冶炼浸出 | 4 | 工艺分析 / 难点分析 / 总体框架 / 小结（**章后导语，无编号引言节**） | PDF p30–40 |

章标题模式：`〈对象过程〉+〈工艺分析/过程描述/问题描述〉(+〈框架/方案〉)`，常见双联式
（如"水泥粉磨过程工艺分析与运行优化框架"）。

## 三、工艺流程描述规范（漏斗式）

组织 = **漏斗式四层**（固废焚烧与锌冶炼最典型）：

1. **全流程定位**：先给全流程图，交代工序全景（锌冶炼图2-1 湿法炼锌全流程）；
2. **核心工序聚焦**：放大到研究对象所在工序（锌冶炼图2-2 中性浸出 5 槽级联）；
3. **设备/机理**：设备编号 + 化学反应方程/机理（固废焚烧图2-1 含 33 编号设备、Arrhenius
   式与热化学方程；锌冶炼给出浸出反应式）；
4. **关键变量**：收敛到被控量/关键变量（固废焚烧 → 烟气含氧量 + 6 影响因素；锌冶炼 →
   3# 槽出口 pH，收敛到"调 1#/2# 废酸流量稳 3# pH"；水泥粉磨 → 比表面积/单位电耗 + MV/CV 划分）。

三条硬规范：

- **工艺流程图必备**（P-FLOW 基础）：5/5 参考论文工艺节均有工艺流程图（含设备编号或工序框）。
  工艺分析节内无 `\ref{fig:...}` 流程图引用触发 **P-FLOW（Major）**。
- **深度以"能支撑难点推导"为度**：可写到机理/反应方程层，但须服务于后面"为什么难建模/
  难控制"，不是工艺教科书式罗列。
- **必须落到变量/被控量**：工艺分析终点是锁定研究对象并给出变量选取，为后续各章建立
  **统一数据契约**（3/5 论文在第二章设变量表/角色划分，如水泥粉磨用表列五水泥品种比表面积
  范围、划分 MV/CV）。

## 四、难点推导链模板

推导链 = **工艺特性词 →（导致/使得/难以/造成/致使/加大…难度）→ 建模/控制难点**。
5/5 论文都是显式因果句，不是罗列特性名词。P-DERIVE 检查：难点节缺特性词 → **Major**；
有特性词但无因果连接词 → **Minor**。

**工艺特性词表**（可配置，脚本 `PROCESS_TRAIT_RE_ZH`）：强非线性、大滞后/大惯性/时滞、
强耦合、时变、多工况、多速率、多源异构、波动、不确定/扰动、长尾、不平衡。

推导模式（**示意，非逐字引用**，取自参考论文难点节归纳）：

| 论文 | 推导模式示意 | 出现的特性词 |
| --- | --- | --- |
| 固废焚烧 | 成分复杂、热值波动、工况变化 → 强非线性 → 精确建模困难 | 强非线性、大惯性、强耦合、不确定 |
| 锌冶炼浸出 | 液固多相 + 多槽级联耦合 + 强非线性 → pH 难估计；时延特性 → 时滞不一致 → 操作参数难协调 | 级联耦合、强非线性、时延/大滞后、多工况 |
| 水泥烧成 | 数据维度高、采集频率不同 → 变量冗余；煤耗电耗时间尺度不一致 | 高维、多采样频率、时变延迟 |
| 水泥粉磨 | 多源异构 + 多时间尺度不平衡 → 建模难；停留时延 + 分级回流 → 时变时延高非线性 | 多源异构、多时间尺度不平衡、时变时延、强耦合 |

**难点条数 ≈ 后续方法章数**：难点是"问题"，后续各方法章逐一回应（固废焚烧 3 难点、锌冶炼
3 难点、水泥烧成 3 子问题、水泥粉磨多难点，分别对应第 3 章起的多个方法章）。**但难点↔章号在
难点节内部通常不点名**——难点节只做"问题-特性"归纳，章号映射留给绪论 1.3 与框架节。

**正反例**（P-DERIVE 判据）：

| 写法 | 判定 |
| --- | --- |
| "过程成分复杂、热值波动、工况频繁切换，**导致**被控对象呈强非线性、大惯性，**使得**基于机理的精确建模难以实现。" | 通过（特性词 + 因果连接 + 建模难点，推导链完整） |
| "本过程具有强非线性、大滞后、多变量耦合等特点。"（仅罗列特性词） | P-DERIVE Minor（有词无因果，应补"导致…难以…"句） |
| "本过程建模较为困难，需要先进方法。"（无特性词、无推导） | P-DERIVE Major（缺特性词，难点未从工艺推出） |

## 五、问题数学形式化规范

难点定性归纳后，问题形式化节（或难点节末）给出数学表述，为后续方法章建立统一符号：

- **符号定义**：被控量/状态/输入/扰动符号一次性定义（如 pH、含氧量、f-CaO 记号），后续各章沿用；
- **映射/优化式**：把研究对象写成映射 `y = f(x)` 或优化式 `min J s.t. 约束`（水泥粉磨的
  多目标优化模型即独立形式化节）；
- **子问题-章节对应**：多子问题时列子问题（如质量预测 / 能耗预测 / 决策优化三子问题 →
  第 3 / 4 / 5 章）。

篇幅弹性：问题形式化可并入难点节，也可独立成节——独立成节会使直属节增至 6~7（属正常，
见第八节）。

## 六、总体框架图规范（P-FRAME 核心）

框架节是"难点 → 框架"闭合的落点，须**显式回指难点**。范句（某水泥烧成系统博士论文
2.5 节开头，PDF p43）："根据前节工艺特征分析及现存问题难点，采取相应解决方案。"

三条规范：

1. **框架图必备**（P-FRAME 基础）：5/5 论文有总体框架图。框架节内无 `\ref{fig:...}`
   框架图引用触发 **P-FRAME（Major）**。
2. **分层组织 + 数据流箭头 + 覆盖方法模块**：框架图按"数据/输入 → 方法模块 → 输出"分层，
   模块间用数据流箭头连接（锌冶炼图2-4 四层：输入 → 估计 → 识别 → 控制；水泥烧成整体框架图：
   数据平台 → 两预测模型 → 双循环耦合决策）。框架节须覆盖 **≥2 个方法模块名或后续章指向**，
   否则"框架空泛"触发 **P-FRAME（Major）**。
3. **章号映射（推荐加强项）**：**推荐**在框架图或接口表中显式标注"第 X 章"章号映射
   （如接口表列出各研究内容对应的第 3 / 4 / 5 / 6 章），更规范、便于盲审与答辩定位。**缺失
   只触发 Info（不硬拦）**——参考论文 **5/5**（固废焚烧、水泥烧成、水泥熟料、水泥粉磨、
   锌冶炼）框架节均不写章号、只用方法模块名组织数据流，"第 X 章"章号映射按惯例统一放在
   绪论"研究内容与组织结构"节（图1-1/图1-3 类章节结构图），后续各章引言以"根据第 2 章…"
   反向承接。两种写法均合规，**显式章号映射为本指南推荐的加强写法**。

图题规范：框架图图题应含"总体框架/技术路线/数据流"等定位词，与图内分层一致；图题在图
下方（详见 [`../modules/format.md`](../modules/format.md)）。

**工程/系统实现章的地位**：有独立工程应用章的论文，框架图**可含可不含**该章——锌冶炼
将工程应用章排除在框架图外（只入绪论 1.3 章节树），亦有论文以接口表纳入；脚本对工程章
缺席映射只出 Info，不作 Major。

**正反例**（P-FRAME 判据）：

| 写法 | 判定 |
| --- | --- |
| 框架节含 `\ref{fig:framework}` 分层数据流图，正文覆盖"软测量/工况识别/优化控制"≥2 模块，开头回指难点 | 通过（有图 + ≥2 模块 + 难点闭合） |
| 框架节仅一段文字"本文提出一套完整方案"，无图、无模块分解 | P-FRAME Major（缺框架图 + 框架空泛） |
| 框架图与模块齐备，但未标注各模块对应"第 X 章" | P-FRAME Info（推荐补章号映射；不写亦合规） |

## 七、绪论—第二章分工表与查重清单

绪论"研究内容与组织结构"（1.3/1.4/1.5）与第二章总体框架节分工明确、**内容不重复**
（锌冶炼最清晰）：

| 维度 | 绪论 1.3/1.4/1.5 | 第二章总体框架节 |
| --- | --- | --- |
| 面向 | 全文导航 | 问题求解 |
| 内容 | 逐章说做什么 + 递进关系 | 方法模块间技术衔接与数据流 |
| 覆盖范围 | 全部章（含背景/工程/总结） | 只覆盖核心方法章 |
| 配图 | 章节结构树图（如七章结构树） | 数据流/模块框架图 |
| 立足点 | 研究动机 | 2.1/2.2 工艺与难点 |

**查重清单**（防绪论—第二章重复，LLM 判断，脚本不硬检）：

- [ ] 第二章框架节**不逐章复述**绪论已写的"章节安排/各章做什么"；
- [ ] 绪论章节树立足"结构安排"（第 N 章做什么），框架节立足"技术数据流"（模块如何组成闭环）；
- [ ] 二者重叠仅方法模块名——框图性质（章节树 vs 数据流图）、粒度、立足点不同，属**合规
  分工，非重复**。

## 八、篇幅与节数弹性口径

| 口径 | 默认值 | 出处 |
| --- | --- | --- |
| 第二章篇幅 | 10~18 页（约占全文 8%~13%），显著短于方法章 | 5 篇参考论文实测 |
| 直属节数 | 4~7 节（含引言与小结），中位数 5~6 | 同上 |
| 引言篇幅 | 编号引言节默认 ≤1600 字；章后导语约 190~600 字 | 同上 |

节数弹性：过程分析章常见 4~7 直属节，**超 5 节不机械报警**（水泥粉磨 7 节，因问题形式化
独立成节属正常）。超 5 节时优先检查可合并的变量/数据节——如把"数据预处理""变量选取"
"问题定义"合并为"问题描述与建模基础"。详见 [`structure-guide.md`](structure-guide.md)
的"直属小节数量"一节。

## 九、"小论文拼接感"表述规范

工业博士大论文常由若干已发表小论文整合而成，但**正文不得暴露"小论文拼接"痕迹**
（盲审风险）。P-PAPER 检查章内可见正文命中"源论文/小论文/N 篇论文"表述 → **Minor**。

| 暴露写法（应改） | 建议表述 |
| --- | --- |
| "三篇源论文所对应的三个核心问题" | "三个核心问题 / 三项研究内容" |
| "三篇源论文在大论文中的接口关系" | "三项研究内容之间的技术衔接关系" |
| "本文由 N 篇学术论文整合而成" | 删除，或改述为研究内容的递进关系 |

注意：连"为避免小论文拼接感"这类**元表述本身**也不应出现在正文（它同样暴露拼接意图）。
`\cite{}` 与注释内的文字不计入 P-PAPER。

## 十、两种引言形态说明

第二章引言两形态**均合规**（参考论文 4:1 分布），R2 检查器适配两者，不强推其一：

| 形态 | 论文 | 篇幅 | 特点 |
| --- | --- | --- | --- |
| 编号"2.1 引言"节 | 固废焚烧/水泥烧成/水泥熟料煅烧/水泥粉磨（4/5） | 约 600~1500 字 | `\chapter` 后直接 `\section{引言}`，编号 2.1 |
| 章标题后不编号导语 | 锌冶炼浸出（1/5） | 约 190~600 字 | 章标题后直入导语，再进 2.1 工艺分析 |

**关键：第二章引言是"本章概述式"，不是"承上启下式"。** 它预告本章各节（固废焚烧引言段 2
预告"过程描述 → 架构 → 重要性难点"；锌冶炼用"首先/接着/然后/最后"串四节），承接对象是
**绪论已建立的研究背景**，而非前一章的结论。故第二章引言：

- **只需**：预告本章各节 + 篇幅适度；
- **不要求**：显式写"第 1 章"承接前章结论——这是第 3 章起正文方法章的承上启下要求
  （见 [`thesis-writing-guide.md`](thesis-writing-guide.md) 的"正文章引言"一节）。

R2 检查器据此对第 2 章只查"预告各节 + 篇幅"，不报"缺承上衔接"；承上启下两段式从第 3 章
起适用。两形态的本章小结按节顺序收束、与引言/导语近镜像（列点与单段两种均可，见
[`thesis-writing-guide.md`](thesis-writing-guide.md) 的"正文章末小结"一节）。
