# 期刊分级策略

投稿信的三层框架策略。每个模板都引用其层；以下写作规则适用于每一层，并在不矛盾的情况下优先于特定场地的风格。

## 顶级期刊

自然家族、科学家族、细胞出版社。

- **开场**：以科学进步为主导，而不是主题。第一句话必须说明由于这项工作该领域发生了什么变化。
- **新颖的框架**：范式转变水平。 “我们解决了 X 和 Y 之间长期存在的差异”胜过“我们为 X 提出了一种新方法”。
- **字数预算**：≤350字。编辑们预计会出现紧张情况。
- **重要性阈值**：必须对广大科学受众而不是子领域重要。如果只对某个子领域重要，请转至二级姊妹期刊。
- **定量锚**：必需。至少有一个标题编号可追溯到论文稿件。
- **比较框架**：引用来自_同一期刊_的最近一篇论文，该论文直接扩展或矛盾。编辑们注意到了这一点，这标志着对场地的真实阅读。
- **避免陈词滥调**：永远不要以“我们很高兴提交......”作为开头——标记为省力。

## 期刊中期

IEEE Transactions、ACM 期刊、Springer LNCS / LNAI、PLOS 系列、Elsevier 专业期刊。

- **开场白**：清楚地阐述了方法论的贡献。 “我们引入了 X，一种通过 Z 处理 Y 的算法。”
- **新颖的框架**：以贡献为主导。列举3-4个具体贡献。
- **字数预算**：400-500字。为方法论背景提供更多空间。
- **重要性阈值**：场地专业领域内的事项。影响更广泛的框架是可选的；需要深入的方法论框架。
- **定量锚**：必需，具有明确的比较器命名（基线+数据集+协议）。
- **比较框架**：引用同一期刊的一篇或两篇近期论文来定位作品。
- **会议延期**：如果延期之前的会议论文，请披露地点和新内容的百分比（IEEE / ACM 典型条：≥30%）。

## 会议

NeurIPS、ICML、CVPR、ICCV、ECCV、ACL、EMNLP、AAAI、IJCAI、KDD、WWW。

> **主要的 ML/视觉会议不使用投稿信。** NeurIPS、ICML、
> CVPR、ICLR 和同行通过结构化收集提交元数据
> OpenReview / CMT 表格（作者列表、摘要、清单），不是自由格式
> 信。 Treat the `neurips` / `icml` / `cvpr` templates as applicable only
> 当研讨会、数据集和基准跟踪或明确的特殊调用时
> 请求一封信。对于主轨道，将用户重定向到提交
> 形式而不是生成一封信。

- **开场**：用一句话陈述技术贡献。
- **新颖的框架**：以贡献为主导，简洁。
- **字数预算**：≤400字。会议审稿人不会仔细阅读较长的信件。
- **显着性阈值**：为特定子领域做出贡献，具有强有力的经验或理论证据。
- **定量锚**：必需，具有数据集和分割命名。
- **信函本身没有更广泛影响的言论**：这属于论文稿件专门的更广泛影响部分（许多机器学习场所现在都需要它）。
- **双重提交披露**：会议严格；始终确认合规性。
- **匿名**：对于双盲场地，投稿信通常不会匿名，但不应泄露提交系统中已有的识别信息。

## 当场地不符合任何级别时

回落至 `templates/generic.md`。手动选择最接近的层进行框架指导。如果不确定不同级别之间的关系，请选择更保守的（期刊中）框架——夸大其词比低估编辑信任更糟糕。

## 编辑实践快照（2025-26）

投稿信是案头审查的第一步（大批量期刊案头拒绝 50-80%），因此这些特定地点的现实很重要：

- **人工智能使用披露现在是顶层投稿信的要求。** ICMJE（2026 年 1 月，第五节）要求在投稿信和论文稿件中描述生成式人工智能的使用； Science/AAAS、NEJM 和 APS 明确要求披露投稿信。 IEEE（致谢）、ACM（工作内）和 Elsevier/Springer（方法/专用声明）将其放在论文稿件中。未公开的人工智能使用可被视为不当行为。
- **自然系列投稿信是保密渠道**——不会向审稿人展示。将它们用于竞争利益、正在考虑的相关工作或特定的编辑处理请求；不要重述摘要。对于 Nature 旗舰来说，这封信是可选的。
- **IEEE 是双模态的**：_IEEE 会议记录_ 要求提供一份详细的投稿信（缺失的可以退回）； _IEEE TIM_ 明确表示不要提交，除非有具体问题需要提出。请务必检查目标标题的作者中心。
- **作者建议的审稿人正在减少**（Cureus 在 2025 年删除了该选项；PLOS ONE 更早删除了它；Wiley/IOP 现在需要独立验证）。默认情况下不要生成建议审稿人段落 - 仅当目标场所的提交流程要求时才包含它。
- **被拒绝并重新提交的稿件**：某些场所（Wiley _Small_、IEEE/ACM ToN）要求投稿信说明之前提交的内容并总结更改。
- **双盲场所**：列出已经看过论文稿件的人（以保护盲人），并披露与作者自己之前的工作或共享数据集的重叠部分。
- **施普林格·自然固定措辞**：“我们确认该论文稿件尚未在其他地方发表，也没有被其他期刊考虑。所有作者均已批准该论文稿件并同意将其提交给[期刊]。”
- **通用模板信件是一个负面信号**：每周筛选 50 多封信件的编辑会立即发现群发邮件的措辞。特异性（称为范围维度，最近的同场论文，具体的标题结果）是读起来用心写的。
