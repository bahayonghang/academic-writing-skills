# 技能总览

六个公开技能覆盖四类职责：源码级写作、审稿式评估、文献库检索和投稿包装。

| 技能 | 主要材料 | 第一条有用动作 | 入口 |
| --- | --- | --- | --- |
| `cover-letter` | LaTeX 论文与可选投稿信草稿 | 生成投稿信或做证据对齐 | [打开](/zh/skills/cover-letter/) |
| `paper-audit` | `.tex`、`.typ` 或 `.pdf` 论文 | 选择 quick-audit、deep-review 或 gate | [打开](/zh/skills/paper-audit/) |
| `latex-paper-en` | 英文 `.tex` 论文 | 编译后再做定向检查 | [打开](/zh/skills/latex-paper-en/) |
| `latex-thesis-zh` | 中文学位论文 `.tex` 工程 | 先映射结构再做专项检查 | [打开](/zh/skills/latex-thesis-zh/) |
| `typst-paper` | `.typ` 论文 | 编译/导出后再做定向检查 | [打开](/zh/skills/typst-paper/) |
| `bib-search-citation` | BibTeX/BibLaTeX 文献库 | 运行紧凑查询 | [打开](/zh/skills/bib-search-citation/) |

## 概览结构

每个技能概览统一提供：

1. 适用与不适用边界；
2. 模块或模式路由；
3. 最小输入；
4. 首条命令和脚本入口；
5. 输出产物；
6. 公开资源分组；
7. 常见请求与相邻技能交接。

## 公开资源

每个技能都使用一致的资源目录：

- `references/`：详细规则和模块指南；
- `templates/`：期刊、报告或格式快照；
- `examples/`：完整的请求到命令或输出示例；
- `agents/`：技能明确公开的人类可读 reviewer 或工作流契约。

侧栏从文件系统发现这些页面。只打开当前模块或模式路由到的资源。

## 快速路由

- 写给编辑的信：`cover-letter`。
- 审稿报告、阻塞项分流或 PASS/FAIL 判断：`paper-audit`。
- 源码编译、格式、章节、表格或引用工作：对应写作技能。
- 本地文献库检索或引用片段提取：`bib-search-citation`。
