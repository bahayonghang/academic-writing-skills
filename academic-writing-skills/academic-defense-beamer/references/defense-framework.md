# 答辩稿框架

本文件规定博士学位论文答辩稿的页序、章角色和各章角色的页序列。各页角色的页数见 [时长预算](time-budget.md)，版式见 [版式目录](slide-layouts.md)。

框架来源为一份 94 页的博士预答辩 pptx（16:9）。本文件只记录它的结构与页型。该 pptx 的作者、论文题目和正文内容不进入本技能的任何文件。

## 全稿页序

1. 封面（`cover`）。
2. 总目录（`toc`）：列出全部章，不加粗任何章，调用 `\DefenseTocFrame{0}`。
3. 第 1 章各页。
4. 第 k 章（k = 2..n）：先放章前目录（`toc`），加粗第 k 章，调用 `\DefenseTocFrame{k}`；再放第 k 章各页。
5. 致谢页（`thanks`）。

defense 阶段在结论章的展望页之后加成果页（`achievements`）。

备用页（`backup`）放在致谢页之后。页序检查、内容页计数和时长预算都不计备用页。

参考框架的总目录加粗第 1 章。本技能的总目录不加粗任何章，第 1 章前也不另设章前目录。

## 章角色

| 角色          | 含义                                                                 | 识别提示                                                                        |
| ------------- | -------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| `intro`       | 绪论章                                                               | 第 1 章，或章题含「绪论」「引言」                                               |
| `conclusion`  | 结论章                                                               | 章题含「结论」或「总结与展望」                                                  |
| `application` | 系统或平台的设计与应用章                                             | 章题含「系统」或「平台」，并含「设计」「应用」「实现」之一                      |
| `foundation`  | 理论基础与问题框架章：给出机理、问题形式化与总体框架，无独立方法实验 | 不是第 1 章或最后一章，且章内各级节题都不含「实验」「案例」「结果分析」「仿真」 |
| `research`    | 研究章：提出方法，并用实验验证                                       | 其余章                                                                          |

识别提示按表中行序判定，先命中的行生效。提取脚本把判定结果写为角色建议。规划文件中的章角色是最终值，用户可以修改。

## 各章角色的页序列

| 章角色        | 页角色序列                                                        | 40 分钟默认页数                          |
| ------------- | ----------------------------------------------------------------- | ---------------------------------------- |
| `intro`       | `background` → `status` → `challenges` → `organization`           | 2、2、1、1                               |
| `foundation`  | `foundation` × n                                                  | 3                                        |
| `research`    | `intro` → `problem` → `method` × m → `experiment` × e → `summary` | 1、1、m、e、1；三个研究章时 m = 3、e = 4 |
| `application` | `intro` → `architecture` → `application` × n                      | 1、1、2                                  |
| `conclusion`  | `innovation` → `outlook`；defense 阶段再加 `achievements`         | 1、1；defense 阶段另加 1                 |

其他时长与章结构下的页数按 [时长预算](time-budget.md) 的公式计算。

## 页角色内容

| 页角色            | 内容                                                                      | 默认版式                               |
| ----------------- | ------------------------------------------------------------------------- | -------------------------------------- |
| `background`      | 研究背景与意义：要点或配图，加一句结论句                                  | `bullets` 或 `figure-bullets`          |
| `status`          | 研究现状：文献统计图或综述图，加一段归纳；末页引出本文的研究章            | `figure` 或 `bullets`                  |
| `challenges`      | 现存问题与挑战：每个研究章一张问题卡片，按章序排列，关键词强调            | `cards`                                |
| `organization`    | 研究内容与章节安排：论文组织结构图，加理论、方法、应用三层说明            | `figure`                               |
| `foundation`      | 基础章：机理图、问题形式化与总体框架                                      | `equations-figure` 或 `figure-bullets` |
| `intro`（研究章） | 引言：小节条「研究内容 i：章题」，技术路线图，一段「本章首先…其次…最后…」 | `figure-bullets`                       |
| `problem`         | 问题描述：数据图或问题示意图，加问题陈述                                  | `figure-bullets` 或 `bullets`          |
| `method`          | 方法：公式与示意图两栏，或流程图与要点；公式编号沿用论文                  | `equations-figure` 或 `figure-bullets` |
| `experiment`      | 实验：对比子图（2×2 或 2×3）或指标表；子图题与图号沿用论文                | `figure-grid`、`figure` 或 `table`     |
| `summary`         | 本章小结：结论要点，加本章对应论文的「论文」框                            | `paper-summary`                        |
| `intro`（应用章） | 应用背景与目标                                                            | `figure-bullets`                       |
| `architecture`    | 系统架构图                                                                | `figure`                               |
| `application`     | 平台界面或应用结果                                                        | `figure` 或 `table`                    |
| `innovation`      | 主要创新点：创新点卡片，卡片数等于研究章数                                | `cards`                                |
| `outlook`         | 未来研究展望：「其一」「其二」等条目                                      | `outlook`                              |
| `achievements`    | 攻读学位期间取得的成果（defense 阶段）                                    | `bullets`                              |
| `backup`          | 备用页：回答预期提问时使用                                                | 任一内容版式                           |

## 问题、研究内容与创新点的对应

- `challenges` 页的问题卡片数、研究章数、`innovation` 页的创新点卡片数三者相等。
- 研究章按章序编号 i = 1..R。第 i 张问题卡片、第 i 个研究章 `intro` 页的小节条「研究内容 i：章题」、第 i 张创新点卡片对应同一章。
- 创新点卡片的文字取自论文结论章中对应的贡献条目，并标明章号。

## 「论文」框

- 条目来源：论文成果列表中标注了对应章的条目，例如「对应论文第三章」。
- 放置位置：对应章的 `summary` 页。著录文本逐字取自成果列表。
- 一章对应多条成果时，`summary` 页放一条，默认取第一条。其余条目可以在讲稿中提及。
- 没有对应条目的章不放「论文」框。不编造成果。

## 阶段差异

| 项目         | `predefense`             | `defense`                      |
| ------------ | ------------------------ | ------------------------------ |
| 封面阶段字样 | 博士学位论文预答辩       | 博士学位论文答辩               |
| 致谢页主句   | 敬请各位老师批评和指正！ | 敬请各位老师批评和指正！       |
| 成果页       | 不设                     | 展望页之后加 `achievements` 页 |

正式答辩常需说明预答辩意见与盲审意见的修改情况。本版不生成该页。
