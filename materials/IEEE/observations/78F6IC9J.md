## Structure

罗马数字标题：`I. INTRODUCTION` → `II. METHODOLOGY` → `III. DATASETS` → `IV. CASE STUDY` → `V. CONCLUSION`。前置 `Abstract—` 与 `Index Terms—`。无独立 Related Work。`related_work=inlined`（Introduction 中段评物理模型 / 浅层数据驱动 / RNN-LSTM-GRU / 注意力机制 / re-attention）。Introduction 末有节序路标，指向 Section II–V。Datasets 独立成节。Experiments 标题为 `CASE STUDY`。
