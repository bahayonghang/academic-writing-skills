# 模块：文献综述综合

目的：将相关工作部分视为分析对话，而不是引文列表。

```bash
uv run python -B scripts/analyze_literature.py main.typ --section related
```

## 核心检查

- **A1：枚举**——重复的作者/年份列表而不是主题聚类。
- **A2：比较综合**——缺少关于权衡、差异或共同限制的句子。
- **A3：间隙推导** - 本节末尾附近没有文献支持的未解决的限制。

## 推荐的重写链

`Consensus -> Disagreement -> Limitations -> Gap -> This paper`

提出修改建议时使用上面的链：

1. 总结多篇论文达成的共识
2. 表面上存在分歧或权衡
3. 隔离剩余的限制
4. 将这种限制转化为有证据支持的差距
5. 将差距与当前论文连接起来

## 边界

- 保持`@cite`, `<label>`，并且数学完好无损，除非用户明确要求进行源代码编辑。
- 当引用的证据太薄弱或相互矛盾时，不要强行留出空白。
- 在生成新的散文之前，更喜欢诊断+重写蓝图。
