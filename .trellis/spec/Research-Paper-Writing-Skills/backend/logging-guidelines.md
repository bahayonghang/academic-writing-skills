# Logging Guidelines

Logging here means note-taking about writing decisions, evidence, and review
status, not runtime logs.

Local pattern:

- The SKILL file asks for a compact outline, revised paragraphs, a self-review
  checklist, and a claim-evidence map.
- The paper-review guide turns reviewer concerns into explicit pass/needs
  revision/needs new experiment notes.
- The introduction and method guides ask for motivation, design, and technical
  advantage notes before the prose is finalized.

Reference files:

- `ref/Research-Paper-Writing-Skills/research-paper-writing/SKILL.md`
- `ref/Research-Paper-Writing-Skills/research-paper-writing/references/paper-review.md`
- `ref/Research-Paper-Writing-Skills/research-paper-writing/references/introduction.md`
- `ref/Research-Paper-Writing-Skills/research-paper-writing/references/method.md`

Avoid:

- Treating the self-review checklist as optional decoration.
- Hiding evidence notes that should stay visible to the next reviewer.
- Writing vague progress text that does not explain the decision or the source.
