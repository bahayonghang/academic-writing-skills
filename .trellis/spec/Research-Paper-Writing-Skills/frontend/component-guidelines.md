# Component Guidelines

Section guides are the components in this repository.

Local pattern:

- Every section guide should start with a goal.
- Then give a compact logic map or step sequence.
- Then provide the section skeleton and concrete writing patterns.
- Then end with a checklist or example-bank pointer.

Reference files:

- `ref/Research-Paper-Writing-Skills/research-paper-writing/references/introduction.md`
- `ref/Research-Paper-Writing-Skills/research-paper-writing/references/method.md`
- `ref/Research-Paper-Writing-Skills/research-paper-writing/references/paper-review.md`

Avoid:

- A section guide that only says "write better" without an actionable structure.
- Copying one section's template into another section without adaptation.
- Hiding the local cite path that shows where the pattern came from.
