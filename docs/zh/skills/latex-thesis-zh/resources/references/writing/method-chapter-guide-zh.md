# 正文方法+实验章（第 3 章起）写作专章指南

面向工业/过程背景中文博士学位论文的**正文方法章**写作与诊断。此处特指"一章一方法 +
同章实验验证"章式（下称**方法章**）：第 3 章起至结论前，每章提出一个核心方法/模型，并在
章内实验节闭环验证。这类章多由已发表英文小论文经 paper-to-chapter 工作流转写而来，盲审
第一风险是"小论文拼接感 / 草稿态残留"。诊断入口：

```bash
# 逐方法章实验完整性（E-DATA/E-ATTR/E-REF/E-FIG/E-METRIC/E-PARAM/E-ABL/E-ECHO）
uv run python $SKILL_DIR/scripts/analyze_experiment.py document.tex --per-chapter
# 拼接感 P-PAPER 默认扫全部正文章并报全部命中；单章文件承上/章序检查须声明真实章号
uv run python $SKILL_DIR/scripts/analyze_logic.py chapter3.tex --first-chapter 3
# 草稿态对冲 F-NOTE / 占位符表格行 F-PLACEHOLDER
uv run python $SKILL_DIR/scripts/check_format.py document.tex
```

> 本文所有阈值为 5 篇工业背景博士论文（固废焚烧、水泥烧成、水泥熟料、水泥粉磨、锌冶炼浸出）
> 逐篇通读的**学科惯例**口径（出处见各节），**以导师与本校研究生院最新规范为准**，命令行
> 均可覆盖。**跨章检查（承上启下、章间主线、P-PAPER 全文覆盖）推荐在装配后的 `document.tex`
> 上运行**，单文件诊断须配 `--first-chapter N` 声明真实章号。

## 一、章式判别（先判别，再套规则）

面对第 3 章起的某一正文章，先判断它属于哪一类，判据不同、规则不同，**不可混用**：

| 章类型 | 决定性判据 | 典型位置 | 走哪套规则 |
| --- | --- | --- | --- |
| 方法章（本指南） | 一章一方法/模型 + 同章实验节闭环 | 第 3 章起至结论前 | 本指南 + `analyze_experiment.py --per-chapter` |
| 过程分析章 | 工艺流程分析 + 全文方法框架，本身不含独立方法 | 通常第 2 章 | [`process-chapter-guide-zh.md`](process-chapter-guide-zh.md) + `--process-chapter` |
| 工程应用章 | 需求分析 → 系统架构 → 现场上线 → 量化效益 | 结论前独立章 / 末方法章实验节 | 本指南（四态落位，见下） |

**判据说明**：过程分析章（第 2 章）与方法章（第 3 章起）通常并存，判别是为每一章路由规则、
非贴全文标签。方法章锚点是"章标题 =〈方法名/缩写〉+〈对象〉+〈任务〉"，缩写在章/节标题、
图题反复出现（5/5）。

**工程应用/系统验证四态分布，检查器不得硬性要求某一态**（5 篇实测）：①独立工程应用章置于
结论前（锌第 6 章，1/5）；②末章为集成/系统验证章、组装各章成果端到端验证（固废焚烧第 8 章，
1/5）；③工业验证吸收进末方法章实验节（粉磨、烧成，2/5）；④全程离线回测、无现场验证（熟料，
1/5）。四态均合规。

方法有效性与工程落地可分层验证：方法章仿真节只证方法本身（历史/仿真被控对象），真实上线
数据集中到应用章。控制章"用生产数据拟合 NARX 当被控对象再控制它"是通行安全逻辑、不是造假
（红线 11）。

## 二、推荐骨架与弹性口径

5 篇参考论文章式 5/5 高度同构，推荐骨架：

```text
X.1 引言（或章标题后导语）
X.2 基础理论 / 框架 / 结构设计〔可选，框架节与建模节常分家〕
X.3 方法建模（逐模块数学推导）
X.4 理论分析〔控制方向章的收敛性/稳定性，预测/优化章无此要求〕
X.5 实验（设计）与结果分析
X.6 本章小结
```

- **直属二级节 4~6 个**。首节"引言"（4/5 为编号 X.1 引言；锌为章后无编号导语），实验节含
  "实验/仿真验证/案例研究/结果分析"字样，末节"本章小结"（5/5 逐字一致）。
- **框架/结构设计节与建模/方法节常分家**（粉磨/烧成/熟料 X.2 框架 + X.3 建模）：框架节给总体
  结构图 + 模块概述，建模节逐模块数学推导；合并为一节亦可。
- **控制方向章在方法与实验间插独立理论分析节**（收敛性/稳定性）——控制学科刚性惯例；预测/
  优化章无此节不报（红线不作硬检）。
- **方法章内允许"教科书式基础理论节"**（固废焚烧通用网络理论、锌 AE/LSTM 介绍）——2/5 存在，
  不算冗余（红线 5）。
- **单章 10~30 页**（主流 15~21），显著长于同名英文小论文（中科院抽检：大论文须详于小论文）。

## 三、章引言规范（承上启下）——本指南最关键口径

**用户已决策口径**：承上启下两段式为**主动推荐形态**——paper-to-chapter 工作流下始终写承上
更稳、更利于盲审定位主线（两段模板见 [`thesis-writing-guide.md`](thesis-writing-guide.md)
"正文章引言"）。但它**推荐而非硬性**，弹性边界经 5 篇范文核实：

- **并列方法章可不承上**：承上强度 **∝ 章间真实依赖**。有数据/模型依赖的章 5/5 强承上（烧成
  第 5 章点名第 3、4 章）；纯并列方法章之间可不回指（熟料、固废焚烧各章自足立论）。→ 检查器
  对**纯并列章缺承上只给 Info、不报 Major**；仅当章内已复用前章产出（出现"第 X 章"）而引言
  无承接时才维持原级。
- **承接靠"角色复用句"而非"叙述回顾段"**：不复述前章做了什么，直接声明"将第 X 章的预测模型
  作为本章适应度函数"（粉磨）。用**章节号**指代，避免"上一章/上文"相对表述。
- **启下是"方法路线预告"而非"节号目录"**（3/5）：句式"首先……其次……最后，基于……实验
  验证了……有效性"；不必写"3.2 节将介绍……"。
- **篇幅 1~3 段、约 300~500 字**；文献密集章可扩到 3 页、承担小型综述并带 `\cite`（固废焚烧
  第 4 章引 30+ 篇）——**引言含 `\cite` 不是错误**。
- **两形态均合规**：编号引言节（X.1 引言，4/5）/ 章后无编号导语（锌，1/5）；编号引言节形态下
  `\chapter` 后直接 `\section{引言}` 不报"缺导语"。
- **禁重复绪论综述**（清华§4.5：已在绪论综述讲过的内容，章引言不再重复）。
- **"缺陷驱动过渡"推荐范式**：最优雅的章间过渡在**上一章实验末尾**——用实验暴露的缺陷逼出
  下一章（粉磨第 5 章"单步决策致系统不稳定"逼出第 6 章滚动优化）。

| 写法 | 判定 |
| --- | --- |
| "第 5 章的预测模型仍需人工整定，本章将其作为适应度函数嵌入优化框架……首先……最后实验验证了有效性。" | 通过（角色复用句承接 + 方法路线预告启下） |
| 纯并列章：引言只立本章问题、不回指前章，但预告本章方法路线 | Info 推荐（并列章可不承上，红线 1） |
| 章内 4.3 节写"沿用第 3 章的特征集"，但引言完全不提第 3 章 | 维持原级（有依赖线索却漏承接，应补角色复用句） |
| 引言写成第二篇绪论、大段重复绪论综述 | 违反清华§4.5（应删至承接问题、不重复综述） |

## 四、方法设计呈现规范

- **每章必配 1 张方法总体框架/结构图（5/5）**，置于框架/方法节开头，图后用 (1)(2)(3) 逐模块
  讲解数据流。方法/框架节内无 `\ref{fig:...}` → **E-FIG（Major）**。
- **公式 20~40 编号式/章**，连续编号 (X-n)；每式后"**式中 X——释义**"逐符号解释（GB/T 惯例）。
  抽样检查公式后缺"式中"释义（LLM 车道）。
- **机理建模先列假设条件**（锌"做出以下假设：1)……4)"）——机理章固定动作。
- **算法呈现三态，同篇内可随方法性质切换**（红线 9，不强求全篇统一）：①伪代码框"算法 X-1
  输入/输出/步骤"（燕大系 3/3）；②编号步骤列表；③流程图（粉磨伪代码 + 流程图双呈现）。
  确定性算法多用伪代码，循环反馈控制多用流程图。
- **问题形式化落位三态**（红线 8）：①独立"问题描述/定义"节（粉磨 4.2.1：符号 + 映射 + 式）；
  ②内嵌方法推导；③**优化模型前置第 2 章、方法章跨章引用式号**——单一数据源、避免重复推导，
  合法且推荐。
- **大论文须详于小论文**（中科院抽检）：方法原理、数值/理论依据、参数拟合细节应比投稿小论文
  更完整，不能只有简要介绍。

## 五、实验写作规范（工业版）

- **数据描述四要素**（5/5，缺任一 → E-DATA Major）：来源（厂/装置脱敏）、样本量、训练/测试
  划分、预处理（滤波/3σ/归一化/时间尺度对齐）。脱敏四手段：厂名匿名、变量代号、工况限定、
  数值缩放声明。
- **对比方法三类分组 + 公平性四同**：经典基线 + 同类 SOTA + 消融变体；四同 = 同数据集/同划分/
  同指标/同硬件（提升须归因于方法本身而非更多数据/更长训练）。**优化/决策章可仅用"人工经验
  操作"做基线、可无算法基线**（烧成第 5 章、固废焚烧 Manual operation）——合法核心对照（红线 4）。
- **指标必给公式，首次给全、后续复用不重列**：RMSE/MAE/MAPE/R²、ISE/IAE/ITAE、HV/GD 等 + 业务
  指标（达标率、节能率）。指标词出现但章内无公式且非复用前章（无"X.X 节"复用指涉）→
  **E-METRIC（Minor）**。
- **参数设置必有专表 + 敏感性分析**（5/5）：对比方法超参也列；超参"试错法确定"可如实写 +
  敏感性扫参图替代严格调参（参数敏感度讨论已成隐形必选项）。无参数线索 → **E-PARAM（Minor）**。
- **结果表规范**：中英双题；单点值为主（4/5）合法；最优加粗或末行胜负统计行 +/-/~；训练/测试
  双栏。随机性优化算法章报 **Mean±Std**（粉磨 20 次）——但**无均值±方差、无显著性检验不报**
  （红线 3）。
- **结果分析三段套路（5/5 强范式）**：描述现象（点名图表号）→ 定量比较（引表内数字 + 相对
  百分比）→ 机理归因（'这是因为/其主要原因在于'），末句"因此/综上，……是有效的"收束。
  **图-表-文字-百分比四重呼应**，禁流水账。实验节无 `\ref{tab:/fig:}` → **E-REF（Major）**；
  归因句密度过低（默认 <15% 或最少 3 行）→ **E-ATTR（Major）**。
- **消融必备（5/5）+ 顶会闭环进阶标准**：机制拆解/单源 vs 融合/去改进任一形态即可（章内无
  消融线索 → **E-ABL（Info）**，形态多样不硬拦）。进阶标准：①每个消融形成逻辑闭环（须机制
  证据，非仅数值微涨）；②验证模块间交互（A+B 同移 ≠ 各自之和须解释）；③跨数据集/跨工况一致。
- **显著性检验分方向口径**（不得一刀切）：需统计推断的方向（实证、部分控制对比）是硬要求；
  **纯确定性算法对比惯例为多次运行均值±方差 + 多工况一致，而非 p 值**。工业过程论文 5/5 无
  p 值/t 检验属惯例（红线 3）。
- **加强项**（有则更强，无不扣）：公开基准 + 本问题两段式验证（固废焚烧 ZDT 先证普适再证
  适用）；多工况/多品种（粉磨三品种）；扰动鲁棒性；推理实时性（延迟 + 内存）；**工艺机理翻译
  算法输出**（粉磨把优化解翻译成工艺操作逻辑再落节能率，而非只报数字）。
- **仿真验证 vs 现场应用措辞诚实性**（红线 12，正向可查）：数据真实但离线验证须写"仿真实验/
  离线验证"，**不得写成"现场应用"**。

## 六、本章小结模板

- **模板（5/5）**：单段"**问题 → 方法 →（关键）数字 → 意义**"（可'首先……最后'串方法要点，
  带核心数字）。长度 **1 段、150~350 字**主流（编号列点复述贡献属少数派，非默认形态）。
- **"为第 X 章奠基"式启下句是分歧点**：锌 5/5 必写（点名章号），烧成/熟料/固废焚烧基本不写
  → **启下句只作 Info 推荐，不得作缺失即报的硬检查**（红线 2）。工程应用章小结收束到量化效益
  + 推广价值，不再启下。
- **结论 ≠ 各章小结简单重复**（清华§4.6）：全文"结论/总结与展望"综合全文贡献、局限与未来
  方向；本章小结只做章内证据收束，不机械重复每章"第 X 章……"句式。

## 七、与第二章框架呼应规范

方法章须与第 2 章总体框架呼应（5/5），但**呼应可正向也可反向，均合规**：

- **固定回指句**："根据第 2 章……工艺/变量分析"；
- **跨章引用第 2 章式号/表号/变量体系**（CV/MV/EV 代号），全书同名对象贯穿；
- **方法章不重画总架构，只画本章局部框架**（不与第 2 章框架图重复）。

**反向承接亦合规**：第 2 章框架节已把方法模块映射到后续各章（正向），故 3/5 论文的方法章不
再显式回指第 2 章，而靠框架图的正向指派承接。因此**全章无"第 2 章"回指且无跨章 `\ref` 只
触发 E-ECHO（Info），不得升级**。

## 八、"小论文拼接感"与草稿态专节

工业博士大论文常由若干已发表小论文整合而成，**正文不得暴露拼接与草稿痕迹**。盲审四大主因
（官方抽检与盲审经验交叉印证）：**创新点不突出 / 逻辑主线断裂 / 工作量单薄 / 拼凑感**。对照
规避：

| 暴露写法（应改） | 建议表述 | 检查车道 |
| --- | --- | --- |
| "源论文/小论文/N 篇论文对应的核心问题" | "N 个核心问题 / N 项研究内容" | P-PAPER（Script，默认全章报全部命中） |
| "本文提出了 PG-MOEA/D……"（章内说"本文"却指本章方法） | 改"本章提出" | Info / LLM 车道 |
| 草稿态对冲："待验证/暂以占位/仍在进行/重跑后补齐/复算/不代表补强后性能" | 定稿表述或删除 | F-NOTE（Script，Info） |
| 结果表占位行 `& --- & --- & ---` | 补齐数据或删行 | F-PLACEHOLDER（Script，Major） |
| "我们提出/我们发现"泛滥（中科院点名某论文 318 个"我们"） | "本章/本文"，区分作者与合作者贡献 | LLM 车道 |
| 直接翻译已发表英文论文、明显翻译腔 | 重写而非翻译，补理论细节 | LLM 车道 |
| 方法配图从已发表论文截图、未标注/未引用 | 自绘或标引用；正文未提及的图删除 | LLM 车道 |
| **方法名自相矛盾**（截图实例用 NSGA-II，与全文 PG-MOEA/D 冲突） | 统一术语与符号表 | **LLM 车道**（语义级，脚本不判） |

**查重清单**（LLM 判断，脚本不硬检）：

- [ ] 全章无"源论文/小论文/N 篇论文"及"为避免拼接感"这类元表述；
- [ ] 方法名/模型缩写在章标题、图题、正文、伪代码中前后一致（无自相矛盾）；
- [ ] 结果表无占位行、无草稿态对冲词；
- [ ] 每章围绕全文唯一主题递进（清华§4：不能是几块工作拼凑），有一条贯穿主线。

## 九、防误报红线清单（12 条，检查器不得报错）

以下情形**合法，检查器不得报 Major**（负例锁定，5 篇范文核实）：

1. **并列方法章引言无承上** → 不得报 Major（依赖驱动判定，纯并列至多 Info）。
2. **小结无"为第 X 章奠基"启下句** → 不得报（Info 推荐至多）。
3. **无统计显著性检验 / 无均值±方差** → 不得报（工业惯例）。
4. **优化/决策章无算法基线、仅人工经验对照** → 合法。
5. **方法章含教科书式基础理论节** → 合法。
6. **引言预告方法路线而非节号目录** → 合法（两态均可）。
7. **引言含大量 `\cite`** → 合法（可承担小型综述）。
8. **优化问题模型不在本章而引用第 2 章式号** → 合法且推荐。
9. **算法呈现体例章间不统一**（伪代码 vs 流程图）→ 合法。
10. **工程应用四态落位**（独立章/集成末章/嵌入实验节/无现场验证）→ 均合法。
11. **控制章用仿真被控对象（NARX 拟合）做控制实验** → 合法通行做法。
12. **仿真 vs 现场措辞边界**：数据真实但离线验证须写"仿真实验/离线验证"，不得写"现场应用"
    ——措辞诚实性检查点（正向可查，非误报豁免）。

## 十、阈值与出处

| 维度 | 默认值 | 出处 |
| --- | --- | --- |
| 单章页数 | 10~30 页（主流 15~21） | 5 篇实测 |
| 直属二级节 | 4~6 | 5 篇实测 |
| 图/章（图 > 表 3:1~7:1） | 5~17 | 5 篇实测 |
| 表/章 | 1~9 | 5 篇实测 |
| 编号公式/章 | 20~40 | 5 篇实测 |
| 章引言 | 1~3 段、300~500 字（文献密集章可例外） | 5 篇实测 |

| E-ATTR 归因句密度 | ≥15% 或最少 3 行（逐章计） | 复用 B3 词表 |
