# Module: Literature Review Synthesis

Use the dedicated `literature` module when Related Work needs synthesis rather than a generic logic pass.

- A1: detect author/year enumeration
- A2: detect missing comparative synthesis
- A3: detect missing research-gap derivation

Recommended rewrite chain:

`Consensus -> Disagreement -> Limitations -> Gap -> This paper`

## Claim-Evidence Boundary

When a gap, novelty, or contribution sentence appears, summarize the claim,
visible evidence anchor, support strength, missing evidence, and bounded
wording. A citation key proves only that a source is cited; it does not prove
that the cited source supports the exact manuscript sentence.
