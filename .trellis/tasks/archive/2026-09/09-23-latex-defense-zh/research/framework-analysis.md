## 2. 页型（按出现规律归纳）

1. 封面：见 §4 视觉测量。
2. 目录：顶部居中蓝色椭圆内白字「目 录」；各章一行，微软雅黑 24 pt，黑色；当前章加粗。
   章前目录与总目录版式相同，只换加粗行。
3. 绪论背景页：顶部节标题「1.1 …」；正文用标题条 + 结论句 + 下箭头 + 红框强调句 + 典型行业配图。
4. 研究现状页：文献计量图或综述图 + 一段归纳 + 文献出处小字；末页落到「为此开展第 x 章研究」。
5. 现存问题与挑战页：「问题一…问题四」四个标题条，每条下 1–2 行说明；关键词红色。
   问题数与研究章数相同，顺序对应。
6. 研究内容与章节安排页：论文组织结构图 + 左侧一段说明（理论、算法、应用三层）。
7. 研究章引言页：节标题「k.1 引言」；小节条「研究内容 n：章题」；技术路线图；
   下方一段「本章提出…首先…其次…最后…」。
8. 问题描述页：节标题「k.2 基础理论与问题描述」；小节条「k.2.x 问题描述」；过程数据图 + 两段问题陈述。
9. 方法页：节标题「k.3 …模型建立」；小节条「k.3.x …」；左右两栏（公式 + 示意图），或流程图 + 三个圆角框说明。
   公式与论文编号一致，如「(3-29)」。
10. 实验页：节标题「k.4 案例研究与结果分析」；小节条「k.4.x 面向…的实验」；一级小标题「案例–…结果」；
    2×2 或 2×3 对比子图，子图题「(a) 方法 A 监测结果」；底部一段结论，关键词红色；图题沿用论文图号「图2-6」。
11. 指标对比表页：论文表格原样截取，图注「表 2-5 …」；最优加粗、次优下划线的说明句。
12. 本章小结 / 论文框页：结论段 + 深蓝边框圆角框，左侧深蓝底白字「论文」标签，框内为该章对应发表论文的著录。
13. 应用章页：系统架构图、平台截图；截图页只有节标题和整页图。
14. 创新点页：顶部「01 主要创新点」标题条；左侧「创新点 1…4」标签 + 箭头 + 圆角卡片；
    卡片句式「针对…问题，提出/设计/构建…，实现…」，关键词红色；创新点数与研究章数相同。
15. 展望页：「02 未来研究展望」标题条；「其一…其二…」两段。
16. 致谢页：封面版式，题带文字改为「敬请各位老师批评和指正！」。

## 3. 讲稿备注

94 页中绝大多数页有演讲者备注。备注内容是口语化的逐页讲稿：说明本页结论、指向图号、
给出与下一页的衔接（例如「为此开展了第 2/3 章的研究工作」）。总目录页备注为「我将按照论文的 7 章内容结构进行汇报」。

## 5. 对目标论文类型的影响

- 参考 pptx 的第 2–5 章都是研究章。目标论文可以有「理论基础与问题框架」类基础章（无独立算法与实验），
  页型序列需要支持基础章角色：1–3 页，只含背景机理图、问题形式化与总体框架。
- 创新点页与现存问题页的条目数都等于研究章数，页面之间存在「问题 k → 研究内容 k → 创新点 k」对应链。
- 「论文」框内容来自论文成果列表中标明「对应论文第 X 章」的条目；没有对应条目的章不放框。
