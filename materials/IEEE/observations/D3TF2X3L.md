## Candidate rules

- R001 abstract 贡献句用 `In this study, a ... model is proposed`，不用 `Here we`。
- R002 Introduction 无独立 Related Work，机理/数据驱动/LSTM/TCN 评述写在引言中段，并以编号 1)–3) 对比后再提案。
- R003 Introduction 末用 `The rest of the article is organized as follows` 指向 II–VI。
- R004 Note to Practitioners 用 `This work considers` / `This work proposes` 复述问题与方法。
- R005 Conclusion 先收回方法，再报 MSE 数字，最后 `In the future, more field tests ... should be performed`。
