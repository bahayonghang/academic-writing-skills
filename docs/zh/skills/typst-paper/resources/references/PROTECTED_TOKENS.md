# 正文中的受保护 Token

润色时**不得改写**的 token 的单一事实源。`SKILL.md` 与模块文档只做指针，不复制此表。

`@cite`、`<label>`、数学块与 Typst 宏已由语法规则守住。本文件覆盖的是**完全没有标记**的那一类——统计值、带单位的数值、模型与数据集名、基因与化学名——它们在正文里就是普通词，不专门写护栏就没有护栏。

## 三档

规则引擎无法识别全部类别。每个类别只归入一档；没有真正可用的检出方法前，不得升档。

| 档  | 标记        | 脚本行为                                                             |
| --- | ----------- | -------------------------------------------------------------------- |
| A   | `auto`      | 检出可靠——遮蔽该 token，绝不改写，并列入 `Protected:`                |
| B   | `candidate` | 模式可检出但有歧义——只报告，绝不自动应用，`Risk-Flags: not-assessed` |
| C   | `llm-only`  | 无可用规则——脚本不处理，由 `[LLM]` 层按下方指导判断                  |

## A 档 —— 自动遮蔽

| 类别                 | 示例                                               | 检出方式                     |
| -------------------- | -------------------------------------------------- | ---------------------------- |
| p 值                 | `p < 0.05`、`p<=0.01`                              | `p` + 比较符 + 小数          |
| 百分比               | `92.1%`                                            | 数字 + 可选转义 + `%`        |
| 数值 + 单位          | `3.2 GB`、`15 ms`、`2.4 GHz`、`5 kg`               | 数字 + 闭集单位              |
| 含数字的标识符       | `ResNet-50`、`CIFAR-100`、`GPT-4`、`VGG16`、`TP53` | 以数字结尾的词形，可含连字符 |
| 首字母大写的连字符名 | `BERT-base`、`T5-small`                            | 大写词头 + 连字符词尾        |
| 全大写缩写           | `SOTA`、`GPU`、`RMSE`                              | 连续两个及以上大写字母       |

遮蔽刻意宽松：多护住一个普通词只损失一条润色建议，少护住一个指标却会静默损坏实验结果。

## B 档 —— 只报告，不应用

| 类别                              | 示例                              | 为何不进 A 档              |
| --------------------------------- | --------------------------------- | -------------------------- |
| 形态与普通名词无异的模型/数据集名 | `Transformer`、`ImageNet`、`Adam` | 无语料时无法与普通名词区分 |

它们通过常规的候选块呈现，作者能看见，而脚本不替他做决定。

## C 档 —— 交 `[LLM]` 层判断

| 类别                      | 示例                              | 为何无规则                       |
| ------------------------- | --------------------------------- | -------------------------------- |
| 非全大写形态的基因/蛋白名 | `p53`、`Shh`、`mTOR`              | 词形与普通词、变量名重叠         |
| 化学名                    | `sodium dodecyl sulfate`、`2,4-D` | 开放词汇；词典既维护不了也仍会错 |
| 依附于检验的统计表述      | “在 5% 水平上显著”                | 含义在句子里，不在 token 里      |

给 `[LLM]` 层的指导：这些字符串保持逐字节原样。若改写会碰到其中之一，保留原措辞并注明——作者纠正一个被保留的术语只花一秒；submission 之后才发现基因名被悄悄改掉，代价是一份更正声明。
