# 设计：Beamer 备注版

## 1. 备注宏（`templates/beamer/defense-layouts.sty`）

```latex
% #1 要点  #2 说什么  #3 过渡  #4 秒数
\newcommand{\DefenseNote}[4]{\note{%
  \textbf{#1}\par\medskip
  #2\par\medskip
  {\color{gray}→ #3}\hfill{\scriptsize #4 秒}}}
\setbeamerfont{note page}{size=\small}
\setbeamertemplate{note page}[plain]
```

- 宏放在 `defense-layouts.sty`（两套主题共用），不放在帧模板（契约：`templates/jinja/` 不定义宏）。
- 参数为空时渲染为空串，不渲染“无”；`notes.md` 中的“无”规则不变。
- `\note` 写在帧内、`\end{frame}` 之前。帧外 `\note` 会生成独立备注页，破坏“帧数 = PDF 页数”。

## 2. 模板改动

- 新增 `templates/jinja/frames/_note.tex.j2`：一行 `\DefenseNote{((( frame.note.key )))}{((( frame.note.say )))}{((( frame.note.transition )))}{((( frame.note.seconds )))}`。
- 12 个帧模板在 `\end{frame}` 前 `((* include "frames/_note.tex.j2" *))`。
- `build_deck.py` 准备 `frame.note`：取 `notes.key/say/transition/seconds`，用现有转义函数处理文字；`**关键词**` 转为 `\textbf{…}`（不调用着色宏）。
- `deck.tex.j2` 在 `\usetheme` 之后加：
  ```latex
  \ifdefined\DefenseNotesPDF\setbeameroption{show notes on second screen=right}\fi
  ```
- 新增 `templates/jinja/defense-notes.tex.j2`（渲染为自有文件 `defense-notes.tex`）：
  ```latex
  % defense-notes.tex: generated by academic-defense-beamer. Presenter build with notes on the right half.
  \def\DefenseNotesPDF{}
  \input{defense.tex}
  ```

## 3. 编译

- `compile_deck(out_dir, notes_pdf: bool)`：先 `latexmk -xelatex defense.tex`，成功且 `notes_pdf` 时再 `latexmk -xelatex defense-notes.tex`。
  任一失败退出 5，并指出是哪一份；日志各自为 `defense.log`、`defense-notes.log`。
- `build_manifest.json` 增加 `"backend": "beamer"` 与 `"notes_pdf": "defense-notes.pdf" | null`。
- `OWNED_FILES` 增加 `defense-notes.tex`；“内容未变不重写”规则同样适用。

## 4. 检查

- D-NOTES（源级）：解析 `defense.tex`，按 `% defense-frame:` 标记切帧，统计每帧 `\DefenseNote{` 次数；≠1 报 Minor，定位到帧。
- D-NOTES-PDF（新码，Severity 默认 Minor，比例或页数错误为 Major）：
  - 定位：`--notes-pdf` > `--deck` 同目录 `defense-notes.pdf`。
  - manifest `notes_pdf` 为 null → skipped；PyMuPDF 缺失 → skipped；文件缺失但 manifest 期望存在 → Minor。
  - 页尺寸全部一致、W/H ∈ [3.1, 3.6]；页数 = `defense.pdf` 页数；相邻页 `page.get_label()` 不同（全空标签视为不同，FerroStage 对空标签逐页独立）。
- PyMuPDF 惰性导入，沿用 `render_preview.py` 的做法；`conftest.py` 已在收集阶段预导入。
- 码集合 21 → 22：同步 `references/quality-gate.md`、spec 契约、`check_deck.py` 的码表与输出契约测试。

## 6. 风险与 spike

- S1 Beamer 页标签：确认 XeLaTeX + Beamer 默认的 PDF 页标签在 second-screen 模式下逐页不同（FerroStage 已知 `notes-right.pdf` fixture 中两帧同标 `1,1`）。
  若重复，在 `defense.tex` 导言区加 `\hypersetup{pdfpagelabels=true}` 或用 `\thepage` 方案，并在 spec 中锁定。
- S2 ctexbeamer + second screen：中文字体在备注半页的渲染与换行；长讲稿（≥ 250 字）是否截断。若截断，备注页字体降为 `\footnotesize` 并在 D-NOTES 加长度提示。

### Spike 结论（2026-10-27，TeX Live 2025 XeLaTeX，fixture 54 帧）

- **S1 不通过，需修复**：second-screen 模式下 pgfpages 把每个逻辑页（幻灯片页与备注页）都交给 hyperref 写页标签，
  `/PageLabels` 有 108 条记录对应 54 个物理页（`0:<FEFF0031> 1:/S/D 2:<FEFF0032> 3:/S/D/St 2 …`），解码后物理页标签为 `1,1,2,2,…`，
  正是 FerroStage 会误并组的情形。只加 `\hypersetup{pdfpagelabels=false}` 无效（记录照旧写出）。
  有效方案：备注版额外写 `\special{pdf:put @catalog <</PageLabels<</Nums[0<</S/D>>]>>>>}`（放在 `\AtBeginDocument`），
  物理页标签变为 `1…54`，与投屏版一致，相邻页互不相同。该语句只在 `\DefenseNotesPDF` 已定义时生效，投屏版不变。
  另：PyMuPDF `page.get_label()` 不解码十六进制字符串（返回 `<FEFF0031>`），D-NOTES-PDF 必须自行把 `<FEFF…>` 按 UTF-16BE 解码后再比较，否则会漏报重复标签。
- **S2 通过**：备注半页中文渲染与换行正常；288 字讲稿加要点、过渡、秒数在 `\small` 下只占约半页，无截断（截图 `research/spike-s2-notes-page.png`）。
  保持 `\small`，不加长度提示。
- 投屏版 `defense.pdf`：54 页，453.5×255.1 pt；备注版 54 页，907.1×255.1 pt，W/H = 3.556。

### 实施细化（spike 后）

- D-NOTES-PDF 在未编译时（`defense.pdf` 不存在）记入 `skipped`，与日志三码一致，基线检查仍零结果；PDF 无法打开报 Major。
- `\DefenseNote` 的四个参数加入 `check_deck.py` 的隐藏参数表，不计入可见字符、D-NUM-SRC 的答辩稿部分与 D-FIG-NUMBER；
  讲稿文字仍由 `notes.md` 侧的检查覆盖。D-PLACEHOLDER 的答辩稿扫描跳过 `\DefenseNote` 行，避免与 `notes.md` 重复报告同一占位符。
- 只改讲稿后 `--force` 会重写 `defense.tex`（备注在其中），`test_force_keeps_unchanged_files` 与 spec 错误矩阵相应更新。
