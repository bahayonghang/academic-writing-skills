# 正文各级段落职责与结构去重

本指南为正文各层级段落提供职责分配基准与结构去重规则。重点解决盲审与导师批注中常见的“这段前文已讲过”“小节开头反复列整章问题”“公式后逐字翻译运算”“小结新增论证”等结构重复与写作冗余问题。

## 使用入口

```bash
uv run python scripts/analyze_logic.py main.tex --paragraph-roles
uv run python scripts/analyze_logic.py main.tex --paragraph-roles --section method
```

- **适用范围**：第 2 章至结论前的正文各章（绪论专章见 [`introduction-guide-zh.md`](introduction-guide-zh.md)，结论专章见 [`conclusion-guide-zh.md`](conclusion-guide-zh.md)）。
- **指南分工**：
  - 章引言承上启下两段式与弹性口径见 [`thesis-writing-guide.md`](thesis-writing-guide.md) 与 [`method-chapter-guide-zh.md`](method-chapter-guide-zh.md) 第三节；
  - 总节导语规范见 [`structure-guide.md`](structure-guide.md)；
  - 方法小节首段与公式闭环见 [`method-description-guide-zh.md`](method-description-guide-zh.md) 第三节与第五节；
  - 实验结果分析见 [`results-analysis-guide-zh.md`](results-analysis-guide-zh.md)；
  - 本章小结规范见 [`thesis-writing-guide.md`](thesis-writing-guide.md) 与 [`method-chapter-guide-zh.md`](method-chapter-guide-zh.md) 第六节。
- **运行特征**：`--paragraph-roles` 是可选附加开关，默认关闭；不传时 `logic` 输出保持不变。所有输出均为 `[Script]` 观察，默认 Info/P3，且包含 `Meaning-Check: NEEDS-LLM`。`--section` 接受英文键或中文章节名（如 `method` / `方法`），不接受章号；按章节区间过滤，本章小结若不在所选区间内则不报 `PR-SUM-NEW`。

## 逐位置说明与正反例

### 章引言

- **合适职责**：明确本章所要解决的具体技术问题、与前一章的输出/结论接口，以及本章提出的核心技术方案。
- **不必反复做**：重新长篇介绍整个行业宏观应用背景；在同一引言内双写节号目录与路线预告，或逐节详列每个小节的具体研究内容。
- **反例**（重复了绪论第 1 章已交代过的行业背景与宏观需求）：
  > 近年来，随着智能制造和工业互联网的快速发展，流程工业在国民经济中的地位日益突出。然而，由于工况复杂多变、环境恶劣以及传感器易受噪声干扰，如何实现高精度状态估计成为了学术界与工业界关注的热点问题。本章组织如下：3.1 节介绍预处理，3.2 节介绍模型构建，3.3 节介绍参数优化，3.4 节介绍实验验证，3.5 节对本章进行总结。
- **正例**：
  > 第 2 章构建的离线代理模型验证了状态估计的可行性，但在工况剧烈波动时泛化误差显著增大。针对该动态泛化瓶颈，本章提出自适应动态重加权机制，利用在线时序残差动态调整估计器权重。本章首先给出机制的数学描述，其次设计在线重加权准则，最后基于真实运行工况数据完成泛化性能验证。

### 含子节的总节导语

- **合适职责**：界定本节讨论的具体对象、本节在全章中的作用，或为直属子小节提供清晰简短的阅读地图。
- **不必反复做**：把本章引言刚刚交代过的全章核心科学问题、整套方法链和多模块架构再完整复述一遍。
- **反例**（重复了本章章引言已交代过的全章核心挑战与方法链）：
  > 针对非平稳工况下传统估计方法误差大、泛化能力弱的核心挑战，本章整体提出了由动态特征提取、自适应重加权和多任务输出组成的完整估计系统。本节作为该系统的核心组成部分，将围绕上述系统面临的所有泛化问题与特征提取瓶颈展开深入研究。
- **正例**：
  > 本节重点设计自适应重加权模块。该模块接收上一节提取的时序特征表示，根据动态偏差估计权重矩阵，输出调整后的加权表征。下文 3.2.1 节建立重加权数学模型，3.2.2 节推导在线更新准则。

### 具体方法小节首段

- **合适职责**：开门见山说明本小节模块的输入对象、核心作用，或直接承接上游模块遗留的未解决接口。
- **不必反复做**：再次从头列举领域研究面临的所有挑战（如“挑战一……挑战二……挑战三……”）。
- **反例**（重复了总节导语甚至章引言已概括过的全局研究挑战）：
  > 在构建特征投影算子时，现有研究通常面临多重挑战：首先是高维观测带来的特征冗余问题，其次是多模态采样不同步导致的分布漂移问题，最后是标注样本匮乏引发的过拟合问题。为了克服上述全部挑战，本小节展开深入推导。
- **正例**：
  > 针对上节输出的异步特征表征，本小节构建时间连续投影算子。该算子将离散时间索引映射到连续隐空间，在保留采样拓扑的同时消除多通道对齐偏差。

### 公式后段落

- **合适职责**：使用“式中”完成新引入符号的释义；阐释该公式体现的关键物理/算法机制，以及该公式适用的假设与边界条件。
- **不必反复做**：按照公式符号的书写顺序，把矩阵相乘、求和累加、求逆等代数运算按顺序逐字翻译成中文长句。
- **反例**（重复了数学公式本身已表达清楚的算子计算过程）：
  > 上式中，首先计算矩阵 $\mathbf{A}$ 与输入向量 $\mathbf{x}$ 的矩阵乘积，随后将乘积结果加上偏置向量 $\mathbf{b}$，再对相加后的向量进行矩阵转置并与权重矩阵 $\mathbf{W}$ 相乘，最后应用 Softmax 激活函数计算出各项最终概率分布。
- **正例**：
  > 式中：$\mathbf{W}$ 为动态缩放矩阵，$\mathbf{b}$ 为工况偏置项。该变换通过将输入投影至主成分正交补空间，在保留有效动态变化的同时滤除稳态漂移扰动。当观测序列信噪比低于预设阈值时，偏置项将退化为均值先验。

### 实验结果段

- **合适职责**：报告主要基线间的数值显著差异、提取折线图/散点图中的分布与收敛趋势，并给出合理的机制级解释。
- **不必反复做**：把表格中每个单元格的数字机械抄读一遍；在缺乏消融或专门实验支撑的情况下，为每个对比算法凭空猜测失败机理。
- **反例**（重复了实验数据表格已完整呈现的全部数字单元格）：
  > 如表 4-2 所示，算法 A 在数据集 1 上的 RMSE 为 0.321，算法 B 的 RMSE 为 0.345，算法 C 的 RMSE 为 0.389，而本文方法在数据集 1 上的 RMSE 为 0.287；在数据集 2 上，算法 A 的 RMSE 为 0.412，算法 B 的 RMSE 为 0.430，算法 C 为 0.478，本文方法为 0.356。推测这是因为算法 C 没有注意力机制导致网络过深无法收敛。
- **正例**：
  > 表 4-2 对比了四种算法在两类工况下的估计误差。在非平稳工况（数据集 2）下，本文方法的均方根误差较次优的算法 A 降低了 13.6%，表明动态重加权机制在扰动增强时仍能稳定跟踪状态变化。

### 本章小结

- **合适职责**：凝练本章提出的新方法、最关键的实证结果或核心结论，以及为下一章或全文主线提供的必要接口。
- **不必反复做**：在小结中引入新的公式推导、新的图表或新的参考文献；将数据清洗、特征提取、模型训练到参数配置的执行步骤逐一流水账式复述。
- **反例**（重复了正文小节详细推导的公式与引用，新增未在小结前论证的内容）：
  > 本章围绕时序估计问题展开研究。首先完成数据预处理，其次构建如式 (3-28) 所示的损失函数 $\mathcal{L}_{\text{total}} = \alpha \mathcal{L}_{\text{rec}} + \beta \mathcal{L}_{\text{reg}}$，并结合文献 \cite{smith2024} 的收敛准则完成训练。最后得到最优权重 $\mathbf{W}^*$。
- **正例**：
  > 本章针对非平稳工况下的状态估计漂移瓶颈，提出了自适应动态重加权方法。首先建立基于在线残差的权重更新机制，其次通过连续投影消除采样异步偏差。工业实测数据验证表明，该方法在剧烈扰动工况下显著提升了跟踪精度与抗扰稳定性，为第 4 章的全局闭环优化控制提供了可靠的状态反馈源。

## 跨层级去重判据

学术论文包含绪论、正文章、总节、小节、段落等多层级结构。为避免各层级“各自为政、反复声明”，应遵循以下判据：

1. **一处完整、其余指代**：
   - 核心概念、背景需求、全局研究框架或评价指标的完整定义只在最先登场的权威层级给出（绪论交代背景与现状，章引言交代全章方案，总节导语交代本节对象，正文小节展开具体机制）；
   - 后续层级如需使用，一律采用指代式衔接（如“沿用 3.2 节定义的加权矩阵”、“具体实验环境见 4.1 节”），严禁在每个小节反复重述定义。
2. **信息增量两问**：
   - 审阅任何过渡段或承接句时，作者与检查者应自问：
     1. 该段是否提供了前文尚未呈现的新信息（新对象、新约束、新推导、新趋势）？
     2. 若直接删去该段，整章或整节的核心论证链条是否会发生逻辑断裂？
   - 若不提供任何新信息且删去后不影响论证成立，则该段属于写作冗余，应予精简或删除。
3. **四类重复打标与处置**：
   - **同义复述**：换用近义词将前文论点换汤不换药地重写一遍 → 删除冗余句子，保留首个清晰表述。
   - **结论重述**：在证据尚未推导完毕的小节首尾提前宣称全文或全章结论 → 收窄为主张当前小节的局部产出。
   - **材料复用**：多个方法小节重复交代相同的数据集来源、实验硬件配置或参数边界 → 上移至专门的小节统一交代，其余处仅作指代。
   - **概念重复定义**：在每个包含公式的小节中重复解释同一通用符号 → 统一使用符号表或在首次登场处明确。
4. **结构功能性重述保留准则**：
   - 本章小结、全文结论等属于承担“论证收束与闭环”的结构功能性单元；
   - 结构功能性重述允许回顾要点，但必须做**高密度提炼与压缩**（章级小结压缩至单段、要点串接），绝不可退化为操作步骤的逐一流水复述。
5. **过渡句带本层级具体名词**：
   - 段落与小节的过渡引导应使用本层级具体的学术对象名词（如“针对特征对齐后的异步时延”）；
   - 避免使用“下面介绍……”“接下来将探讨……”“本节分为三个部分进行阐述”等缺乏学术信息增量的目录式空话。

## 与既有口径的协调

为确保与本仓库已有规范及工业博士范文标定口径完全一致，本指南确立以下协同准则：

- **D2 章引言“目录与路线二选一”**：
  - 既有 [`method-chapter-guide-zh.md`](method-chapter-guide-zh.md) 第三节核定的“编号引言节 / 章后导语两形态均合规”与“路线预告 / 节号目录两态均合规”原口径完全保持；
  - 本指南仅追加去重约束：**路线预告与节号目录二选一，不得在同一引言内双写**；节号目录不逐节展开每节的具体研究内容。检查器只在双写或节号目录条目过多（$\ge 5$ 条逐节详列）时报出提示。
- **D3 本章小结“要点串接与流程流水边界”**：
  - 既有“可‘首先……最后’串方法要点”口径保持不变；
  - 本指南明确界限：每个方法要点占一个分句（章级宏观粒度，如“首先提出……其次推导……最后验证……”）完全合法；但展开到执行步骤级流水（如数据清洗→特征工程→参数初始化→前向迭代→保存部署逐一复述）属于冗余流水账。该判定属于语义范畴，由 `[LLM]` 复核清单承接。
- **D4 本章小结“不新增论证”**：
  - 既有“不新增未在正文出现的结果与引用”扩展为：**不得新增引用、公式、图表或推导**；
  - 小结中回指本章正文已有图表（如使用 `\ref{fig:...}` 或 `\ref{tab:...}`）属于合规的论证回顾，不属于新增论证，检查器不报。
- **D5 章引言“行业背景与综述边界”**：
  - 既有“禁重复绪论综述（清华§4.5）”与本指南的“不重述行业背景”并列；
  - 第 2 章作为概述式引言承接绪论背景，在脚本层予以豁免；指南仍建议正文各章将背景精简至引出本章直接依赖的程度。

## [LLM] 复核清单

在运行 `--paragraph-roles` 得到启发式候选后，LLM 或作者按以下清单逐项进行语义判读：

1. **章引言**：
   - [ ] 该引言是否花费大段篇幅重新交代整个行业的宏观应用价值与国家政策，而未聚焦本章的具体接口？
   - [ ] 该引言结尾是否在给出“首先……最后……”路线预告后，又追加了一整段“X.1 节……X.2 节……”的节号清单？
2. **含子节的总节导语**：
   - [ ] 导语是否在重复整章的总体目标与全部方法模块，而非针对本节讨论对象建立上下文？
   - [ ] 导语是否只是一句单纯的报幕（“本节分为以下三小节”），未说明各小节之间的推进逻辑？
3. **具体方法小节首段**：
   - [ ] 小节首段是否直接说明了本模块的输入数据、所消除的直接约束，还是又把整篇论文要解决的三大挑战重新罗列一遍？
   - [ ] 首段是否与总节导语或上一小节末段形成了有效的数据接口对接？
4. **公式后段落**：
   - [ ] 公式后文字是否仅仅将数学算子（加减乘除、卷积、转置）按顺序翻译一遍，而未解释变量含义与物理机制？
   - [ ] 公式后是否交代了该计算产出对象的下游用途及其适用的边界条件？
5. **实验结果段**：
   - [ ] （详细判据指向 [`results-analysis-guide-zh.md`](results-analysis-guide-zh.md) 与 RA-*/B3 规则，本清单不重造判据）
   - [ ] 结果段是否演变为逐行抄读表格数字的流水账，缺乏对关键差距和现象趋势的归纳？
   - [ ] 是否在缺少对比消融证据的情况下，主观断言了基线模型的内部缺陷机理？
6. **本章小结**：
   - [ ] 小结中是否出现了正文从未引用的新文献、未曾推导的新公式或新图表？
   - [ ] 小结是否将实验准备、模型训练的每一个具体操作步骤都完整流水账复述了一遍？

| 本章小结 | 无（既有走 logic 指南） | `PR-SUM-NEW` | 区分方法要点串接与步骤级流水账 |
