# 中文论文证据保真与章段叙事增量

## Goal

细化已有摘要、小结、综述与结果分析指南，改善因果/接口叙事并保留事实和证据范围。父需求归属见父 PRD Task Map。

## Background

现有五角色小结缺少章型差异；综述只有宏观综合链；结果指南未区分展示筛选与统计聚合；摘要多组件工作段缺少依赖/并行的分流。依据父任务 research/writing-evidence.md 的 D1-D3 与 research/engineering-evidence.md 的交付 B。现有方法叙述、RA、P-ARC/S-CTX 不重做。

## Requirements

- R1：摘要多组件叙事区分真实串行依赖与并行模块，不补造“后模块修复前模块”的因果。
- R2：小结按框架/方法/系统章表达各自贡献和验证，覆盖全部独立任务；段数、序词和数字数按模板与证据条件判断。
- R3：综述区分主题簇综合、代表文献归因和簇末比较；作者/方法/对象/结果用于核对单篇介绍，不变成每句固定模板。
- R4：结果分析区分展示范围与统计集合，核对聚合是否重算、分母/单位/样本/缺失率层级；缺少共同样本重算时不比较新排名。
- R5：不增删引用键、标签、公式、数值和原有限定；新增脱敏正反例并同步双语资源，语义结论不由正则自证。

## Acceptance Criteria

- [x] AC1（R1、R5）：串行例能说明真实接口，并行反例保留并行；不凭模块名新增作用或消融结论。
- [x] AC2（R2、R5）：三类小结各有合成案例；框架章无指标可合法，双任务小结不漏副任务，方法链与系统时序不一律套序词。
- [x] AC3（R3、R5）：连续三条四要素作者句仍能被识别为流水账；主题综合加代表文献可通过，缺作者/结果不凭 citekey 猜造。
- [x] AC4（R4、R5）：隐藏图中通道且冻结聚合时不宣称指标改变；共同集合/分母未知时保留不可比较状态；不因排版请求重算数据。
- [x] AC5（R5）：新增实际响应及逐项人工/LLM审阅记录可定位；引用、数学、数字、限定保真，无私有材料；未运行模型则不得勾选行为 AC。
- [x] AC6（R1、R2、R3、R4、R5）：原语料不删除，目标资源/双语/manifest 和相关契约检查通过；脚本和 RA 家族不变。
