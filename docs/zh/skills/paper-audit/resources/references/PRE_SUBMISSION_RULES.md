# 提交前机械规则

来源归属：改编自
`ref/Supervisor-Skills/plugins/phd-research/skills/pre-submission-reviewer`
（许可证：CC-BY-4.0）。该参考保留了规则结构和严重性
装配时校准`paper-audit`的深度审查优先架构。

该文件列出了确定性规则和 AI-tone 术语列表。对于如何
这些规则插入到每种模式中（门行为、深度审查升级、PDF
跳过规则，重新审核中的回归），请参阅`references/PRESUBMISSION_GUIDE.md`.

## 目的

`paper-audit`使用该层作为确定性的最后一周检查，而不是作为
竞争模式。这`PRESUBMISSION`脚本提要：

- `quick-audit`：快速机械就绪信号。
- `gate`：咨询结果以及任何真正的关键阻碍因素。
- `re-audit`：机械结果的回归比较。
- `deep-review`第 0 阶段：审阅者通道的上下文。

对于完整/编辑深度审查，高信号`PRESUBMISSION`研究结果可以变成
`pre_submission_readiness`审查通道问题。重点理论、文献、
方法论和逻辑审查仅将这些发现保留在第 0 阶段的背景下。

## 严重性映射

|来源分类|纸质审核脚本严重性|深入审查捆绑严重性|
|---|---|---|
|批判的|严重/P0|主要的，`gate_blocker=true` |
|主要的|专业 / P1|缓和|
|次要的|未成年人/P2|仅次要或阶段 0|

`gate`仅在关键脚本结果或失败的清单项目上失败。主要的
和未成年人`PRESUBMISSION`调查结果仅供参考。

## 确定性脚本规则

这些规则对于`pre_submission_check.py`因为他们直接
在源文件或提取的 PDF 文本中可见。

### 语法和风格 ID

- G1：在读者可见的散文中发现破折号。默认严重性：严重。
- G2：段落长度超过180个单词或超过8个句子。默认：
次要的。
- G3：段落以弱过渡开始，而不是类似声明的主题
句子。默认值：轻微。
- G4：禁止AI音术语组出现3次及以上。默认值：主要。
- G5：摘要缺少五个提交要素：背景、目标、
方法、结果、结论。结果缺失或定量结果缺失
证据是主要的；其他缺失的元素是次要的。
- G6：没有当地证据的重复宣传主张语言应该被拒绝
升级到审稿人判断，而不是自动失败。
- G7：冠词、时态、一致、which/that 和 Chinglish 调查结果要求
法学硕士审稿人报告时准确引用的证据。
- G8：被动语态或句子长度的发现是次要的，除非它们隐藏了一个
方法或结果声明。

### LaTeX/源卫生 ID

- L1：引文之前缺少不间断的联系`\cite...`， 例如
  `Method \cite{key}`而不是`Method~\cite{key}`。默认值：轻微。
- L2：标签包含空格。默认值：主要。
- L3：标签使用连字符，下划线更安全。默认值：轻微。
- L4：编号方程环境没有标签。默认值：轻微。
- L5：编号方程标签从未在文本中引用。默认值：轻微。
- L6：图/表源有标题，但没有具体发现。默认：
次要的。
- L7：图/表源有标签，但没有前面的文本引用。
覆盖范围`references`;除非源上下文很重要，否则不要重复。
- L8：参考书目、引文关键存在以及格式错误的参考文献保留在
  `bib`, `citations`， 和`references`模块。
- L9：页数限制检查停留地点/检查表特定。
- L10：编译错误在外部`paper-audit`;通往 LaTeX/Typst 的路线
当用户要求修复源时的写作技巧。
- L11：机械扫描应忽略源注释。
- L12：PDF 输入必须跳过仅源代码检查，而不是猜测 LaTeX 状态。
- L13：仅限源的结果应包括可用的行号。

### 图质量 ID

该脚本只能检查源字幕。以下仍然是手册或LLM
审稿人提示：

- F1：标题缺乏具体的发现或比较提示。脚本可检查自
源字幕。
- F2：光栅而不是矢量最终图形。
- F3：缩放后字体太小。
- F4：非色盲安全调色板，无双重编码。
- F5：图表垃圾或掩盖比较的装饰元素。
- F6：概览图标签与章节标题不匹配。

F2-F6 需要 PDF/图形工件或审阅者检查。请勿举报
除非视觉检查器证明它们，否则它们将被视为确定性脚本结果。

## 禁止的 AI-Tone 术语

该脚本将这些视为频率阈值，而不是单个单词的禁令。三
或读者可见文本中的更多匹配项变为 Major/P1：

- 创新的
- 开拓
- 革命性的
- 变革性的
- 突破
- 空前的
- 卓越
- 优越的
- 超过
- 最先进的
- 凸显了潜力
- 铺平道路
- 深刻的挑战
- 本质上

单一用途可能是合法的技术措辞。将它们保留在阶段 0 环境中
除非它们成为一种模式。

## 抽象五元素规则

准备提交的摘要应显示：

1. 背景或问题压力。
2. 客观或研究问题。
3. 方法或途径。
4. 具体的结果，最好是定量的。
5. 结论、暗示或有限的收获。

缺少定量结果证据是一项重大准备发现，因为它
阻止最后一周的大门看到论文实际取得的成果。

## PDF 与源行为

PDF 模式仅运行可验证文本的检查：

- 长划线扫描
- 禁用AI音调
- 抽象五要素检查
- 长段落/主题句弱信号

PDF 模式明确跳过：

- LaTeX 引文领带卫生
- 标签空间/连字符规则
- 编号方程参考规则
- 源标题规则

跳过必须在脚本输出中作为被忽略的注释或元数据可见，
不作为一个问题。

## 诚信门

在将这些发现用于面向审稿人的输出之前：

1. 每个发现都必须与源文本、行号或章节相关联。
2. 严重性必须遵循上面的映射；仅关注味道并不重要。
3. 脚本结果必须保留`[Script]`出处。
4. `PRESUBMISSION`研究结果不应取代审稿人的深入判断
方法论、理论、文献或主张的有效性。
5. 仅进行技能审核；它不会重写论文来源。
