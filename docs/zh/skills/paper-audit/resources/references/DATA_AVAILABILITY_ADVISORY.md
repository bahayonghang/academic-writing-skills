# 数据可用性咨询

当提交准备或深入审查需要检查中心论文声明是否可以追溯到源数据、代码或稳定的外部记录时，请使用此建议。它是一种审计辅助工具，而不是数据托管工作流程。

## 检查什么

|物品|问题|严重性指导|
|---|---|---|
|中央声明源数据|主要结论是否有数据文件、存储库、附件、附录表或图形源数据路径？|仅当期刊或会议政策有要求且缺少核心证据时才设置阻拦门。|
|图/表出处|每个中心图形面板或表格是否可以映射到原始或处理后的数据？|主要当中心结果缺少映射时；小号用于辅助数字。|
|稳定的标识符|是否有 DOI、登录号、存储库 URL 或外部数据/代码的稳定存档？|如果期刊或会议需要，可以选择专业；否则建议。|
|许可和访问|是否规定了访问限制、许可证或请求程序？|轻微到中等程度的影响取决于再现性影响。|
|代码/分析工件|脚本、笔记本或分析设置在影响中心声明时是否被命名？|缺席时主修计算论文。|

## 举报规则

- 不要声称数据不可用，除非论文稿件或提供的工件表明存在这种差距。
- 如果用户没有提供工件列表，则报告`missing_evidence`而不是发明存储库。
- 区分源数据、处理数据、图形源数据、软件输出和辅助数据。
- 对于门模式，仅在影响中心证据的明确期刊或会议所需数据可用性差距上失败。
