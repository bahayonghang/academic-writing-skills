# 标题模块参考

用途：按照 GB/T 7713.1-2006 标准和学位论文结构惯例，优化中文论文标题及章/节标题架构。

## 质量标准

| 标准 | 权重 | 说明 |
|-----------|--------|-------------|
| 简洁性 | 25% | 删除“关于...的研究”“...的探索”“新型”“改进的” |
| 可检索性 | 30% | 前 20 个字符包含核心术语（方法 + 问题） |
| 长度 | 15% | 最优：15-25 个字符；可接受：10-30 个字符 |
| 具体性 | 20% | 使用具体方法/问题名称，避免模糊术语 |
| 合规性 | 10% | 遵循论文标题规范，避免生僻缩略语 |

## 标题模式

| 模式 | 示例 | 适用场景 |
|---------|---------|----------|
| 基于方法 | 基于Transformer的时间序列预测方法研究 | 方法创新 |
| 面向领域 | 工业系统故障检测的图神经网络方法 | 应用驱动 |
| 理论 + 应用 | 时间序列预测的注意力机制及其在工业控制中的应用 | 双重重点 |

## 章/节标题架构

当用户询问大标题、小标题、章标题、小节标题、目录标题、每章小节太多，或标题是否
“扣题”时，使用 `--headings`。

标题架构检查报告：

- 没有体现对象 + 问题/任务 + 方法/路径的正文章标题；
- 直接 `\section` 标题超过 5 个的正文章；
- 过于宽泛或没有锚定上级章标题的直接节标题。

绪论、相关工作、文献综述、总结与展望、参考文献、致谢和附录等惯例章节，豁免
对象-问题-方法标题规则。

示例命令：

```bash
uv run python $SKILL_DIR/scripts/optimize_title.py main.tex --check --headings
```

## 应删除的词语

“关于...的研究”“...的探索”“新型”“新颖的”“改进的”“优化的”“基于...的”（可简化）

## 高校专用限制

- **清华大学（thuthesis）**：不超过 36 个汉字，不使用缩略语/公式
- **北京大学（pkuthss）**：不超过 25 个字符，允许使用破折号副标题
- **通用（ctexbook）**：建议 15-25 个字符

## 双语对齐

- “基于X的Y” -> “X-Based Y”或“Y via X”
- 英文标题使用 Title Case
- 避免逐字翻译
