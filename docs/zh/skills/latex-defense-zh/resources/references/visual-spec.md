# 视觉规格

本文件给出 `yanshan` 与 `generic` 两个主题的颜色、版位、字号层级、字体回退和校徽规则。`yanshan` 主题复刻参考预答辩 pptx 的测量值；`generic` 主题使用相同版位和中性颜色，不显示校徽。主题文件为 `templates/beamer/beamerthemeYanshanDefense.sty` 与 `templates/beamer/beamerthemeGenericDefense.sty`，共用宏包为 `templates/beamer/defense-layouts.sty`。

## 页面

- 文档类：`\documentclass[aspectratio=169,11pt]{ctexbeamer}`，页面 16 cm × 9 cm。
- 左右文字边距各 1 cm；页脚预留 0.3 cm；帧内容顶端对齐。
- 不显示 Beamer 导航符号。

## 换算

参考 pptx 页面为 33.867 cm × 19.05 cm。Beamer 页面宽 16 cm，缩放系数 16 / 33.867 = 0.4724。位置、尺寸与字号都乘以该系数。

Beamer 正文 11 pt 在 16 cm 宽页面上等效于 pptx 中的 23.3 pt。pptx 正文下限 16 pt 对应 Beamer 7.6 pt。本技能取 Beamer 文字下限 8 pt（`\scriptsize`），推荐正文 `\small`（10 pt）。

## 字体回退

| 类别 | 依次尝试                                         |
| ---- | ------------------------------------------------ |
| 中文 | Microsoft YaHei → Source Han Sans SC → FandolHei |
| 西文 | Arial → TeX Gyre Heros                           |

宏包用 `\IfFontExistsTF` 按顺序选择第一个可用字体。FandolHei 与 TeX Gyre Heros 随 TeX Live 提供。

## 校徽

- 校徽文件从论文仓库读取，路径写入 `\DefenseSetup{logo=<path>}`。技能包不含校徽文件。
- 内容页校徽高 0.76 cm，封面与致谢页校徽高 1.23 cm，宽度按原图比例。
- `yanshan` 主题：校徽路径为空或文件不存在时，显示文字标识，默认「燕山大学」，粗体，颜色 `defenseNavy`。`\DefenseSetup{logo-text=<文字>}` 可以修改文字标识。
- `generic` 主题：不显示校徽，也不显示文字标识。
