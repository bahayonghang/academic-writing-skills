# 深入审查标准

运行时使用该文件`deep-review`.

## 要检查什么

1. **公式/推导错误**
2. **符号不一致**
3. **散文与正式对象不匹配**
4. **数值不一致**
5. **理由不足**
6. **声明准确性/过度声明**
7. **误导性歧义**
8. **信息缺失/再现性差距**
9. **内部矛盾**
10. **标准的自我一致性**
11. **表格结构违规** - 缺少三行格式（书签）、存在垂直线、列内数字精度不一致、标题位于下方而不是上方
12. **抽象结构不完整** - 五要素模型中缺少要素（背景/目标/方法/结果/结论），无数据的结果部分，空洞的结论仅重述结果
13. **理论贡献不足**——核心概念未定义或模糊，与现有理论没有实质性对话，理论增量无法识别（参见 domain_reviewer_agent.md 参考审稿手册中的 A5-A7）
14. **定性方法论不透明** — 缺少抽样原理、未描述编码过程、没有饱和讨论、敏感研究中缺乏反思性（参见 methodology_reviewer_agent.md 参考审稿手册中的 B6-B10）
15. **伪创新/稻草人** - 捏造研究差距，错误描述先前的工作，选择性引用隐藏与现有方法的重叠（参见prior_art_reviewer_agent.md）
16. **段落级论证不连贯** — 相邻段落之间的逻辑跳转、因果倒置、不支持所陈述主张的证据（参见 critical_reviewer_agent.md 参考审稿手册中的 C5）。在 `Methods` 中，还要检查相邻方法模块是否明确给出上游产出、连接变换、下游用途和剩余约束。

## 主编筛选（门模式）

为了`gate`模式下，EIC 筛选过程在详细检查表之前运行。读`agents/editor_in_chief_agent.md`完整的协议。 EIC 评估：

- 推介质量：论文的前三段是否吸引了读者？
- 地点适合：论文是否适合目标期刊/会议？
- 致命缺陷：无论技术优点如何，是否有任何问题会导致拒绝？
- 演示基线：稿件是否符合最低专业标准？

EIC 筛选的直接拒稿判决是一个障碍。

## 推理风格

对于每个发现：

- 说明最初引起关注的问题
- 解释一下你检查的上下文
- 说出尚未解决的事情
- 保留最有力的证据
- 比起几个浅薄的重复，更喜欢一项成熟的发现

## 不该做什么

- 不要报告文案编辑琐事
- 不要将明显的 OCR 故障报告为作者错误，除非该问题经过最仁慈的更正后仍然存在
- 不要批评某个部分省略了稍后明显出现的内容

## 审核者校准

一篇优秀的论文可能仍然存在几个重大问题，如果它们各自威胁到不同的结论。不要过度合并不同的论点。
