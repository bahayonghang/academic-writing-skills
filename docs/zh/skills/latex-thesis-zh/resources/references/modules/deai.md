# 去 AI 模块参考

用途：在保留 LaTeX 语法和技术准确性的前提下，检测并减少 AI 生成写作痕迹。

## 核心原则

1. **保留语法**：绝不修改 `\cite{}`、`\ref{}`、`\label{}`、数学内容或 LaTeX 命令
2. **零虚构**：绝不添加数据、指标、比较或论断
3. **信息密度**：每个句子都必须传达可验证的信息
4. **克制措辞**：避免没有依据的确定性；使用适当的限制语
5. **学术信息优先**：改变语气前，保留问题-方法-证据-结论-边界链条

## 学术人化契约

去除“AI 味”之前，提取四类受保护内容：

- **事实/证据**：数据、公式、实验、图、表、引用和指标。
- **论断/立场**：作者真实的结论、方法选择、不确定性和局限。
- **逻辑**：章节角色、段落角色、论断-证据映射和跨章闭合。
- **边界**：范围、假设、未验证要点和 `待补证` 项。

只有在这些内容明确后，模块才能移除结构壳。默认输出仍是诊断发现、风险摘要或
改写蓝图。只有用户明确要求时才提供正文改写。

## 高优先级 AI 模式（必须修复）

| 模式 | 示例 | 修复方式 |
|---------|---------|-----|
| 空洞形容词 | “显著提升” | 替换为具体指标：“MAE 降低 12%” |
| 绝对断言 | “显而易见”“必然” | 添加限定：“实验结果表明” |
| 模糊量词 | “大量研究” | 使用数量：“三项研究 [1-3]” |
| 模板化开头 | “近年来”“随着科技的飞速发展” | 从具体问题背景开始 |
| 引用堆叠 | “[1]-[5]”但没有讨论 | 分别讨论每项引用工作 |
| 填充连接词 | “总之”“不可否认的是”“值得注意的是” | 删除并直接陈述结论 |
| 结构壳 | “不是 A，而是 B”“真正的问题”“我的结论是：” | 仅保留承载证据的对比；否则直接陈述学术论断 |
| 模糊指代/比较 | “这些东西”“更自然”“更适合” | 明确研究对象、基线和评价标准 |

## AI 密度评分

| 分数 | 处理方式 |
|-------|--------|
| >70% | 紧急：立即改写 |
| 50-70% | 高：尽快改写 |
| 30-50% | 中：审阅并修订 |
| <30% | 低：仅做轻量润色 |

## 编辑类型

1. 删除空话  2. 添加具体信息  3. 拆分长句  4. 重组结构  5. 降低确定性  6. 删除冗余  7. 补充缺失主语  8. 替换模板表达

## 英文摘要时态检查（`[Script]` LOW）

`deai_check.py` 还会标记现在时报告动词（`shows`、`presents`、`demonstrates`、
`outperforms` 等），但**仅限英文摘要**。中文正文没有时态，因此检查只在英文摘要区域
启用，在其他位置保持静默。它能在主要模板中定位该区域：generic 的
`\begin{abstract}`、thuthesis 的 `\begin{abstract*}` 和 pkuthss 的
`\begin{eabstract}`；跳过中文 `abstract` / `cabstract` 环境，多个摘要并存时按内容
语言选择英文摘要。主语为图/表/公式的动词（`Figure 2 shows ...`）豁免。每次命中
都会生成一条 `[Script]` LOW 痕迹，建议方法/结果使用过去时。

判断层检查清单参见 [`../writing/tense-guide-zh.md`](../writing/tense-guide-zh.md)，其中说明
哪些动词处于边界，以及为何排除 `is`/`are`。
