# 修正术语与缩写一致性误诊

## Goal
避免一致性检查建议合并不同技术概念，并让缩写检查遵守实际阅读顺序、允许合法跨章重引。

## Background
父任务 G4/G5。
`academic-writing-skills/latex-thesis-zh/scripts/check_consistency.py:58`
混合深度学习/深度神经网络等不同概念；第 200–208 行按频率确定统一目标。
第 276 行漏报先用后定义，第 290–296 行误报合法逐章定义。
对应当前内存探针和旧测试证据详见父任务 research/gap-analysis.md。

## Requirements
- R1：不同概念共现不被判为同义漂移；词频不作为语义等价或规范名的证明。
- R2：有完整入口时检测装配全文首次有效使用是否早于首次定义，准确回指源文件/行；无入口时只检查文件内顺序。
- R3：保留合法逐章重引和正常全称/缩写混用；不同释义只给可定位的人工核对候选。
- R4：保留现有显式 custom-terms 能力，验证真实脚本路径，说明自动检查和语义复核的边界。

## Acceptance Criteria
- [x] AC1（R1/R4）：深度学习/深度神经网络、机器学习/机器智能、循环/递归神经网络共现不被要求合并；显式 custom-terms 的真正变体仍可报告。
- [x] AC2（R2）：同一行和多行的全文先用后定义均被定位；主文件 include 前/后的使用顺序正确；后章复用已定义缩写不要求再次定义；定义行不吞入前一章标题。
- [x] AC3（R3）：两章合法首现重引、同章重复同一释义、正常全称后缩写不被报告为语义冲突；同一缩写对应不同释义时提供源位置与 NEEDS-LLM 建议，不替作者认定等价。
- [x] AC4（R2/R4）：目录及 --all-files 输入只作文件内顺序检查并明确覆盖限制；无依据的跨文件顺序不报成通过；默认 include 图仍排除无关草稿。
- [x] AC5（R4）：完整 API/CLI 回归包含注释、引用键、停用词、一次性缩写、定义后使用和多文件坐标；原有错误“真同义”测试被真实正例替换。
- [x] AC6（R4）：公开说明和双语镜像准确界定术语/缩写脚本与数学符号/单位人工复核，相关门禁通过，默认行为变化被明确记录。
