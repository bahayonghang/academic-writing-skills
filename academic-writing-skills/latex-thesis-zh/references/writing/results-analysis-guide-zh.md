# 实验结果分析与证据分级指南

本指南用于中文工科学位论文中的模型对比、组件对比、敏感性分析，以及生成或增强类方法的
结果讨论。它负责结果章的事实组织、判据绑定和解释强度；章级实验完整性读
[`method-chapter-guide-zh.md`](method-chapter-guide-zh.md)，方法收益的主张类型读
[`method-description-guide-zh.md`](method-description-guide-zh.md)，措辞校准读
[`over-claim-guard.md`](over-claim-guard.md)。

运行候选检查后，仍须按本指南核对原始图表、实验协议和方法定义：

```bash
uv run python scripts/analyze_experiment.py thesis.tex --results-analysis
```

`RA-*` 只提供启发式线索，不等同于本指南 `R-*` 清单的覆盖实现。脚本命中不能证明正文
错误，脚本静默也不能证明分析完整；真实论文上的查准率与召回率仍为 `UNVERIFIED`。

## 一、先锁定目标与事实边界

结果分析依次回答三个问题：观察到什么差异，差异集中在哪些样本、工况或指标上，哪些已定义
的方法结构与该差异一致。先写图表事实，再写解释；不得先给机制结论，再挑选数字印证。

写作前锁定以下对象：

1. 数据块、样本数、评价顺序和各方法可使用的输入信息。
2. 评价对象所在的管线阶段，例如原始候选、准入后候选、选定集或下游输出。
3. 每项指标的方向、最优值、次优值、判据和风险子集定义。
4. 图、表和正文数值的来源批次，以及是否来自同一评价对象。
5. 模型已经定义的输入、结构、损失和训练协议。
6. 能否区分完整设置与单个组件的实验类型。

本地论文只能作为段落组织参照，不能成为当前论文数值、机制或学术主张的来源。结论范围须
限定到实际数据块、测试协议和评价对象；离线验证不得改写成现场应用。

依据：用户规范 §1、§3.2、§5.1；外部来源 #1、#3、#6。

## 二、按两条八步链组织论证

模型对比小节使用以下顺序：

1. 比较协议与模型分组。
2. 总体指标排序与最接近基线。
3. 子集、工况或风险尾的排序变化。
4. 轨迹或散点定位误差发生位置。
5. 箱线或分布统计判断误差主体与离群尾部。
6. 输入信息和表征机制解释。
7. 组件记录或区分性证据复核。
8. 当前结论及下一实验接口。

生成或增强类方法的统计保真度小节使用另一条八步链：

1. 评价对象及来源批次。
2. 参照和界限定义。
3. 边际与指定条件指标。
4. 联合分布指标。
5. 动态结构指标。
6. 图中的支持区间和局部差异。
7. 与完整生成-筛选管线的一致性解释。
8. 下游效用实验接口。

先用一至三个自然段建立完整的经验事实，再解释这些事实与问题特性、方法设计的关系。不要把
段落写成“报一个数、猜一个原因”的交错流水账。预期外结果是合法的分析对象，应先如实报告，
再说明它改变了哪项原有预期以及需要什么后续检验。

依据：用户规范 §2、§5.2；外部来源 #3、#8。

## 三、逐指标完成数值比较

- 每个关键指标比较全表真实次优方法；不同指标的次优方法不同时，分别点名。
- 误差指标的相对降低率统一为：

```text
(e_baseline - e_method) / e_baseline x 100%
```

其中 `e_baseline` 为基线误差，`e_method` 为当前方法误差。

- `$R^2$` 默认报告绝对差；只有相对变化有实际解释价值时才报告百分比。
- 分组比较先说明输入权限、模型类型或训练协议等分组依据。分组均值不是受控组件实验。
- 总体、子集、工况或风险尾的排序不一致时，明确报告反转，不用“总体最优”遮蔽交叉结果。
- 风险子集样本较少时，在首次解释处报告样本数，并将结论限定为当前测试块的点估计。
- 百分比很大不代表实际效应很大。同步报告原始尺度差异，区分统计证据与实际意义。

持平结果写成“在当前误差尺度内表现相当”或“与基线相比具竞争力”。进一步判断它表示效应
确实很小、当前设计无法区分，还是样本量不足；没有相应证据时不替作者选择原因。

依据：用户规范 §3.1、§3.3、§8；外部来源 #2、#3、#9。

## 四、把参照、判据和结果术语逐项绑定

同一张表混合多类比较对象时，先区分三类参照或界限；没有判据的统计量单列处理。

| 类型 | 作用 | 合规比较 | 结果术语 |
| --- | --- | --- | --- |
| 点参照 | 描述估计值与参考中心的接近程度 | 估计值、区间、点参照和绝对差 | 接近参照 |
| 分布界限 | 例如重采样分布的 P95，用于评价同一指标 | 按指标方向比较相应置信端点 | 上界内或区间内 |
| 指定目标界限 | 由支持域、任务目标或预注册规则给出 | 明确名称与来源后比较对应端点 | 上界内或区间内 |
| 无判据统计量 | 没有预先定义的参照或阈值 | 只报告估计值和区间 | 描述性记录 |

“R2R 点参照”和“R2R P95 界限”只可作为具体项目中的命名示例；公开规则分别使用“点参照”
和“分布界限”。不得把点参照、分布界限与指定目标界限统称为同一种“参考”。

端点方向必须与判据一致：

| 判据方向 | 比较对象 |
| --- | --- |
| 数值越小越好且设上界 | 置信上界与上界阈值 |
| 数值越大越好且设下界 | 置信下界与下界阈值 |
| 双侧区间或容许带 | 同时检查两个端点 |
| 点参照，无判定界限 | 报估计值、区间和绝对差 |

每项判读统一按“估计值与区间 -> 对应参照或界限 -> 绝对差或端点比较 -> 受支持的结论”
展开。不能跳过中间比较，直接从点估计写成通过、等价或整体有效。

一个单元格含多个指标时，逐指标绑定判据。某行只有 KS 设上界而 W1 无界限，应写“KS 上界
内；W1 描述性记录”，不能概括为整行“界限内”。区间重叠、数值接近或落在经验范围内均不
等于统计等价；只有预先定义并实际完成等价检验，才能使用“等价”。

结果列使用闭集术语：“接近参照”“上界内”“区间内”“描述性记录”。需要表达未满足判据时，
直接写“高于上界”或“未落入区间”，不要另造“基本通过”“近似等价”等模糊类别。

评价对象名称必须包含管线阶段。若统计量来自筛选后的选定集，标题、表题、图题和正文均使用
“选定集”，不得简称为“生成样本”并外推到原始候选池或下游效用。

可复用的判读骨架如下；项目名词只替换对象和判据，不改变比较顺序：

> 指标 X 的估计值为 a [l, u]，对应点参照/评价界限为 b；二者绝对差为 d，或其置信端点
> 与界限比较的结果为 c。因此，该指标接近参照/处于上界内/处于区间内。指标 Y 未设判据，
> 仅作描述性记录。

依据：用户规范 §3.2、§5.3、§5.4。

## 五、让图、表与分布统计各司其职

| 证据 | 主要回答 | 合格分析 |
| --- | --- | --- |
| 指标表 | 谁更优、差多少 | 最优与次优、相对差、绝对差、排序反转 |
| 预测轨迹 | 差异发生在哪里 | 峰值、低谷、过渡段、连续偏移或局部欠估 |
| 散点图 | 误差随目标如何变化 | 对角线偏离、异方差、边界压缩 |
| 箱线图 | 典型误差与尾部误差如何组成 | 中位数、四分位距、上下须和离群值 |
| 组件表 | 哪些结构变化伴随指标变化 | 同指标逐项对照及交叉结果 |

每张图或表先确定一个主要结论。导语优先直接点出该结论，而不只写“图 X 展示了……”。轨迹
或散点分析把局部现象对应到指标；例如，高值窗口集中欠估应与高风险尾误差或最大绝对误差
对应。箱线分析分开描述中位数、四分位距代表的误差主体，以及上下须、离群值和最大值代表的
尾部，不能只写“曲线更贴合”或“箱体更小”。

表格的窄列、换行和中英双题规则见 [`tables.md`](../modules/tables.md)。结果术语宜使用左对齐
定宽 `p` 列并合理分配列宽，不要用 `\makecell` 把长句强行塞入狭窄单元格。编译后人工检查
逐字断行、异常字距和不可读堆叠，不能只依赖 overfull 警告。

依据：用户规范 §4、§5.4、§5.5；外部来源 #1、#2、#3、#5。

## 六、按适用条件分析生成或增强结果

本节仅适用于生成模型输出经过准入、重排或集合筛选后，与真实样本比较边际分布、联合分布
和动态结构的结果。传统预测模型对比不强制套用本节指标族。

标题同时说明来源方法、最终管线阶段和评价问题。首段继续锁定来源批次、真实样本、点参照、
评价界限、指标计算空间，以及图表是否来自同一批评价对象。

| 指标族 | 回答的问题 | 必须报告 | 可支持的结论 |
| --- | --- | --- | --- |
| KS、W1 | 单变量边际分布及指定条件偏移 | 估计值、区间、逐指标参照或界限 | 对应边际接近点参照，或对应端点处于界限内 |
| MMD、SWD | 多变量联合分布差异 | 核或投影设置、估计值、区间和对应界限 | 在当前核或投影定义下满足联合分布界限 |
| C2ST | 分类器能否区分真实集与选定集 | 分类器、分组方式、折数、AUC 区间和判据 | 在当前分类器与分组折协议下接近随机区分水平 |
| ACF、PSD | 时间相关性与频谱结构差异 | 滞后或频域设置、误差值、区间和对应界限 | 在已评价的时域或频域统计量上满足动态界限 |

先完成边际与指定条件、联合分布、动态结构三类指标的逐项判读，再综合说明哪些统计层面接近
参照或满足界限。不能在第一项 KS 满足判据后提前概括整组指标。

密度图至少分析主要支持区间，以及分箱、峰肩、峰顶或尾部的局部差异，并把差异与 KS/W1
数值对应。条件生成任务须说明生成侧曲线代表指定条件、模型输出还是可观测变量，不能把指定
条件写成“合成样本真实值”。图形只定位边际差异，不能替代联合分布和动态指标。

解释完整设置时，建立“方法中已定义的约束 -> 对应统计量 -> 当前观察”映射。动态表征、时序
编码或动态一致性约束可与 ACF、PSD 的时域和频域结果建立一致性解释；候选准入、可行性约束、
分布距离预算或集合筛选可与选定集的 KS、W1、MMD、SWD 和 C2ST 结果建立一致性解释。只有
存在原始候选、阶段中间输出或受控组件移除记录，才可区分生成器、准入规则或集合筛选的贡献；
否则只能解释完整生成-筛选设置。

结尾先正面回答选定集在哪些已评价的统计量上接近相应参照或满足相应界限，再说明下一小节
为何单独评价下游效用；不要用连续免责声明稀释主结论，也不要从统计保真度直接推出预测、
分类或优化性能。统计保真度与下游效用必须分节评价，不能互相代替。

实验章的通用数据、公平性和消融要求见
[`method-chapter-guide-zh.md`](method-chapter-guide-zh.md#五实验写作规范工业版)，生成段落的
输入输出约束见 [`experiment.md`](../modules/experiment.md)。

依据：用户规范 §5.1-§5.6。

## 七、按五级证据阶梯限制解释强度

方法章按主张类型选证据时使用
[`method-description-guide-zh.md`](method-description-guide-zh.md#六按证据强度陈述收益) 的
四级表；结果章按已有证据决定可写内容时使用下方五级阶梯。前者回答“这类主张需要什么证据”，
后者回答“当前证据允许写到哪一级”。措辞选择另见
[`over-claim-guard.md`](over-claim-guard.md)，不在本指南复制其词表和替换表。

| 证据等级 | 可写内容 | 推荐谓词 |
| --- | --- | --- |
| 图表事实 | 当前测试块直接观察到的数值与形态 | “为”“低于”“集中在” |
| 结构事实 | 公式或算法直接定义的输入与计算 | “使用”“保留”“调节”“回退” |
| 一致性解释 | 结果形态与结构机制相互对应 | “与……一致”“与……相符”“支持……的关联” |
| 组件贡献 | 同一框架中的受控组件变化 | “去除后……变化”“该记录支持……” |
| 因果归因 | 严格受控、预算一致且能够排除替代解释 | “由……带来”“主要归因于” |

四级主张表到五级证据阶梯的映射如下：

| 方法章四级主张 | 结果章五级落点 | 使用方式 |
| --- | --- | --- |
| 定义事实 | 结构事实 | 用公式或算法定义说明实际输入、处理和输出 |
| 机制级作用 | 结构事实 -> 一致性解释 | 先写结构事实；有对应结果形态时再写一致性解释 |
| 经验性能 | 图表事实 + 组件贡献 | 先报告图表事实；受控组件记录可支持组件贡献 |
| 因果归因 | 因果归因 | 仅在区分性设计排除替代解释时使用 |

从结果章五级证据阶梯回看方法章主张时，使用反向映射：

| 结果章五级证据 | 可回接的方法章主张 | 不得外推 |
| --- | --- | --- |
| 图表事实 | 经验性能的观察部分 | 不能单独证明机制级作用或因果归因 |
| 结构事实 | 定义事实；机制级作用的定义部分 | 不能单独证明经验性能 |
| 一致性解释 | 经降级的机制级作用 | 不能写成组件贡献 |
| 组件贡献 | 有受控记录的经验性能 | 不能自动排除全部替代机制 |
| 因果归因 | 有区分性证据的因果主张 | 不能外推到未测试数据块或协议 |

完整模型之间的排名通常只支持一致性解释。因果谓词附近没有组件证据时，应降级或标记机制
尚未确定。`RA-CAUSAL` 只检查“单句因果谓词与窗口内组件证据线索”的词面组合；“多机制堆叠、
逐项无证据、末句统一撤回”的防御性推测解释仍由 [`experiment.md`](../modules/experiment.md)
中的 B3 按 `[LLM]` 组合判据处理，不得用单词或 hedge 数量替代证据映射。

依据：用户规范 §5.6、§6；外部来源 #1、#9、#10。

## 八、沿四个轴解释异构基线

解释基线差异时按四个轴检查，不按模型逐个编写原因：

1. 输入信息：是否接收低频条件、掩码、年龄或其他状态变量。
2. 时序与变量表征：是否保留时间顺序、完整历史、局部模式或变量间耦合。
3. 训练目标：是否对状态重叠、风险尾、缺失路径或不确定性施加约束。
4. 数据支撑：样本量、尾部稀疏性和目标分布是否与模型容量相匹配。

同一段集中解释一至两个轴。机制必须来自正文方法定义、可靠引用或区分性证据。不能根据单次
排名断言某类模型天然不适用，也不能把发表时间、参数量或复杂度直接等同于性能。

依据：用户规范 §7。

## 九、用正反例校准持平、反转与预期外结果

不合格的数值复述：

> 方法 A 的 RMSE 为 0.17，方法 B 为 0.19，方法 C 为 0.20，因此方法 A 最好。

问题：没有点名真实次优方法、计算差值、定位误差，也没有说明结论范围。

不合格的无证据归因：

> 方法 A 的性能提升主要来自门控、注意力、尾部损失和不确定性建模。

问题：完整设置比较不能区分四个组件；机制枚举越多，不代表解释证据越强。

合格的事实到解释：

> 方法 A 的总体 RMSE 较次优方法 B 低 10.2%，高风险尾 RMSE 低 24.5%，但低风险尾由 B
> 取得最低值。轨迹显示差异集中在高值峰附近，箱线分布表明 A 的误差主体和上侧尾部均较小。
> A 显式接收条件可用性与年龄，并在条件不可用时保留单源路径；该结构事实与高值及过渡窗口
> 的误差变化一致。去除条件输入后总体 RMSE 增大，因此当前记录支持条件信息与性能差异的
> 关联，但不能把全部增益归于单一门控组件。

持平结果的合格写法：

> 方法 A 与方法 B 的误差区间重叠，当前测试块未显示稳定排序。该结果支持两种方法在本协议下
> 表现相当；样本量是否足以区分更小效应仍需功效分析或追加数据判断。

预期外结果的合格写法：

> 总体指标由方法 A 取得最低值，但低风险子集由方法 B 领先，这与“优势在各子集保持一致”的
> 预期不符。反转集中在低风险样本；当前结果不能区分该现象来自样本构成还是模型表征，后续需
> 通过分层重复实验或受控输入对比检验。

生成或增强结果中，不得把筛选后的选定集写成原始生成样本，不得让 W1 共享只为 KS 定义的
阈值，也不得由完整设置结果推出某个组件“保证了”保真度。

依据：用户规范 §3.3、§5.7、§8；外部来源 #5、#8、#9。

## 十、区分 R-* 语义清单与 RA-* 脚本线索

`R-*` 是人工与 LLM 语义复核清单；`RA-*` 是候选定位器。两者按下表协作，不能把脚本未命中
解释为相应 `R-*` 已通过。

| spec 清单项 | 脚本线索 | LLM 判读 |
| --- | --- | --- |
| R-NUMERIC | RA-SECONDBEST | 百分比复算、逐指标次优点名 |
| R-CRITERION | RA-EQUIV | 判据三分、端点方向逐行核对 |
| R-REVERSAL / R-COMPETING | RA-UNIVERSAL | 对照表格核对交叉结果 |
| R-LOCALIZE / R-DISTRIBUTION | RA-SHALLOW / RA-DISTVOCAB | 误差位置与主体/尾部实质判读 |
| R-STAGE / R-BATCH | RA-STAGE | 标题、表、图和正文同名核对 |
| R-CAUSALITY / R-MECHANISM | RA-CAUSAL | 证据阶梯逐项定级 |
| R-TRANSITION | RA-TRANSITION | 接口句实质性判断 |
| R-PROTOCOL / R-TITLE / R-FIGSEM / R-TABLE-VISUAL / R-SCOPE / R-UTILITY | 无 | 纯 LLM 检查项 |

逐篇检查时仍须完成全部 17 项 `R-*`，包括没有脚本线索的项目。

依据：用户规范 §10；实施设计 §3.3。

## 十一、阈值、防误报边界与来源

以下阈值只用于筛选候选，不是统计判据，也不是写作质量分数：

| 检查项 | 候选阈值或门控 | 严重度 | 判据来源 |
| --- | --- | --- | --- |
| RA-EQUIV | 出现等价断言，章级窗口无等价检验、TOST、等价包络或等价界线索 | Major/P1 | 用户规范 §3.2、§5.3 |
| RA-CAUSAL | 因果谓词段前后一个段落内无组件证据；章内有证据时降档 | Major/P1 或 Minor/P2 | 用户规范 §5.6、§6；来源 #10 |
| RA-SECONDBEST | 至少 8 个可见行，含表引用、对比语境和最优断言，但无次优线索 | Minor/P2 | 用户规范 §3.1；来源 #2 |
| RA-SHALLOW | 图引用与浅层形态词同段出现，且无数字或指标词 | Minor/P2 | 用户规范 §4；来源 #5 |
| RA-DISTVOCAB | 箱线语境的当前段与后一段均无主体或尾部统计词 | Minor/P2 | 用户规范 §4 |
| RA-UNIVERSAL | 全称优势断言且句内无让步或反转标记 | Info/P3 | 用户规范 §3.3；来源 #3 |
| RA-STAGE | 章级窗口至少出现两类保真度指标后，选定集/筛选后与生成样本/合成样本/原始候选在不同陈述句混用 | Info/P3 | 用户规范 §5.1、§5.4 |
| RA-TRANSITION | 最后一段无下一章、下一节、后续实验或“据此”等接口线索 | Info/P3 | 用户规范 §2、§5.6；来源 #3、#6 |

防误报边界如下：数学中的等价类或等价变换不触发 RA-EQUIV；一致性谓词不触发
RA-CAUSAL；因果论断附近有组件证据时不报，章内有但局部未绑定时只报 Minor；规范性或否定
语境不参与 RA-STAGE 对象混用统计；没有至少两类保真度指标时 RA-STAGE 静默；没有对比语境
或表引用时不报 RA-SECONDBEST；本章已有“小结”节时 RA-TRANSITION 静默。既有工业论文
红线继续有效：无显著性检验、无均值加方差，以及优化章使用人工经验基线均不能单独触发问题。
