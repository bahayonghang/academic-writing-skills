# 答辩提问准备

本文件列出博士学位论文答辩的常见提问类别，并规定准备答案的方法。讲稿中「可能提问」一栏的格式见 [讲稿格式](speaker-notes.md)。

## 提问类别

| 类别                   | 典型提问                               | 准备要点                                                   |
| ---------------------- | -------------------------------------- | ---------------------------------------------------------- |
| 选题意义与创新性界定   | 本文的创新点与已有工作的区别在哪里？   | 每个创新点对应一章，说明对比的已有方法与差异所在           |
| 方法选择理由           | 为什么选用该模型或算法？               | 说明问题特征与方法假设的对应关系，给出论文中的依据节       |
| 实验有效性与对比公平性 | 对比方法的参数如何设置？数据如何划分？ | 说明数据集、划分方式、评价指标与对比方法设置，引用论文表号 |
| 泛化与适用边界         | 方法在其他数据或场景下是否有效？       | 说明论文实验覆盖的范围和未覆盖的条件                       |
| 工程落地与部署         | 方法的计算耗时与部署条件是什么？       | 引用论文中的耗时或复杂度结果，以及应用章的部署情况         |
| 章间逻辑               | 各研究章之间是什么关系？               | 用「问题 k → 研究内容 k → 创新点 k」的对应说明各章分工     |
| 成果与章对应           | 发表论文与各章是什么关系？             | 按成果列表中的章对应标注逐条说明                           |
| 局限与展望             | 本文方法的主要局限是什么？             | 引用结论章的展望条目，说明局限与后续工作                   |

## 准备方法

1. 每个研究章准备 3–5 个问题，覆盖上表中至少三个类别。
2. 每个问题写答案骨架：一句结论，论文依据（节号、图号、表号、式号），一句适用边界或局限。
3. 答案中的数字只取自论文，并注明出处位置。
4. 需要图表辅助回答的问题，准备备用页（`backup`），放在致谢页之后。备用页只用论文中已有的图表。
5. 把每页最可能的 1–2 个问题写入该页讲稿的「可能提问」栏。

## 阶段差异

- 预答辩：评委通常关注工作量、创新点和成果是否达到送审要求。
- 正式答辩：评委通常还会核对预答辩意见与盲审意见的修改情况。本版不生成修改说明页，需要时由用户另行准备。

## 答案骨架示例

```text
问题：为什么选用示例方法一，而不直接使用基线方法？
结论：示例数据存在分布差异，基线方法假设数据同分布。
依据：3.2 节问题描述；表3-1 的对比结果。
边界：论文只在两个合成数据集上验证，更大规模数据未做实验。
备用页：图3-2 的完整对比子图。
```
