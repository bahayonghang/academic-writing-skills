# 数字与单位规范（中文学位论文）

配合 `expression` 模块的 `E-NUMSPACE` / `E-NUMSTYLE` / `E-UNITFONT` 三个检查器使用。规则源：`../writing/academic-style-zh.md` §6 与下列国家标准。

## 标准优先级

**学校模板规范 > 通用国标。** 二者冲突时以 `templates/<template>.md` 快照为准——模板快照是本仓模板事实的唯一权威源。已知引用点：`templates/yanshan.md`（GB 3100 / GB/T 3101 / GB/T 3102 / GB/T 15835 系列引用、数字用法条目、YS-36）。

对照的国标：

| 标准 | 覆盖范围 |
| --- | --- |
| GB/T 15835 | 出版物上数字用法 |
| GB/T 15834 | 标点符号用法 |
| GB 3100 | 国际单位制及其应用 |
| GB/T 3101 | 有关量、单位和符号的一般原则 |
| GB/T 3102 | 各领域的量和单位 |

## 一、数字用法（GB/T 15835）

| 场合 | 写法 | 例 |
| --- | --- | --- |
| 精确数值、计量值、统计值 | 阿拉伯数字 | 3.2 kg、12 组样本、92.1% |
| 概数、约数 | 汉字 | 数十次、几百个、十余年 |
| 序数（正文叙述） | 中文 | 第一、第二（不写 1st、2nd） |
| 定型词组、成语、缩略语 | 汉字 | 三大类、四化、一系列 |
| 编号（图/表/式/章/节/文献） | 阿拉伯数字 | 图 3-1、表 2、式（4-5）、第 3 章 |

**不要把编号当概数报**：`图 3`、`第 1 章`、`式 (2)`、`文献 [12]` 都是编号，`expression` 的 `E-NUMSTYLE` 会按前置字（图/表/式/章/节/条/页/卷/册/第）排除它们。

**与 `spec-check` 的分工**：`expression` 只做通用可判定项；模板专属的完整数字规范终检归 `spec-check` 的 YS-36（判定方式为 `llm`）。两者不重复报告同一问题——定稿前的逐项终检请走 `spec-check`。

## 二、数值与单位之间的空格（GB 3100 / GB/T 3101）

- 数值与单位符号之间**空一格**：`3.2 kg`、`25 MPa`、`50 Hz`。LaTeX 中用窄空格 `3.2\,kg` 更规范。
- **不空格**的例外：百分号 `92.1%`、千分号 `‰`、角度 `30°`、角分 `′`、角秒 `″`、摄氏度 `25℃`（用 `25 °C` 写法时则空格）。

`E-NUMSPACE` 是 auto 档：命中即给出插入 `\,` 的替换建议，`Risk-Flags: whitespace-normalized`。

## 三、单位用正体（GB/T 3101）

量符号用**斜体**（`m`、`v`、`E`），单位符号用**正体**（`kg`、`m/s`、`J`）。在 LaTeX 里 `$3.2 kg$` 会把 `kg` 排成斜体，正确写法是：

```latex
$3.2\,\mathrm{kg}$
% 或使用 siunitx
\SI{3.2}{\kilogram}
```

**红线**：该问题位于数学环境内，而「绝不修改数学环境」是本 skill 的红线一。因此 `E-UNITFONT` **只读、只报告、永不给替换文本**，输出里会明确写"需作者手动在数学环境内调整"。这是全部九个检查器中唯一一个"检出确定但仍不能 auto"的——**分档依据是红线，不是判定能力**，实现时不要误当成可以升 A 档。

## 四、常见错例

| 错 | 对 | 依据 |
| --- | --- | --- |
| `3.2kg` | `3.2\,kg` | GB 3100，数值与单位空一格 |
| `92.1 %` | `92.1%` | 百分号不空格 |
| `实验重复了 10 几次` | `实验重复了十几次` | GB/T 15835，概数用汉字 |
| `参见第 1st 章` | `参见第一章` | GB/T 15835，序数用中文 |
| `$3.2 kg$` | `$3.2\,\mathrm{kg}$` | GB/T 3101，单位用正体 |
