## Structure

罗马数字标题：`I. INTRODUCTION` → `II. FRAMEWORK OF THE PROPOSED METHOD` → `III. DATA REDUCTION` → `IV. WIDE-DEEP-SEQUENCE MODEL` → `V` 评价策略 → `VI` 案例 → `VII. CONCLUSION`。前置 `Abstract—` 与 `Index Terms—`。无独立 Related Work。`related_work=inlined`（Introduction 中段评机理模型、浅层数据驱动与 DL/ELM）。Introduction 末有 `The remainder of this article is organized as follows` 路标，指向 Section II–VII。Method 拆成框架（II）、数据约简（III）与 WDS（IV）。Experiments 为制造过程案例（VI）。

## Candidate rules

- R001 abstract 用被动 `is proposed`，先 `However` 指出特征提取难点。
- R002 Introduction 无独立 Related Work，机理 / 浅层 / DL 评述写在引言中段。
- R003 Introduction 末用 `The remainder of this article is organized as follows` 指向 II–VII。
- R004 贡献嵌在 `is proposed with the main contributions shown as follows`，无单独 `The main contributions` 标题句。
- R005 Conclusion 用 `In this article, a method ... is proposed` 收回，再用 `In future, we will further measure`。
