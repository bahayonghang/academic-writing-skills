# Error Handling

Error handling here means how the skill falls back when a section or example
does not fit the paper.

Local pattern:

- The skill tells the agent to clarify the story before making sentence edits.
- Section guides expose a clear "load only the needed section file" rule.
- The paper-review guide says unsupported claims must be weakened or removed.
- The paragraph-flow check gives a concrete fallback when flow is still weak:
  add temporary section headers or transition phrases, then remove the extras
  before finalizing.

Reference files:

- `ref/Research-Paper-Writing-Skills/research-paper-writing/SKILL.md`
- `ref/Research-Paper-Writing-Skills/research-paper-writing/references/paper-review.md`
- `ref/Research-Paper-Writing-Skills/research-paper-writing/references/does-my-writing-flow-source.md`

When a pattern does not fit:

- Prefer a narrower section guide or example bank entry.
- Weaken or remove unsupported claims instead of inventing evidence.
- Keep the fallback explicit so the next editor understands why the change was
  made.

Avoid:

- Writing section guidance that assumes one fixed paper genre.
- Leaving a paragraph unresolved because it "probably works."
- Using a generic rewrite when the issue is actually missing evidence or a bad
  outline.
