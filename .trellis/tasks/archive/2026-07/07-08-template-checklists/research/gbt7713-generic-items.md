### 二、GB/T 7713.1-2006 条文摘录（出处均为标准自身章条号；引自 xxmu 文本层副本）

#### 一般要求（§4）

- §4.2："学位论文应采用国家正式公布实施的简化汉字和法定的计量单位。"
- §4.3："学位论文中采用的术语、符号、代号全文必须统一，并符合规范化的要求。论文中使用新的
  专业术语、缩略语、习惯用语，应加以注释。国外新的专业术语、缩略语，必须在译文后用圆括号
  注明原文。"
- §4.5："每一面的上方（天头）和左侧（订口）应分别留边25mm以上，下方（地脚）和右侧（切口）
  应分别留边20mm以上。"
- §4.7："学位论文的页码，从'绪论'数起（包括绪论、正文、参考文献、附录、致谢等），用阿拉伯
  数字编连续码；文摘页、目次页、插图和附表清单、符号和缩略词说明等用阿拉伯数字单独编连续码。"
  （注意：**国标要求前置部分用"阿拉伯数字单独编码"**；各校普遍改用罗马数字——罗马数字页码
  属校级惯例，generic 条目须标"以本校规范为准"。）
- §6.7："文本型学位论文宜采用GB/T 788规定的A系列规格纸张的A4幅面（210mm×297mm）。"
  （xxmu 副本 §4.4 处印作"A4纸（210×197mm）"，系该副本数字化笔误；A4 尺寸以 §6.7 为准。）

#### 题名（§5.1.1.2）

- "题名以简明的词语反映论文最重要的特定内容（**不超过20字**），应避免使用不常用缩略词、
  首字母缩写字、字符、代号和公式等。"
- "在整篇学位论文中的不同地方出现时，题名应完全相同。学位论文如是基金资助项目，应将基金
  注释在题名所在页下'地脚'位置。"
- （校级差异：清华 25 字、北大 20 字、燕山 25 字/副题名合计 35 字——generic 用 20 字须标
  "国标值，各校可能放宽"。）

#### 摘要（§5.1.5）

- §5.1.5.2："学位论文应有摘要，为了国际交流，还应有外文（多用英文）摘要。"
- §5.1.5.3："摘要应具有独立性和自含性，即不阅读论文的全文，就能获得必要的信息。……摘要
  一般应说明研究工作目的、实验方法、结果和最终结论等，重点是结果和结论。"
- §5.1.5.4："中文摘要一般不宜超过200～300字，外文摘要不宜超过250个实词。如遇特殊需要字数
  可以略多。"（**注意**：此国标值与高校学位论文普遍要求（清华 800–1000、北大博 800–1000/
  硕 600 左右、燕山硕 500–650/博 900–1200）严重不一致，**不得**作为 generic 的 script 阈值，
  只能作说明性事实并标注"各校规定优先"。）
- §5.1.5.5："除了实在无变通办法可用以外，摘要中不用图、表、化学结构式、非公知公用的符号和
  术语。"（无"摘要不标引用文献编号"条款。）

#### 关键词（§5.1.6）

- "每篇论文选取**3～8个关键词**，用显著的字符另起一行，排在摘要的左下方。如有可能，尽量采用
  《汉语主题词表》等词表提供的规范词。"（§5.1.3 题名页数据处亦写"每篇论文可选取 3～8个
  关键词"。校级差异：清华 ≤5、北大 3~5。）

#### 目次与清单（§5.1.7–5.1.10）

- §5.1.7："学位论文应有目次页，排在序和前言之后，另起页。"
- §5.1.8："论文中如图表较多，可以分别列出清单置于目次页之后。"
- §5.1.9：符号、缩略词等注释说明"如需汇集，可集中置于图表清单之后"（条件项）。
- §5.1.10："为了国际交流，摘要、关键词、分类号和目次页，均应有与中文对应的英文译文。"

#### 引言与正文（§5.2.1–5.2.2）

- §5.2.1："引言（或绪论）简要说明研究工作的目的、范围、相关领域的前人工作和知识空白、理论
  基础和分析、研究设想、研究方法和实验设计、预期结果和意义等。应言简意赅，不要与摘要雷同，
  不要成为摘要的注释。一般教科书中有的知识，在引言中不必赘述。"
  "有关历史回顾和前人工作的综合评述，以及理论分析等，可以单独成章，用足够的文字叙述。"
- §5.2.2：正文"必须实事求是，客观真切，准确完备，合乎逻辑，层次分明，简练可读"。

#### 图、表（§5.2.3–5.2.4）——注意国标是全局连续编号

- §5.2.3："图应有编号。图的编号由'图'和从1开始的阿拉伯数字组成，例如'图1'、'图2'等。
  **图的编号应一直连续到附录之前，并与章、条和表的编号无关**。只有一幅图时，仍应标为'图1'。"
  "图宜有图题……图的编号和图题应置于图下方的居中位置。"曲线图坐标"必须标注'量、标准规定
  符号、单位'"。
- §5.2.4：表编号规则同图（"表1""表2"全局连续）；"表的编号和表题应置于表上方的居中位置"；
  转页接排"编号后跟表题（可省略）和'（续）'，如：表1（续）。续表均应重复表头和关于单位的
  陈述"。
- （**关键结论**：常见的"图 2.1 / 图 3-1 按章编号"是校级惯例（清华、北大、燕山均按章），
  **不是** GB/T 7713.1-2006 条文；generic.md 现有"按章编号"小节的"校级约定"定位是对的，
  清单条目不得把按章编号写成国标依据。）

#### 结论（§5.2.5）

- "论文的结论是最终的、总体的结论，不是正文中各段的小结的简单重复。结论应该准确、完整、
  明确、精练。如果不可能导出应有的结论，也可以没有结论而进行必要的讨论。可以在结论或讨论
  中提出建议、研究设想、仪器设备改进意见、尚待解决的问题等。"（无字数、无"不标引用"条款。）

#### 参考文献与注释（§5.2.6–5.2.7、§6.6）

- §5.2.6："参考文献是文中引用的有具体文字来源的文献集合。按照GB 7714《文后参考文献著录
  规则》的规定执行。"（不注日期引用→按其最新版执行。）
- §5.2.7："注释可作为脚注在页下分散著录，但切忌在文中注释。"
- §6.6："参考文献应另起一页"；"参考文献中所列文件均空两个字起排，回行时顶格排，每个文件
  之后不加标点符号。"（无最低条数、无年限/占比要求。）

#### 附录（§5.2.8、§6.5、附录 B）

- §5.2.8.1："附录是作为论文主体的补充项目，并不是必须的。"§5.2.8.2 列出五类可入附录内容
  （过长推导、辅助表格、重复性数据图表、程序、珍贵资料等）。
- §6.5："附录编号、附录标题各占一行，置于附录条文之上居中位置。每一个附录应另起一面。"
- 附录 A 结构图与附录 B 排列格式示例中，附录按"附录 A""附录 B"大写拉丁字母编号，附录内
  条文编号为 B.1、B.1.1、B.1.2.1。→ `script:appendix_letter` 有国标依据。

#### 章、条、段与公式（§6.3–6.4、附录 B）

- §6.3："章、条的编号顶格排，编号与标题或文字之间空一个字的间隙。章的标题占两行。段的文字
  空两个字起排，回行时顶格排。"
- 附录 B（规范性）条文排列格式示例：章"1"、条"1.1"、"1.2.1"、"1.2.2.1"——层级最深示例为
  四级数字编号（x.x.x.x），阿拉伯数字、点号分隔、顶格。→ `script:heading_depth` 的 generic
  基线（≤4 级）有国标示例依据（注意是"规范性附录示例"，非明文的"不得超过"条款）。
- §6.4："论文中的公式应另起一行居中排，较长的公式尽可能在等号处回行，或者在'+'、'－'等符号
  处回行。""公式的编号右端对齐"；"公式下面的'式中：'空两个字起排，单独占一行。"
  （公式编号亦未规定按章编号。）

#### 结尾部分与数据集（§5.3–5.4）

- §5.3.3 后记/致谢在正文之后，列五类致谢对象（基金/协助者/建议者/转载引用权所有者/其他）。
- §5.3.4/§5.3.5 导师简介、作者简介（可选结尾要素）。
- §5.4 学位论文数据集共 37 项，"有星号*者为必选项，共24项"（含关键词、中图分类号、密级、
  论文题名、作者姓名、导师、授予学位名称等）。
- §4.7 + 附录 A：结构 = 前置部分（封面/封二/题名页/序或前言/摘要/目次页）+ 主体部分（引言/
  正文/结论/参考文献/注释/附录）+ 结尾部分（文献题录/索引/后记致谢/导师简介/作者简介）+
  学位论文数据集。

### 三、「国标原文条目」vs「校级常见惯例」判别表（generic 落地防混淆）

| 条目 | 国标 2006 原文 | 校级常见惯例（须标"以本校规范为准"） |
|---|---|---|
| 题名字数 | ≤20 字（§5.1.1.2） | 20~25 字不等，或另有副题名合计上限 |
| 摘要字数 | 200～300 字、外文 ≤250 实词（§5.1.5.4） | 硕 500–650/600、博 800–1200 等，远超国标值 |
| 关键词个数 | 3～8 个（§5.1.6） | 清华 ≤5、北大 3~5 等收紧 |
| 图表编号 | 全局连续"图1""图2"（§5.2.3/5.2.4） | 按章"图 2.1"/"图 3-1"（点号或连字符） |
| 前置部分页码 | 阿拉伯数字单独编码（§4.7） | 罗马数字 Ⅰ、Ⅱ、Ⅲ…… |
| 页边距 | 天头/订口 ≥25mm、地脚/切口 ≥20mm（§4.5） | 各校给出精确 cm 值（3.0/2.5/2.6 等） |
| 章条层级 | 附录 B 示例最深 x.x.x.x | 多数校"不建议三级以上节标题" |
| 每章起始页 | 无条款（仅附录"另起一面" §6.5） | 每章另起页/另起右页 |
| 本章小结 | 无条款 | 部分学校要求（如燕山 §1.5.2） |
| 参考文献数量/年限 | 无条款 | 部分学校规定最低条数与近五年占比 |

### 四、与检查器映射建议（供落地参考，非事实）

- 有国标依据可直接引 §：`kw_count`(3,8 §5.1.6)、`title_len`(20 §5.1.1.2，宜标"国标值")、
  `appendix_letter`(§6.5+附录A/B)、`heading_depth`(附录 B 示例 ≤4 级)、`abstract_order`
  （§5.1.5.2 应有外文摘要 + §5.1.10 对应译文；中前英后顺序国标未明文，标校级惯例）。

  说明行并注明"以本校规范为准"；`abstract_no_cite`：国标只有 §5.1.5.5 禁图表/结构式/非公知
  符号，无"禁引用编号"——若 generic 引该 checker 需换成"§5.1.5.5 + 校级惯例"表述。
- `wordcount`/`intro_len`/`conclusion_len`/`bib_count`/`bib_recency`/`chapter_summary`/
  `new_page_chapter`/`conclusion_no_cite`：国标**均无**对应条款，generic 中只能作
  llm/manual 且标注"校级惯例，以本校规范为准"，或不写。

## Caveats / Not Found

- 2006 版条文摘录目前依赖单一文本层副本（xxmu.edu.cn，大学官网托管）；另两所大学副本为
  图像版无法交叉抽取。该副本结构（目次、前言、附录 A–I）与 openstd 著录信息一致，
  §4.4 存在"210×197mm"数字化笔误（正确 A4 值见同文 §6.7）。落地引用时建议逐条注
  "GB/T 7713.1-2006 §x.x"并保留"以本校规范为准"限定。
- GB/T 7713.1-2025 全文逐字内容不可公开获取（ISO 采标版权限制 + 托管件为扫描图）；
  其与 2006 版的具体条文差异（题名/摘要/关键词数值是否调整）**未知**，记入 missing-evidence.md。
  generic 清单不得引用任何"2025 版规定了……"的二手转述数值。
- GB/T 7713.2-2022《学术论文编写规则》、GB/T 7713.3-2014《科技报告编写规则》、
  GB/T 7713.4-2025（数据论文）与学位论文 generic 清单无直接关系，仅确认系列存在。
