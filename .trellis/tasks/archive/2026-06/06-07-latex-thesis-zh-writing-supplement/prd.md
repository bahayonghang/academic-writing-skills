# 补强 latex-thesis-zh 学位论文能力

## Goal

把 `latex-thesis-zh` 的写作支持补到接近 `research-writing-skill` 的层级，重点覆盖中文学位论文的绪论漏斗、文献综述定位、方法章节主线、实验/讨论分层，以及摘要/创新点/结论闭合，同时保持学校模板、GB/T 7714、章节导语与中文论文边界不变。

> 范围说明：本任务含两条工作流——(1) 高阶写作 eval 语料扩充（下方原始需求）；(2) 正文章引言（承上启下两段式）能力补强（见《章引言能力补强》一节）。工作流 (2) 通过**扩展现有 `logic` 模块** + 新增写作参考 + 测试实现，**不新增模块**，与 Phase 0 评审门一致。

## Requirements

- 新增一批面向高阶写作能力的 eval 场景，而不只是结构、模板或基础诊断场景。
- 至少新增 6 个高阶 eval 场景，覆盖绪论、文献综述、方法、实验/讨论、摘要/创新点/结论、标题或标题后导语中的关键能力。
- 新增的 eval 场景应覆盖：
  - 绪论：背景 -> 技术瓶颈/研究空白 -> 科学问题 -> 本文贡献 -> 章节安排
  - 文献综述：共识 -> 分歧 -> 局限 -> 空白 -> 本文切入点
  - 方法：章节主线、模块动机、设计说明、技术优势、与上一章的递进关系
  - 实验/讨论：有效性、消融/敏感性、机理解释、与前人比较、局限与启示
  - 摘要/创新点/结论：问题-方法-结果-贡献对齐与闭合
- `trigger_eval.json` 需要补充至少 8 个近邻样例，覆盖 should-trigger 与 should-not-trigger 的边界。
- 近邻样例应明确区分中文学位论文与这些相邻任务：英文论文、Typst、paper-audit、纯文献检索、泛化润色、从零写作、翻译、仅编译/格式检查。
- 保持现有 thesis-specific 路由不变，不引入共享核心或英语会议论文式 section-writing 抽象。

## Acceptance Criteria

- [ ] `evals.json` 新增或重构的场景都能对应到一个可解释的中文学位论文写作能力点。
- [ ] 至少 6 个 eval 能稳定覆盖绪论漏斗、文献综述定位、方法主线、实验/讨论分层、摘要/创新点/结论闭合。
- [ ] `trigger_eval.json` 至少新增 8 个近邻样例，并且正负样本都能清晰区分 thesis 专属写作与相邻任务。
- [ ] 现有模块路由、脚本约定、模板边界、GB/T 约定和去 AI 化边界不被破坏。
- [ ] 如果过程中需要补文字说明，只做最小的边界澄清，不新增共享抽象或新模块。

## 章引言能力补强（Chapter-Intro Workstream）

把"正文每章章首引言（第2章~结论前各正文章）"作为一个独立写作单元补强，使 skill 既能**指导改写**、又能**自动检出**"两段式承上启下"章引言的常见问题。本工作流是对现有 `logic` 模块的扩展，不新增模块、不引入英文会议论文式 `section-writing` 抽象。

### 背景与依据（网络检索）

多所研究生院写作指南（清华 §4.5、北大、北航、同济、北理工）与实务写法高度共识：

- 正文每章开头是"引言"、结尾是"本章小结"，首尾呼应；章引言一般 1~2 个自然段、约 300~500 字。
- 结构为两段式承上启下：
  - **承上（第①段）**：点明上一章/前文对本章的价值，引出本章为何继续。
  - **启下（第②段）**：本章要解决的问题、核心思想、相对已有方法的优势，段末视学科预告本章各节安排（"本章组织结构/路标段"）。
- 两条可机检规范：章引言不与绪论文献综述/前文重复；衔接用章节号（"第2章"）指代，避免"上一章/上文/前一章/下一章"相对指代。
- 绪论（第1章）的三层漏斗式引言**不在本工作流范围**，已由现有 `_check_introduction_funnel` 覆盖。

### Requirements

- 在写作参考新增"正文章引言（承上启下两段式）"指导：两段角色定义、篇幅约定、可套用模板、正反例。
- 扩展 `analyze_logic.py`，把正文章引言从通用导语（S1）中**特化**检测，覆盖：承上缺失、启下缺失、篇幅异常（仅 1 句/极短或远超两段）、相对指代规范。
- "疑似与绪论重复"不强行用正则判定，作为 LLM 备注呈现。
- 新增检查默认随 `logic` 输出，不做成冷门开关；现有 S1 通用导语检查与 `_check_chapter_mainline` 行为不回归。
- 保持模板边界、GB/T 7714、`\cite/\ref/\label`、数学环境、章节号不被改写。
- 提供脚本可判定的测试 fixture：规范章引言（全过）、缺承上+启下、相对指代+篇幅异常。

### Acceptance Criteria

- [ ] 写作参考新增章引言一节，并被 `SKILL.md` Reference Map / 路由规则正确指向。
- [ ] `analyze_logic.py` 能对正文章引言报出承上缺失、启下缺失、相对指代、篇幅异常四类问题，且仅针对第2章~结论前各正文章（排除绪论/结论/总结/致谢/附录等）。
- [ ] 规范两段承上启下章引言 fixture 不被误报（无 P1 误报）。
- [ ] 现有 logic 输出（S1、绪论漏斗、C3 闭合、`--motivation-thread`）无回归；版本与 contract 测试通过。
- [ ] 未新增模块、未引入英文会议论文式 section-writing 抽象。
