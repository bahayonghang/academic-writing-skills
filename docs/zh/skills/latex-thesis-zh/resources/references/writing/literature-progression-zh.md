# 综述递进密度

可选开关 `--progression-density` 只统计已定位章节的可见正文。阈值标记为 `UNVERIFIED`。脚本不轮换同义词，也不输出替换句。

## 计数边界

「进一步」严格多于 5 次、「针对」严格多于 7 次时，输出 `[Script]`、Info/P3、`Meaning-Check: NEEDS-LLM` 候选。
5 次与 7 次不触发。6 次与 8 次触发。
题注、引用键、数学和代码不计入。章节外的出现不计入。
未传 `--section` 时只使用已有 `related` 范围。找不到该节时保留原错误，不改扫全文，也不报告通过。
`--progression-density` 与 `--intro-citations` 不能同时使用。没有 YAML 覆盖层。

## 六类改写方向

这些方向只供人工改写。脚本不从下列方向轮换词语。

1. 方向一：写成可核对的动作。
2. 方向二：写成对象、条件或范围。
3. 方向三：写成阶段顺序。
4. 方向四：写成已给证据及其边界。
5. 方向五：写成分歧或差异。
6. 方向六：合并重复递进，只保留一次转折。

## 四种段落组织

1. 组织一：主题句，然后证据，然后边界。
2. 组织二：共识，然后分歧，然后未解问题。
3. 组织三：方法假设，然后适用条件，然后局限。
4. 组织四：时间阶段，然后转折，然后当前缺口。

## 合成片段

```text
进一步分析条件 A。进一步比较方法 B。
```

该片段只演示「进一步」的计数对象。它不是论文原句。

```text
本节先写条件 A 的范围，再写该范围不覆盖的部分。
```

该片段演示组织一的顺序。不提供同义词替换表，也不编造测量结果。
