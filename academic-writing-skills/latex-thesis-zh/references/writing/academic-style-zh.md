## 一、口语化表达纠正

### 1.1 程度副词替换
| 口语 | 学术 |
|------|------|
| 很多 | 大量、众多、若干 |
| 非常 | 极为、显著、相当 |
| 特别 | 尤其、尤为、格外 |
| 一些 | 部分、若干、某些 |
| 很好 | 优异、显著、卓越 |

### 1.2 主语替换
| 避免 | 使用 |
|------|------|
| 我们 | 本文、本研究、作者 |
| 我 | （尽量避免第一人称单数）|
| 你们 | （不应出现）|

### 1.3 动词规范化
| 口语 | 学术 |
|------|------|
| 用 | 采用、使用、运用、利用 |
| 做 | 进行、开展、实施、执行 |
| 看 | 观察、分析、研究、考察 |
| 想 | 认为、推测、假设、考虑 |
| 试 | 尝试、探索、验证 |

## 二、绝对化词汇规避

### 2.1 禁用词汇
- ❌ 显然、毫无疑问、众所周知
- ❌ 必然、绝对、完全、最好、最优
- ❌ 肯定、一定、当然、无疑

### 2.2 替代表达
| 绝对化 | 学术化 |
|--------|--------|
| 显然 | 研究表明、实验结果显示 |
| 毫无疑问 | 可以认为、有理由相信 |
| 众所周知 | 已有研究指出、文献表明 |
| 必然 | 往往、通常、一般而言 |
| 最好 | 较优、更优、具有优势 |

## 三、逻辑连接词

### 3.1 递进关系
- 此外、另外、进一步、更为重要的是
- 不仅...而且...、既...又...

### 3.2 转折关系
- 然而、但是、不过、尽管如此
- 与此相反、相比之下

### 3.3 因果关系
- 因此、由此可见、综上所述
- 鉴于此、基于上述分析

### 3.4 举例说明
- 例如、譬如、以...为例
- 具体而言、特别是

## 四、常见语病

### 4.1 搭配不当
| 错误 | 正确 |
|------|------|
| 发挥问题 | 发现问题 |
| 增加效率 | 提高效率 |
| 扩大精度 | 提高精度 |
| 改进缺点 | 改正缺点 |

### 4.2 成分残缺
❌ "通过实验，验证了方法的有效性。"（缺主语）
✅ "通过实验，本文验证了该方法的有效性。"

### 4.3 语序不当
❌ "该方法不仅提高了效率，而且也降低了成本。"
✅ "该方法不仅降低了成本，而且提高了效率。"（先易后难）

## 五、标点符号规范

### 5.1 中文标点
- 使用中文标点：，。！？；：""''（）【】
- 中文句子末尾使用中文句号"。"

### 5.2 英文标点
- 英文术语后可用英文标点
- 公式后的说明用英文逗号

### 5.3 混用规则
- 中文语境中的英文单词后用中文标点
- 括号内全英文时用英文标点

### 5.4 正文中的冒号、分号与句间逻辑

中文论文的连续正文默认写成完整句。避免反复使用“标签：内容”“原因是：结论”等冒号壳，
也不要用分号把整个段落串成清单。改写的目的在于显化命题之间已有的逻辑关系，而不是机械
替换标点；如果材料只支持并列事实，就保持并列，不得补造因果、递进或先后关系。

这类判断属于 `[LLM]` 层。按以下顺序处理：

1. 先保护数据、引用、公式、术语、限定条件和 LaTeX 命令，抽取每个分句的事实或主张。
2. 判断因果、递进、转折、条件或并列关系是否得到原文明示证据支持，并按
   [over-claim-guard.md](over-claim-guard.md) 核对论断强度。出现实验、消融、机制分析或来源文本
   本身不等于证明因果；关系不明时使用完整句分别陈述。
3. 删除“结果：”“原因是：”“局限：”等标签壳，补出研究对象、方法或证据作为主语；优先用
   句号划分命题，再按已确认的关系使用必要的连接成分。
4. 复核改写前后的事实、强度和适用范围。不得把冒号或分号简单替换成逗号，也不得仅凭这些
   标点判断文本由 AI 生成。

以下用法可以保留：确有引出或定义作用的冒号、层次较复杂的并列分句所需的分号、摘要总起句
“主要研究工作如下：”、关键词分隔符，以及公式、代码、URL、引文、引用和学校模板要求的标点。

| 场景 | 改写前 | 改写后 |
|------|--------|--------|
| 有组件移除对照 | 结果：表 4-2 显示误差下降；原因是：移除校正模块后误差回升；局限：仅完成离线验证。 | 表 4-2 显示误差下降。组件移除对照中，移除校正模块后误差回升，说明该模块与误差改善相关。该结论目前限于离线验证。 |
| 只有并列事实 | 数据集 A 包含 120 个样本；数据集 B 包含 118 个样本；因此模型 C 更稳定。 | 数据集 A 包含 120 个样本，数据集 B 包含 118 个样本。现有样本数不能证明模型 C 更稳定。 |
| 合法引出与复杂并列 | 主要研究工作如下：当输入完整时，系统执行联合估计；当输入缺失时，系统保留上一时刻状态。 | 保留原句；冒号用于引出，分号分隔内部已有逗号的条件分句。 |

## 六、数字与单位

### 6.1 数字使用
- 精确数值：阿拉伯数字（1, 2, 3）
- 概数：汉字（几十、数百）
- 序数：第一、第二（非 1st, 2nd）

### 6.2 单位规范
- 国际单位制（SI）
- 单位与数值之间空一格
- 使用正体字母（非斜体）
