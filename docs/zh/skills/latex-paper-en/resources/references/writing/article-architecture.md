## 全文论证链

起草或重构前，将论文压缩为以下链条：

`field-scale need -> unresolved bottleneck -> proposed move -> decisive evidence -> broader implication -> boundary`

边界条件应与贡献和证据具有同等地位。若来源缺少某一环，应将其标为缺失；不得虚构主张、
结果、引文、机制或范围条件来补全链条。

## 期刊式摘要推进

期刊式摘要可考虑以下六步顺序：

1. 建立领域背景或问题。
2. 说明现有路径为何未能充分解决问题。
3. 指明论文引入或论证了什么。
4. 报告证据最充分的结果；若材料允许，提供定量或比较证据。
5. 陈述有证据支持的机制、工作流影响或实践后果。
6. 以有边界的含义收束。

该顺序是一种附加模式，不替代
`references/writing/section-writing/abstract.md` 中的三种摘要模式。应根据论文类型、
目标期刊、证据和作者意图选择模式。

## Results 证据阶梯

组织 Results 时，应使后续主张建立在前面的证据上：

1. 系统、工作流或设计空间概览。
2. 证明平台、测定方法或实验设置可信。
3. 主要性能或发现结果。
4. 与基线、标准实践或既有方法进行公平比较。
5. 机制、诊断分析或可解释性证据。
6. 放大、应用、泛化或压力测试。

当该模式与证据相符时，可用以下形式开启主张先行的小节：

`To test [question], we [action].`

随后报告结果及其证据。除非段落明确转入 Discussion，否则应保持解释简短。关于主张到实验的
规划，见 `references/writing/section-writing/experiments.md`。

## Discussion 扩展

从发现逐步扩展到有证据支持的含义：

1. 陈述核心推进。
2. 解释证据为何支持该推进。
3. 指出发生变化的工作流、设计规则或概念边界。
4. 公平地说明该变化与既有研究的关系。
5. 陈述仍然存在的限制与依赖。
6. 指出当前证据使哪些未来工作成为合理方向。

不要复述每一幅图。只选择会改变解释的证据。段落级规划应使用
`references/writing/section-writing/experiments.md` 中现有的 Discussion Layering 指南。
