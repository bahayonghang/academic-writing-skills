# 超额声明防护（审核通道参考）

参考`claims_vs_evidence`Lane：如何发现超出证据范围的措辞，
以及应该修改为保守的措辞。目标是**校准**，而不是胆怯
散文——强有力的证据赢得有力的措辞；薄弱的证据必须使用薄弱的措辞。

## 边界与`CLAIM_EVIDENCE_CONTRACT.md`

- `CLAIM_EVIDENCE_CONTRACT.md`决定**可见证据是否支持某个主张**
（力量阶梯`unsupported → observed → supported → strong`).
- 该文件决定**一旦知道其强度**后应如何措辞声明（其中
动词/限定词将句子保留在证据内）。

在一项发现中，设置`claim_strength`从合同中并将有界重写放入
`allowed_wording`/ 中的过度措辞`forbidden_wording`。在他们发生冲突的地方，
合同获胜（实质内容胜于措辞）。将这些发出为`comment_type: claim_accuracy`.

## 确定性阶梯（动词，最强 → 最弱）

```
demonstrate / prove                         ← intervention + controlled experiment
reveal / identify / find                    ← strong effect, multi-method or replicated
indicate / suggest                          ← significant but single-method
support / be consistent with                ← trend, agrees with prior work
may indicate / could suggest / appear to    ← marginal or predictive
hint at / point toward                      ← very weak signal or hypothesis
```

标记其动词位于其证据可以到达的梯级之上的任何主张。

## 限定措辞不是证据

证据较弱时需要降低确定性等级，但这不会让没有支持的解释变成有证据的解释。一个段落用 `may`、`could` 或 `is consistent with` 列出多个具体机制，随后又声明当前数据无法验证其中任何一项，这属于防御性推测解释。应先应用 `CLAIM_EVIDENCE_CONTRACT.md`：只保留有可见锚点的机制，或者直接说明机制尚未确定。不得删除限制语，也不得仅为让段落显得果断而选择更强措辞。

## 替换表（标记❌→建议✅）

### 1. 因果关系（相关性表述为因果关系——最常见的过度主张）

|❌ 过度主张|✅ 保守|
|---|---|
|引起的|与/链接到|
|驱动/决定|有助于/与...相关|
|负责|涉及/与...有关|
|证明|表明/提供证据表明|

因果措辞只有通过受控干预（消融、随机
作业、A/B 测试）、工具变量设计或复制的既定机制。

### 2.新颖性/首创性（审稿人在几秒钟内验证这些）

|❌ 过度主张|✅ 保守|
|---|---|
|第一个到|据我们所知，第一个/第一个|
|小说（自有标签）|说出新内容；放下标签|
|空前的|实质性的/显着的|

### 3. 普遍性（研究一种设置，声明所有设置）

|❌ 过度主张|✅ 保守|
|---|---|
|总是/从不|一般/很少|
|在所有情况下/普遍|在研究的案例中/在评估的基准中|
|任何数据集|采样的数据集|

### 4. 效应大小（模糊的大小词，没有数字）

|❌ 过度主张|✅ 保守|
|---|---|
|强/大的改进|将误差减少 X% / β = X.XX (95% CI: …)|
|显着的收益|从 X 改进到 Y (p = ...)|
|强壮的|在 N 次运行中保持一致/在[扰动]下稳定|

如果数字很重要，则应该删除形容词。

### 5. 时间/推断顺序（当前数据，过去机制）

|❌ 过度主张|✅ 保守|
|---|---|
|X 推动了变革|变化与X一致|
|发生在时间 T|估计表明〜T（CI：...）|

### 6. 应用/影响（此处未展示下游用途）

|❌ 过度主张|✅ 保守|
|---|---|
|将彻底改变|有潜在影响|
|解决了X的问题|解决 X 的一方面|
|准备部署|为[设置]提供了一种候选方法|

### 7.比较（贬低以前的工作）

|❌ 过度主张|✅ 保守|
|---|---|
|以前的方法都失败了|以前的方法受到以下限制|
|优于所有先前的工作|与【具体方法】相比毫不逊色|

## 高频陷阱短语

|陷阱|安全重写|
|---|---|
|“我们的结果证明了 X。” （X 因果）|“我们的结果与 X 一致。”|
|“这是第一个作品……”|“据我们所知，最先……”|
|“X 在 Y 中起着至关重要的作用。”|“X 与 Y 有牵连/可能对 Y 有贡献。”|
|“这些发现对......具有重要意义”|“这些发现为进一步研究……提供了基础”|
|“强烈支持”|“符合/提供符合的证据”|

## 何时不标记（反向校准）

不要标记证据中的强硬措辞：

- 受控干预（消融/随机对照试验/A-B）→`demonstrate`很好；
- 多种方法/数据集/种子复制结果 →`robustly`（注明证据）；
- 复制既定机制 →`confirms` / `validates`;
- 具有强有力的统计数据的巨大影响 → 强有力的措辞**加上**数字。

标记获得的强硬措辞是一种误报——放弃它。

## 审查通道如何使用它

这`claims_vs_evidence`审查通道标志过度声称措辞为`claim_accuracy`调查结果与
`allowed_wording` / `forbidden_wording`已填写。这是法学硕士判决的补充
写作技巧”`deai_check.py`过度声明脚本，仅捕获一些明确的内容
短语；上表涵盖了脚本无法做出的上下文判断。
