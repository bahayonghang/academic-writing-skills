# 模块：适应

**触发**：适应、换投、改投、期刊改编、重新格式化、期刊装备、重新提交、更改地点、切换期刊、格式转换

## 命令

该模块没有专用脚本。这是一个由法学硕士驱动的工作流程。

## 工作流程

1. 阅读 `references/venues/journal-adaptation-workflow.md` 了解完整的 4 步流程
2. 交叉引用 `references/citations/styles.md` 的引文格式规则
3. 交叉参考 `references/venues/catalog.md` 以满足特定期刊或会议的要求
4. 交叉引用 `references/formatting/number-unit-guide.md` 以了解数字/单位约定
5. 交叉引用 `references/formatting/table-guide.md` 了解表格格式要求

## 细节

适应模块指导系统的期刊或会议到期刊或会议格式转换：
- 从序言中检测当前地点
- 接受目标地点或用户提供的期刊指南（最高优先级）
- 生成跨 5 个维度的差异清单（参考文献、摘要、数字、图形/表格、布局）
- 使用 `[ADAPTED: reason]` 注释应用自动更改
- 为无法自动化的布局项目生成手动清单

关键约束：永远不要改变实质性内容（论点、数据、结论）。

技能层响应：将差异检查表、带注释的更改和手动检查表呈现为结构化输出。
