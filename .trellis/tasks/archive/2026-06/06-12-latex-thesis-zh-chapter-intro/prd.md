# latex-thesis-zh 章引言承上启下能力补强

## Goal

把"正文每章章首引言（第2章~结论前各正文章）"作为一个独立写作单元补强，使 `latex-thesis-zh` 既能**指导改写**、又能**自动检出**"两段式承上启下"章引言的常见问题。本任务通过**扩展现有 `logic` 模块** + 新增写作参考 + 测试 fixture 实现，**不新增模块**，不引入英文会议论文式 `section-writing` 抽象。

## 背景与依据（网络检索）

多所研究生院写作指南（清华 §4.5、北大、北航、同济、北理工）与实务写法高度共识：

- 正文每章开头是"引言"、结尾是"本章小结"，首尾呼应；章引言一般 **1~2 个自然段、约 300~500 字**。
- 结构为**两段式承上启下**：
  - **承上（第①段）**：点明上一章/前文对本章的价值，简述上一章解决了什么、得出什么结论，引出本章为何继续。
  - **启下（第②段）**：本章要解决的问题、核心思想、相对已有方法的优势，段末视学科预告本章各节安排（"本章组织结构/路标段"）。
- 两条可机检规范：
  - 章引言**不与绪论文献综述/前文重复**（清华指南明确）。
  - 衔接**用章节号（"第2章"）指代，避免"上一章/上文/前一章/下一章"**相对指代。
- 绪论（第1章）的三层漏斗式引言**不在本任务范围**，已由现有 `_check_introduction_funnel` 覆盖。

来源：清华研究生学位论文写作指南 §4.4-4.5；知乎《毕业论文中每一章的"引言"和"本章小结"的写法》；百度知道同题问答；同济/北大/北航/北理工写作规范。

## Requirements

- 在写作参考新增《正文章引言（承上启下两段式）》指导：两段角色定义、篇幅约定、可套用模板、正反例。
- 扩展 `analyze_logic.py`，把正文章引言从通用导语（S1）中**特化**检测，覆盖：承上缺失、启下缺失、篇幅异常（仅 1 句/极短或远超两段）、相对指代规范。
- "疑似与绪论重复"不强行用正则判定，作为 LLM 备注呈现。
- 新增检查默认随 `logic` 输出，不做成冷门开关。
- 现有 `logic` 行为（S1 通用导语、`_check_introduction_funnel`、C3 闭合、`_check_chapter_mainline` 既有可观察行为、`--motivation-thread`）不回归。
- 保持模板边界、GB/T 7714、`\cite/\ref/\label`、数学环境、章节号不被改写。
- 提供脚本可判定的测试 fixture：规范章引言（全过）、缺承上+启下、相对指代+篇幅异常。

## Acceptance Criteria

- [ ] 写作参考新增章引言一节，并被 `SKILL.md` Reference Map / 路由规则正确指向。
- [ ] `analyze_logic.py` 能对正文章引言报出**承上缺失、启下缺失、相对指代、篇幅异常**四类问题，且仅针对第2章~结论前各正文章（排除绪论/引言/结论/总结/展望/致谢/附录等）。
- [ ] 规范两段承上启下章引言 fixture 不被误报（无 P1 误报）。
- [ ] 现有 logic 输出无回归；`tests/test_skill_contracts.py`、`tests/test_skill_versions.py` 及 logic 相关测试通过。
- [ ] 未新增模块、未引入英文会议论文式 section-writing 抽象。
- [ ] skill 版本号按约定递增，`last_updated` 更新。
