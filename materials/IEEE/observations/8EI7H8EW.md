## Structure

罗马数字标题：`I. INTRODUCTION` → `II. METHODOLOGY` → `III. EXPERIMENTS` → `IV. CONCLUSION`。前置 `Abstract—` 与 `Index Terms—`。无独立 Related Work。`related_work=inlined`（Introduction 中段分 model-based / model-free，并用 TABLE I 汇总近期研究）。Introduction 末有节序路标，指向 Section II–IV。Method 为 II，含 Algorithm 1。Experiments 标题为 `EXPERIMENTS`（NREL PV + 吉林风电 + 日前经济调度）。

## Candidate rules

- R001 abstract 用 `Existing researches have mainly focused on` 再 `However` 指出被忽略的多模态，随后 `a ... model is proposed`。
- R002 Introduction 用 TABLE I 汇总相关研究，再把问题收成 two-sample problem，用 `Thus, the main contributions of this article are as follows` 给列表。
- R003 Introduction 末用 `The rest of this article is organized as follows` 指向 II–IV。
- R004 Experiments 用 scaled MMD 与 MAR 缺失率对照，结论段复述 SOTA 与 1.43% 调度误差。
- R005 Conclusion 以 `To address the issue of` 起句，末句 `future work will focus on`。
