# latex-thesis-zh 第二章写作能力优化：工艺流程分析 + 全文方法架构章式

## Goal

升级 `academic-writing-skills/latex-thesis-zh`（v5.3.0）对**工业背景中文博士大论文第二章**（"工艺流程分析 + 整篇论文综合方法架构"章式，下称**过程分析章**）的写作指导与自动诊断能力，使其能够：判别章式、给出结构骨架与写作规范、诊断"工艺→难点→框架→章节映射"主线闭合，并修复现有检查器对该章式的误报。

## 章式边界（本任务明确不做）

- **"第二章直接写方法+实验"流派**（如《预测控制综合方法及其在回转窑煅烧过程中的应用》：第二章即方法章、工艺分析推迟到第六章）：按既有正文方法章规则处理（thesis-writing-guide 方法章三问 + experiment 模块），本任务不为其新增内容。
- 指南必须先提供**章式判别**入口：工业/过程对象贯穿全文 → 过程分析章式；方法学为主、应用对象仅在后期出现 → 方法章式（走既有规则）。判别之后各走各的规则，不混用。

## 外部最佳实践依据（调研结论，写入 references 时注明适用边界）

1. **本地 5 篇工业背景博士论文**（ref/thesis，目录级证据全量核实，见 research/chapter2-conventions.md）：章式 5/5 一致为"工艺/过程分析 → （变量/数据）→ 难点/关键问题 → 总体框架 → 小结"；篇幅 10~18 页（约占全文 8%~13%）；直属节 4~7 个；引言形态"编号 2.1 引言"4/5、"章后导语"1/5；难点节必在框架节之前。
2. **网络检索同型目录 6 例**（钨冶炼 CPS、水泥回转窑模糊 ARX〔燕山〕、锌钡白回转窑、铁矿球团、乳化炸药、甲醇装置）与反例 1 例（预测控制综合方法论文），确认"过程分析章"是流程工业控制/建模方向主流章式，且存在"工艺章与方案章拆成两章"的变体（高炉自动化）。
3. **校规范侧**：燕山大学 2024 规范仅要求绪论含"研究框架/内容/方法"（YS-09），对第二章无硬性规定 → 所有口径标注"学科惯例，以导师与学校规范为准"，阈值可配置。
4. **绪论-第二章分工**（多篇论文一致）：绪论 1.3/1.4/1.5"研究内容与组织结构"讲**各章做什么与递进关系**（面向全文导航）；第二章总体框架节讲**方法模块间的技术衔接与数据流**（面向问题求解），二者内容不重复、粒度不同。内容级细则以 research/chapter2-content-analysis.md（5 子代理精读产出）为准。

## Requirements

- **R1 第二章专章指南**：新增 `references/writing/process-chapter-guide-zh.md`，含：①章式判别表（过程分析章 vs 方法章 vs 拆两章变体）；②推荐骨架与顺序不变式（引言 → 工艺流程分析 → 变量/数据〔可选〕→ 难点/关键问题 → 总体框架 → 本章小结；难点必须在框架前）；③工艺流程描述规范（按物料流工序段组织、工艺流程图必备、"设备/工序 → 关键变量 → 耦合关系"三层落位、深度以"能支撑难点推导"为度）；④难点推导链模板（工艺特性词 → 建模/控制难点 → 方法必要性；特性词表：强非线性、大滞后/大惯性、强耦合、时变、多工况、多速率、多源异构、不确定/波动等）；⑤问题数学形式化规范（符号定义、映射/优化式、子问题-章节对应）；⑥总体框架图规范（分层组织、模块=后续章、**推荐显式"第 X 章"映射**〔用户决策：作为加强项主动推荐；同时说明 3/5 范文用方法模块名+后续章反向承接亦属合规〕、数据流箭头、图题规范）；⑦绪论-第二章分工表与查重清单；⑧篇幅/节数弹性口径（10~20 页、直属节 4~7，超出时的合并建议）；⑨"小论文拼接感"表述规范（"源论文/小论文"→"核心问题/研究内容"）；⑩两种引言形态说明（编号 2.1 引言 vs 章后导语，均合规）。
- **R2 章引言形态适配（bug-fix 性质）**：`analyze_logic._check_chapter_intro` 识别"首个下级小节标题为引言/概述"形态：将该节内容作为章引言检查对象，消除误报；编号引言节形态使用独立篇幅上限（默认口径依 5 篇参考论文实测定，可配置）。两种形态均视为合规，不强推其一。**第 2 章特判**：参考论文 5/5 的第二章引言均为"本章概述式"（预告本章各节，不承接前章结论——承接对象是绪论已建立的背景），故对第 2 章只查"预告各节 + 篇幅"，不报"缺承上衔接"；承上启下两段式要求从第 3 章起适用（见 research/chapter2-content-analysis.md §1）。
- **R3 过程分析章主线检查**：`analyze_logic.py` 新增 flag `--process-chapter`（默认扫描第 2 章，`--section` 可覆盖），全部 `[Script]` 启发式：
  - `P-FLOW`：工艺/过程分析节内无 `\ref{fig:...}` 流程图引用 → Major（工艺章无流程图）。
  - `P-DERIVE`：难点/问题节缺"特性词 → 难点"推导句式（特性词表同 R1④）→ Major；特性词出现但无"导致/使得/难以/造成"类因果连接 → Minor。
  - `P-FRAME`：总体框架/方案节无框架图引用 → Major（缺框架图）；框架节未覆盖 ≥2 个方法模块名/后续章指向 → Major（框架空泛）；"第 X 章"显式章号映射缺失 → **Info（推荐加强项）**——参考论文 3/5 只用方法模块名组织数据流、靠后续章引言反向承接，不写章号（见 research §4/§7），故不作 Major 硬拦；但**用户决策：将显式章号映射作为推荐加强项**，Info 主动建议补全（更规范、便于盲审答辩定位），指南同步推荐。
  - `P-ORDER`：框架节先于难点/问题节出现 → Minor（顺序不变式）。
  - `P-PAPER`：章内出现"源论文/小论文/N 篇论文"表述 → Minor（盲审风险，建议改"核心问题/研究内容"）。
- **R4 structure-guide.md 修正**：第二章定位由单一"相关工作/文献综述"改为**双轨**（工业/过程背景 = 工艺流程分析+方法架构章；综述已在绪论承担时不得再设综述章；CS/方法学论文保留相关工作式），同步注明直属节预算对过程分析章的弹性口径；消除与 introduction-guide-zh.md 的自相矛盾。
- **R5 源码卫生检查（通用，fixture 驱动）**：`check_format.py` 新增：①`F-MD` Markdown 残留（可见正文 `**…**` 加粗等）→ Major；②`F-NOTE` 草稿备注模式（"后续可根据…替换""此处占位""TODO/待补充"等保守词表）→ Info。均不改写、只定位提示。
- **R6 文档与路由落位**：SKILL.md logic 行 Use when 追加"第二章工艺流程分析/总体框架章式"触发词、Reference Map 增指针行（延续瘦身原则，细节全下沉）；`references/modules/logic.md` 增 `--process-chapter` 检查表；`references/modules/routing-rules.md` 增判据条目；thesis-writing-guide.md 在方法章节前加一行指向新指南；evals.json 追加第二章诊断路由用例（≥1 正例 + 1 个"方法+实验流派不走该 flag"的边界例）。
