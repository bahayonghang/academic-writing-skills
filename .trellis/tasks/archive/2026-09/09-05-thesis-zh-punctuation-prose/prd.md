# 中文论文冒号分号与句间逻辑写作约束

## Goal

用户于 2026-09-05 实施中追加：AI 频繁用冒号和分号组织中文大论文，削弱句间逻辑且有明显机器写作感，要求写入任务并强化中文技能。当前仓库中文 LaTeX 技能名称为 latex-thesis-zh；父需求归属见父 PRD 的 Task Map。

## Requirements

- R1：中文学位论文连续正文默认避免“标签：结论”“原因是：”和分号堆叠，优先用完整句及有材料支持的因果、递进、转折、条件或并列关系组织论证。
- R2：保留必要的冒号引出、解释与真正并列的分号；不将标点本身判为 AI 证据，不虚称所有中文学术规范禁止这些符号。公式、代码、URL、引文原句、关键词和模板规定用法不机械替换。
- R3：规则写入既有中文表达指南，由 expression/deai 和技能入口明显可达；同步双语资源及实际输出评测，不新增检查码、阈值、计数正则或脚本。

## Acceptance Criteria

- [x] AC1（R1、R3）：既有 academic-style-zh 标点节有明确正文默认约束、改写步骤及前后示例；入口可按需发现该规则，deai 复用同一规则源。
- [x] AC2（R1、R2）：过度冒号/分号的合成正文改为连贯句子并保留全部事实；输入仅并列时不补造因果，不只是将符号替换为逗号。
- [x] AC3（R2）：合理引出/复杂并列和源码场景保留必要标点；摘要编号总起句与关键词等既有合法用法不被全禁。
- [x] AC4（R2、R3）：至少 3 个新 output 场景和触发正例完整追加，保存真实回答与逐项裁决；目标契约、资源同步与文档构建通过，脚本保持不变。

## Out of Scope

用户本次追加已授权实施。只改中文技能与对应公开文档；不修改其他技能，不新增依赖、检查器或全局标点禁令，不改真实论文，不提交/归档/推送。
