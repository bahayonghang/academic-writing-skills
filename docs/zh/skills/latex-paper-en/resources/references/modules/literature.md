# 模块：文献综述综合

**触发**：相关工作、文献综述、研究差距、重写相关工作、比较综合

**目的**：诊断文献综述是否在做分析工作而不是列出论文，然后提供一个安全的重写蓝图。

```bash
uv run python -B scripts/analyze_literature.py main.tex --section related
```

## 该模块检查什么

- **A1：枚举** — 3 个以上连续作者/年份行建议按论文列出。
- **A2：比较综合**——每个主题簇应至少包含一个句子来比较优点、缺点、权衡或共同的局限性。
- **A3：差距推导** - 最后几行应该揭示未解决的限制或激发论文动机的未充分探索的设置。

## 重写链

在提出散文时使用这个精确的推理链：

1. **共识**：多篇论文达成一致的内容
2. **分歧**：方法出现分歧或权衡的地方
3. **局限性**：比较方法都不能很好地处理什么
4. **差距**：论文目标的未解决条件
5. **本文**：目前的工作如何填补这一空白

## 声明-证据图

当文献综述包含差距、新颖性或贡献声明时，
将其与声明-证据合同进行总结
`references/evidence/claim-evidence-contract.md`：

- `claim`：确切的差距或贡献句子。
- `evidence_anchor`：引用以前的工作、章节引用或`missing`.
- `claim_strength`: `unsupported`, `observed`, `supported`， 或者`strong`.
- `missing_evidence`：最接近的先前工作、比较维度或声明支持
检查仍然不存在。
- `allowed_wording`：有界限的间隙措辞，不会夸大所引用的内容
文献证明。

## 硬性界限

- 请勿发明引用或添加未引用的权利要求。
- 保持`\cite{}`, `\ref{}`, `\label{}`，并且数学保持不变，除非用户明确要求进行源代码编辑。
- 如果该部分中的证据太薄弱，请说该差距不受支持，而不是强行证明。
- 引文关键字仅证明来源被引用；它并不能证明
引用的来源支持确切的论文稿件主张，直到主张支持为止
检查过。
