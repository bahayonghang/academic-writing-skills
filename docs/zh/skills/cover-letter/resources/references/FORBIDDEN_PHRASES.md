# 禁止短语

不应出现在学术提交投稿信中的短语。这
`presubmission_check.py` 中的正则表达式模式是唯一的事实来源；这
文件是人类可读的镜像。每个层映射到脚本的代码组
发出：

| 层 | 脚本常量 | 代码 | 触发器 |
| ------------------------ | ---------------------------- | ------------ | ------------------------- |
| 1（开瓶器） | `LETTER_OPENER_CLICHES` | `L2a`-`L2e` | 仅第一个内容行 |
| 2（营销形容词） | `BANNED_TONE_PATTERNS` | `AI1`-`AI14` | 出现 3 次以上 |
| 3（投稿信陈词滥调） | `LETTER_BANNED_PHRASES` | `J1a`-`J1i` | 1+（`major` 为 3+） |
| 4（通用型） | `LETTER_GENERIC_FIT_PHRASES` | `J4a`-`J4d` | 1+，带更换提示 |

## 第 1 层：轻松的开场白（始终旗鼓相当）

这些标志着一封轻松写给顶级期刊编辑的信：

- “我们很高兴提交”
- “我们很高兴分享”
- “我们很高兴提交”
- “我们很荣幸提交”
- “我们很高兴提交”
- “随函附上，请查收”
- “请查收附件”
- “请查收附件”
- “我们特此提交”

## 第 2 层：营销形容词（出现 3 次以上的标记）

这些都在没有增加证据的情况下膨胀。继承自纸质审核 `BANNED_TONE_PATTERNS`：

- 创新的
- 开拓
- 革命性的
- 变革性的
- 突破
- 空前的
- 卓越
- 优越的
- 最先进的
- “凸显潜力”
- “铺平道路”
- “深刻的挑战”
- “本质上”

## 第 3 层：投稿信特定的禁止短语（出现 1 次以上时标记）

这些是顶级期刊编辑们不予考虑的模板式填充内容：

- “新颖、创新”
- “开创性的”
- “史无前例”
- “改变游戏规则”
- “范式转变”
- “前沿”
- “非常感兴趣”
- “将引起广泛的兴趣”
- “这个领域需要”

## 第 4 层：通用短语（带有建议替换的标记）

这些表明作者没有仔细阅读该期刊：

- “你的期刊”/“你享有盛誉的期刊”——明确地命名期刊
- “适合范围”——指定具体的范围维度
- "broad readership" — 命名特定的读者档案
- “对该领域的重要贡献” - 命名贡献类别

## 什么是可以接受的

- 可信的事实陈述：“我们的方法在 ImageNet 验证集上将推理延迟减少了 47%。”
- 有界比较：“这通过引入 X 扩展了 Chen 等人 (2024) 的框架。”
- 具体期刊联系：“这项工作直接解决了[目标期刊的最新论文]中提出的悬而未决的问题。”

## 为什么这些被禁止

这些层级的模式是：他们用营销代替证据。每周阅读 50 封信件的编辑可以立即发现模板语言并降低信件的信号价值。通过 `presubmission_check.py` 且 1-3 级命中率为零的投稿信将被解读为用心书写。
