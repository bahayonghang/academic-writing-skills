# Research Paper Writing Frontend Guidelines

In this repository, "frontend" means the writing guides and example bank that
the skill exposes to users. There is no UI framework here.

## Pre-Development Checklist

Before editing section guides or example files:

1. Read [Directory Structure](./directory-structure.md) to keep the single-skill
   layout and example bank intact.
2. Read [Component Guidelines](./component-guidelines.md) before changing a
   section guide template or example structure.
3. Read [Hook Guidelines](./hook-guidelines.md) before changing load-on-demand
   or routing guidance.
4. Read [State Management](./state-management.md) before changing the revision
   workflow or claim-evidence flow.
5. Read [Quality Guidelines](./quality-guidelines.md) and [Type Safety](./type-safety.md)
   before changing metadata, examples, or section names.
