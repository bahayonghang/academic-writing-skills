# Research Paper Writing Backend Guidelines

In this repository, "backend" means the skill package metadata, repository
layout, and any supporting files that keep the writing skill installable. There
is no executable app backend.

## Pre-Development Checklist

Before editing the package structure or metadata:

1. Read [Directory Structure](./directory-structure.md) to keep the single-skill
   layout intact.
2. Read [Reference Corpus And State](./database-guidelines.md) before changing
   references, examples, or attribution text.
3. Read [Error Handling](./error-handling.md) before changing fallback or
   unsupported-section guidance.
4. Read [Quality Guidelines](./quality-guidelines.md) before changing the skill
   narrative or packaging text.
5. Read [Logging Guidelines](./logging-guidelines.md) before changing any
   progress, review, or evidence-noting language.
