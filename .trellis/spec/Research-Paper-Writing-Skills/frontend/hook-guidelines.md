# Hook Guidelines

There are no runtime hooks here. Use this file for load-on-demand guidance.

Local pattern:

- Load only the section guide you need.
- Keep the example bank indexed so the next file to open is obvious.
- Do not load all section references at once.
- When a writing issue crosses sections, start with the relevant guide and move
  outward only if the problem truly spans the paper.

Reference files:

- `ref/Research-Paper-Writing-Skills/research-paper-writing/SKILL.md`
- `ref/Research-Paper-Writing-Skills/research-paper-writing/references/examples/index.md`

Avoid:

- Teaching the agent to open every guide preemptively.
- Writing guidance that assumes one fixed paper structure.
- Losing the route from the SKILL file to the right section reference.
