# 示例：预设反驳与让步壳

用户请求：
导师说我学位论文第 4、5 章是防御性写作，满篇“这并不意味着”“不能简单地认为”“仍有提升空间”。请去除防御性表述和预设辩解，真实的局限都要留着，证据撑不住的结论帮我校准。

推荐模块顺序：
1. `claim-forward`（脚本检查五个 `CF-*` 码）
2. `claim-forward`（按 `references/writing/claim-forward-zh.md` 的仅 LLM 处置判断）

命令：
```bash
uv run python $SKILL_DIR/scripts/check_claim_forward.py main.tex --section results
uv run python $SKILL_DIR/scripts/check_claim_forward.py main.tex --section discussion
```

脚本在这里可能零发现。四类处置没有脚本码，由 LLM 按写作指南判断。

预期输出：
- 每条发现一个 `[LLM]` 块，以处置小节标题称呼：预设反驳壳、让步后否定、断言与让步壳共现、空泛谦辞。
- 指向真实差异或混杂的让步句保留。它所维护的结论绑定到稿件已有的分析，或收回到数据支持的范围，或标【待补证】。
- 改后断言强度不高于原文；不补造对照、分层、显著性结论、数字或局限。
- 准确清楚的原文保留。零发现是合法结果。

示例块（合成）：
```latex
% 主张前置（合成）[Severity: Major] [Priority: P1]: [LLM] 让步后否定
% 原文：虽然随访登记人数由250增至320，按期完成随访的比例由84.0\%降至80.0\%，但这并不影响新提醒流程提高了随访依从性的判断。
% 修改后：随访登记人数由250增至320，按期完成随访的比例由84.0\%降至80.0\%。稿件未比较新增登记者与原有登记者的构成，现有数据不足以判断新提醒流程是否提高了随访依从性【待补证：按原有与新增登记者分别报告按期完成比例】。
% Changed:       主句收回到数据支持的范围；让步内容保留
% Protected:     250；320；84.0\%；80.0\%
% Meaning-Check: NEEDS-LLM
% Risk-Flags:    understatement
```

这里置 `understatement`，是因为用户明确要求校准。没有这一要求时，改写块保持原强度，过度声称作为 finding 报告。

应保持不动的边界：
- “受访者均来自同一城区，结果不说明各原因在其他城区的实际占比。”这是带原因的真实证据边界。
- “本文所称‘按期完成随访’……不包括仅发送短信提醒的情形。”这是定义性否定。
- “虽然已有研究\cite{followup2020}报告了更高的随访完成率，但其统计口径只包含能够到院复诊的居民。”这是对带引用前人工作的让步。
- 结论章写出具体局限、其后接展望的承接句，符合 `CC-OUTLOOK-TRANS`。

多个可能机制加“现有数据无法验证”属防御性推测解释，归 `deai`，不走本模块。
